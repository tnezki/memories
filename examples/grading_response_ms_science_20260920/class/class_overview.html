Major Strengths

  • Students generally identify the design goal and participate in iterative testing.
  • Most students can describe a plausible redesign.
  • Several students use measured test results when explaining performance.

Top Actionable Patterns

  • Use measurements consistently when comparing designs.
  • Connect the observed failure directly to the redesign.
  • Name tradeoffs instead of treating one redesign as simply “better.”
Highest-leverage class target: Make every redesign explanation follow evidence -> change -> expected effect.
