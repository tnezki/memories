Extension Station 2 - Error Analysis - Answer Key

Question 1

A student says the midpoint of \((-6,4)\) and \((2,10)\) is \((-4,14)\). Identify the error and give the correct midpoint.

Answer: They added coordinates but did not divide each sum by 2; correct midpoint \((-2,7)\).

Question 2

A student writes \(x^2-5x+6=(x-1)(x-6)\). Correct the factorization and explain the check.

Answer: \((x-2)(x-3)\); the factors multiply to 6 and add to -5.

Question 3

A student solves \(|2x+1|=5\) using only \(2x+1=5\). What solution is missing?

Answer: The second branch \(2x+1=-5\) gives the missing solution \(x=-3\).

Question 4

A student says a line perpendicular to slope \(\frac35\) also has slope \(-\frac35\). Correct the slope and explain.

Answer: Perpendicular slope \(-\frac53\), the negative reciprocal.
