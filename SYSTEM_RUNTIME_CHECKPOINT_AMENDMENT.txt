SCOPE: Algebra 1 personalized Checkpoint runs executed from pms_build/checkpoint.txt Mode B.

This amendment specializes SYSTEM_RUNTIME_CONTRACT.txt for the live personalized Checkpoint workflow.

PURPOSE
-------
A Checkpoint run is a private state-informed assessment generation workflow, not a public repository artifact build. The owner-local `_algebra_teacher_tools` surface owns the Checkpoint Builder entry page; the public Algebra repository owns shareable curriculum authorities/artifacts. The actual selected students, personalized question plans, source map, and generated run outputs remain private.

OWNER-LOCAL BUILDER - HARD
--------------------------
Normal builder path:
  _algebra_teacher_tools/tools/checkpoint/checkpoint_builder.html

The shared Algebra Teacher Dashboard must not link the Checkpoint Builder. A Mode A tool-build request creates/repairs the declared local owner-tool path through the local transfer helper; it must not recreate the retired public repository builder path.

CANONICAL PRIVATE DRIVE ROOT - HARD
-----------------------------------
Use this exact Google Drive folder as the one and only Portfolio/Checkpoint root:

  title: ____Portfolio_Data
  folder_id: 1xFGmkwiHXxJIwsJEx36nSy4C6OLr3Y3o

For an Algebra Checkpoint run:
1. fetch/open the exact root by folder ID before resolving course/unit folders;
2. never globally search for another same-named root when the ID is available;
3. resolve `Algebra 1 / unit N / 02 Portfolio Data` for current roster/evidence state;
4. resolve/create `Algebra 1 / unit N / 06 Checkpoints` for Checkpoint persistence;
5. create a unique dated/run-specific child folder under `06 Checkpoints`;
6. never overwrite an older Checkpoint run;
7. if the exact root/current Unit state cannot be accessed, fail closed rather than substituting another location.

Use additional Portfolio files when needed for sound targeting.

PRIVATE PERSISTENCE IS A COMPLETION GATE
----------------------------------------
A Checkpoint run is not complete merely because an HTML/PDF can be downloaded.
Before PASS, the exact run folder under `06 Checkpoints` must contain and verify:
- checkpoint.html
- checkpoint.pdf
- checkpoint_source_map.json
- run_manifest.json

If a required write/verification fails, stop with CHECKPOINT_DRIVE_PERSISTENCE_FAILED.

DELIVERY
--------
Successful actual Checkpoint run:
- persist private run state/output under the canonical Drive tree;
- return the printable HTML individually;
- return the printable PDF individually;
- do not package student Checkpoint outputs in a GitHub Transfer ZIP;
- do not write student data or the personalized source map to GitHub.

A separate Mode A request that creates/repairs the owner-local Checkpoint Builder uses the local transfer helper to `_algebra_teacher_tools` and does not create a public repository control page.

All other SYSTEM_RUNTIME_CONTRACT rules remain in force.
