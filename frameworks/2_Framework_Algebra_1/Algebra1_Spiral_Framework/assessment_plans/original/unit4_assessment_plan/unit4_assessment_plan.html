Section Outline

Section 4.1: Recognizing Function Families

Learning Target: Students will identify common function families from graphs, equations, tables, and contexts.

I Can Statements

  • I can construct evidence for a function family using patterns in graphs, equations, tables, and contexts.
  • I can apply family features to sort representations into linear, quadratic, exponential, absolute value, and other familiar forms.
  • I can determine which representation gives the strongest evidence for a function family when features seem similar.

Key Vocabulary / Notation

  • parent function
  • linear
  • quadratic
  • exponential
  • absolute value

Key Representations

  • Graphs of parent and familiar function families
  • Tables showing constant differences, second differences, or ratios
  • Equations in recognizable family forms
  • Contexts involving change patterns
  • Feature language such as intercept, vertex, rate, and symmetry

Common Misconceptions / Failure Points

  • Choosing a family from one surface feature while ignoring conflicting table or equation evidence.
  • Treating all curved graphs as quadratic.

Modeling / Application / Practice Opportunities

  • Use data patterns to choose a reasonable function family for a situation
  • Connect visible graph features to possible real-world behavior
  • Represent the same relationship with a graph, table, equation, and context
  • Critique whether a selected family fits all available evidence

Spiral Planning

Intro: Identify common function families from graphs, equations, tables, and contexts.

Review: Solve systems graphically and by elimination while interpreting the meaning of different solution types.

Mastery: Analyze and compare linear relationships using multiple representations.

Section 4.2: Translations

Learning Target: Students will graph and write translated functions using key points and key features.

I Can Statements

  • I can build translated graphs by moving key points and key features from a parent function.
  • I can use horizontal and vertical shifts to write equations for translated functions.
  • I can predict how changing values in an equation moves a graph left, right, up, or down.

Key Vocabulary / Notation

  • parent function
  • translation
  • horizontal shift
  • vertical shift
  • key point

Key Representations

  • Parent function graphs
  • Translated graphs on coordinate grids
  • Equations in transformation form
  • Key points, vertices, intercepts, and asymptotes where appropriate
  • Tables before and after translation

Common Misconceptions / Failure Points

  • Reversing the direction of horizontal shifts in equation form.
  • Moving only the vertex while leaving other key points inconsistent.

Modeling / Application / Practice Opportunities

  • Shift a model to represent a changed starting value or benchmark
  • Use key points to sketch a translated relationship efficiently
  • Connect equation parameters to movement on a graph
  • Translate a graph to satisfy contextual constraints

Spiral Planning

Intro: Graph and write translated functions using key points and key features.

Review: Graph and interpret linear inequalities.

Mastery: Graph linear functions and interpret key features.

Section 4.3: Transformations

Learning Target: Students will analyze and graph transformations involving stretches, compressions, and reflections.

I Can Statements

  • I can design transformed graphs using stretches, compressions, reflections, and translations of parent functions.
  • I can apply transformation rules to key points and features across function families.
  • I can assess whether an equation, graph, or table represents the same transformed function.

Key Vocabulary / Notation

  • stretch
  • compression
  • reflection
  • translation
  • transformation parameter

Key Representations

  • Transformation equations using parameters
  • Graphs showing vertical stretches and compressions
  • Graphs reflected over an axis
  • Tables transformed from parent-function values
  • Key features such as vertex, intercepts, symmetry, and rate behavior

Common Misconceptions / Failure Points

  • Confusing vertical stretch/compression with horizontal movement.
  • Reflecting or scaling points inconsistently across the graph.

Modeling / Application / Practice Opportunities

  • Adjust a parent function to fit a steeper, flatter, or reflected situation
  • Use a transformed table to generate a graph and equation
  • Connect parameter values to meaningful changes in a context
  • Check whether multiple representations model the same transformation

Spiral Planning

Intro: Analyze and graph transformations involving stretches, compressions, and reflections.

Review: Analyze and interpret systems of linear inequalities.

Mastery: Interpret slope as a measure of constant rate of change.

Section 4.4: Polynomial Operations

Learning Target: Students will add, subtract, and multiply polynomial expressions.

I Can Statements

  • I can formulate polynomial sums, differences, and products from area, perimeter, and expression contexts.
  • I can use structure and like terms to add, subtract, and multiply polynomial expressions.
  • I can extend polynomial operations to equivalent expressions written in different forms.

Key Vocabulary / Notation

  • polynomial
  • like terms
  • monomial
  • binomial
  • product

Key Representations

  • Polynomial expressions in standard and factored forms
  • Area models and algebra tiles
  • Tables of expression values
  • Equivalent expressions after combining or multiplying terms
  • Contextual diagrams involving length, width, area, and total change

Common Misconceptions / Failure Points

  • Combining unlike polynomial terms.
  • Distributing a negative sign or multiplying binomials incompletely.

Modeling / Application / Practice Opportunities

  • Represent area or perimeter situations with polynomial expressions
  • Use algebra tiles or area models to multiply binomials
  • Connect polynomial operations to equivalent forms of a model
  • Check whether an expression form makes sense for a context

Spiral Planning

Intro: Add, subtract, and multiply polynomial expressions.

Review: Solve systems using substitution and choose efficient forms for solving.

Mastery: Write linear equations from graphs, tables, and situations.

Section 4.5: Polynomial Structure and Quadratic Graphs

Learning Target: Students will connect polynomial expressions to quadratic graphs and key features.

I Can Statements

  • I can construct connections between polynomial structure, quadratic graphs, and key features.
  • I can predict graph features from equivalent quadratic expressions.
  • I can critique whether a polynomial expression supports a claimed vertex, intercept, axis of symmetry, or direction of opening.

Key Vocabulary / Notation

  • quadratic
  • parabola
  • vertex
  • axis of symmetry
  • intercept

Key Representations

  • Quadratic expressions in equivalent forms
  • Parabolas with vertex, intercepts, and axis of symmetry
  • Tables showing quadratic patterns
  • Factored or expanded expressions connected to graph features
  • Contexts modeled by quadratic relationships

Common Misconceptions / Failure Points

  • Assuming every expression form reveals every graph feature equally well.
  • Confusing the vertex with an intercept or the axis of symmetry with a solution.

Modeling / Application / Practice Opportunities

  • Use expression structure to predict features of a quadratic model
  • Connect expanded and factored forms to graph information
  • Choose a useful form for answering a contextual question
  • Revise a model when its graph features do not fit the situation

Spiral Planning

Intro: Connect polynomial expressions to quadratic graphs and key features.

Review: Create and solve systems that model real-world situations.

Mastery: Use linear models to represent and interpret real-world data.

Mastery Goals

U4-MG01

Mastery Goal: Interpret slope as constant rate of change across tables, graphs, and contexts and judge whether a rate is reasonable.

Supporting Learning / Prerequisites

  • I can construct rate-of-change statements from tables, graphs, and situations.
  • I can apply slope calculations to interpret constant change between quantities.
  • I can determine whether a slope value is reasonable for a given context.

Key Representations

  • Slope triangles on coordinate graphs
  • Tables showing equal input intervals
  • Contextual rate statements
  • Ratio notation for vertical change over horizontal change
  • Positive, negative, zero, and undefined slope examples

Recurring Practices

  • Reason about rate of change
  • Connect graphs, tables, equations, and contexts
  • Use models to make and evaluate predictions

MEETING evidence should demonstrate: Independently demonstrates the goal across more than one appropriate representation or context, with accurate work, sufficient interpretation, and a defensible connection back to the original problem or situation.

Common Evidence Weaknesses / Misconceptions

  • Reversing vertical and horizontal change or using inconsistent point order.
  • Interpreting slope as a starting value rather than a rate.

  • Slope-intercept equations
  • Tables of input-output values
  • Graphs with marked intercepts
  • Verbal descriptions of rates and starting values
  • Equivalent equation forms

Recurring Practices

  • Reason about rate of change
  • Connect graphs, tables, equations, and contexts
  • Use models to make and evaluate predictions
