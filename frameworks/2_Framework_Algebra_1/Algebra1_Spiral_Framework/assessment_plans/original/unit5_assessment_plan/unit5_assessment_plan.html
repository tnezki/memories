Course-Long Fluency Overlay

Algebra Warm-Ups run on a separate course-long fluency track rather than mirroring the section Intro / Review / Mastery map.

  • Q1 · Solve / Equation Fluency — Use a compact equation-solving mini-set. Progress during the year: one-step → mixed one-step → two-step → combining like terms → distribution → multi-step → variables on both sides → rational coefficients → cumulative mixed solving. Older types continue to reappear.
  • Q2 · Diamond / Factoring Pattern — Build product-sum reasoning from number relationships toward factor pairs, factoring trinomials, and special factoring patterns.
  • Q3 · Skill Review — Rotate foundational skills such as fractions, integer rules, order of operations, distribution, combining like terms, substitution/evaluation, exponent laws, function notation, and upcoming prerequisites. Encourage mental/non-calculator fluency without prohibiting calculator use when needed.
  • Q4 · Challenge — Use a short reasoning, pattern, generalization, error-analysis, representation, or nonroutine problem. Challenge should reward thinking, not merely uglier arithmetic; full completion is not required for every student.

Official Exit Ticket Architecture

Each normal Algebra section has one official four-question Exit Ticket. It is a rolling mastery-evidence pulse, not a second Practice set and not a four-stage sampler.

  • Questions 1–2: two NEW evidence opportunities selected from the current section Mastery Goal(s) and supporting I Can statements. A coursewide Exit map distributes those I Can opportunities intentionally; do not force every supporting I Can onto one ticket.
  • Questions 3–4: two fresh PARALLEL reassessment opportunities for the two new evidence jobs introduced on the previous section’s official Exit Ticket. Reassessment should preserve the evidence target while changing values, representation, context, or structure only when useful.
  • The reassessment chain continues across Unit boundaries: Unit N Section 1 normally reassesses Unit N−1 Section 5.
  • Unit 1 Section 1 is the only opening exception because there is no previous Algebra section. Do not invent fake repeats. Its exact four-question opening pattern remains intentionally reserved for the Bank/Exit map decision.
  • Intro and Review are checked formatively during instruction, Warm-Ups, Practice, CYU, discussion, whiteboards, activities, or a targeted reteach/recovery check. A teacher-requested reteach/recovery check is local formative evidence and is not automatically an official Exit Ticket or canonical Bank requirement.
