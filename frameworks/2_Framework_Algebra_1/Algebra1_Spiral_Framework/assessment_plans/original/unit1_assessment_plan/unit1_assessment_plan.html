Section Outline

Section 1.1: Multiple Representations of Relationships

Learning Target: Students will connect tables, graphs, equations, and contexts that represent the same relationship.

I Can Statements

  • I can construct a table, graph, equation, or context from another representation of the same relationship.
  • I can use features in one representation to work with a related table, graph, equation, or context.
  • I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

Key Vocabulary / Notation

  • input-output pair
  • coordinate graph
  • equation
  • rate
  • equivalent representation

Key Representations

  • Tables of input-output pairs
  • Coordinate graphs
  • Equations and rules
  • Verbal contexts
  • Connections among multiple representations

Common Misconceptions / Failure Points

  • Matching representations by visual appearance while ignoring scale or values.
  • Changing a table or graph without preserving the same ordered pairs or relationship.

Modeling / Application / Practice Opportunities

  • Build a graph from a context about distance, cost, or time.
  • Formulate an equation from a table of values.
  • Use a graph to predict a missing table value.
  • Check whether a context and equation communicate the same relationship.

Spiral Planning

Intro: Connect tables, graphs, equations, and contexts that represent the same relationship.

Review: Interpret and create graphs on the coordinate plane while connecting points, axes, intercepts, and graphical information to mathematical situations.

Mastery: Solve inequalities, represent solution sets graphically, and interpret solutions in context.

Section 1.2: Inputs, Outputs, and Functions

Learning Target: Students will interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

I Can Statements

  • I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.
  • I can apply an input-output rule to generate missing values and ordered pairs.
  • I can assess whether a rule gives one output for each input in a situation.

Key Vocabulary / Notation

  • input
  • output
  • function
  • ordered pair
  • mapping diagram

Key Representations

  • Input-output tables
  • Function rules
  • Ordered pairs
  • Mapping diagrams
  • Context-based input and output quantities

Common Misconceptions / Failure Points

  • Reversing inputs and outputs when applying a rule.
  • Treating a repeated input with two different outputs as a function.

Modeling / Application / Practice Opportunities

  • Build a function rule from repeated input-output calculations.
  • Use a context to assign inputs and outputs meaning.
  • Predict outputs for new inputs using a rule.
  • Check a mapping for repeated inputs with different outputs.

Spiral Planning

Intro: Interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

Review: Identify patterns and represent relationships using input-output rules, tables, words, and symbols.

Mastery: Evaluate numerical and algebraic expressions correctly using substitution and order of operations.

Section 1.3: Function Families

Learning Target: Students will recognize common function families from graphs, tables, equations, and contexts.

I Can Statements

  • I can design examples of linear, quadratic, exponential, and absolute value relationships using more than one representation.
  • I can extend patterns in tables, graphs, equations, and contexts to work with common function families.
  • I can critique a proposed function family choice using evidence from rate of change, shape, or equation structure.

Key Vocabulary / Notation

  • linear
  • quadratic
  • exponential
  • absolute value
  • function family

Key Representations

  • Linear patterns
  • Quadratic patterns
  • Exponential growth and decay patterns
  • Absolute value patterns
  • Family features across representations

Common Misconceptions / Failure Points

  • Classifying a family from graph appearance alone without checking differences, ratios, or equation structure.
  • Confusing quadratic growth with exponential growth.

Modeling / Application / Practice Opportunities

  • Create a context that fits a given family feature.
  • Use table patterns to choose a likely family.
  • Predict how a graph changes when a family pattern changes.
  • Critique family choices that rely only on appearance.

Spiral Planning

Intro: Recognize common function families from graphs, tables, equations, and contexts.

Review: Recognize constant rate of change in tables, graphs, visual patterns, and situations.

Mastery: Accurately perform operations with integers, fractions, and decimals while interpreting results in mathematical and contextual situations.

Section 1.4: Expressions and Structure

Learning Target: Students will interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

I Can Statements

  • I can build equivalent expressions by using structure, grouping, and properties of operations.
  • I can apply rewriting strategies to make the meaning of an expression easier to work with.
  • I can determine whether two expressions are equivalent by using structure, substitution, or properties.

Key Vocabulary / Notation

  • term
  • coefficient
  • factor
  • equivalent expression
  • distributive property

Key Representations

  • Algebraic expressions
  • Equivalent forms
  • Grouped terms and factors
  • Context meanings for terms
  • Substitution checks

Common Misconceptions / Failure Points

  • Combining unlike terms as though they were like terms.
  • Distributing a factor to only one term or changing the value while rewriting.

Modeling / Application / Practice Opportunities

  • Build an expression for a cost, perimeter, or repeated quantity.
  • Rewrite an expression to reveal a useful structure.
  • Use substitution to test equivalence.
  • Connect terms and coefficients to a context.

Spiral Planning

Intro: Interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

Review: Compare relationships using equations, graphs, tables, visual patterns, and contexts, then justify conclusions.

Mastery: Analyze and rewrite algebraic expressions using properties of operations and algebraic structure.

Section 1.5: Equations as Models

Learning Target: Students will write, solve, and interpret equations that model situations.

I Can Statements

  • I can construct an equation that models a situation using meaningful quantities and operations.
  • I can use solution steps to solve an equation and connect the result to the situation.
  • I can predict whether a solution is reasonable by interpreting it in the original context.

Key Vocabulary / Notation

  • variable
  • equation
  • solution
  • inverse operation
  • contextual quantity

Key Representations

  • Context-based equations
  • Solution steps
  • Variables as quantities
  • Balanced relationships
  • Interpreted solutions

Common Misconceptions / Failure Points

  • Performing an operation on only one side of an equation.
  • Reporting a numerical solution without interpreting units or context.

Modeling / Application / Practice Opportunities

  • Formulate an equation from a real-world situation.
  • Use a solution to answer a context question.
  • Predict a reasonable value before solving.
  • Check whether a solution makes sense in context.

Spiral Planning

Intro: Write, solve, and interpret equations that model situations.

Review: Represent linear relationships using tables, graphs, equations, and contextual descriptions.

Mastery: Solve one-variable equations and interpret solutions within mathematical and contextual situations.

Mastery Goals

U1-MG01

Mastery Goal: Compute with rational numbers and evaluate numerical or algebraic expressions accurately, using order of operations and substitution while checking reasonableness.

Supporting Learning / Prerequisites

  • I can construct accurate rational number computations using integers, fractions, and decimals in mathematical and contextual situations.
  • I can apply operation rules to calculate sums, differences, products, and quotients with rational numbers.
  • I can assess whether rational number results are reasonable for the situation they represent.
  • I can formulate a clear sequence of steps for evaluating numerical and algebraic expressions.
  • I can use substitution and order of operations to calculate expression values accurately.
  • I can determine whether an expression value makes sense after substitution.

Key Representations

  • Integer expressions
  • Fraction operations
  • Decimal operations
  • Number line models
  • Contextual quantities
  • Numerical expressions
  • Algebraic expressions
  • Substitution tables
  • Operation hierarchy
  • Contextual expression values

Recurring Practices

  • Reason quantitatively with signed and fractional values
  • Use structure and properties to preserve equivalence
  • Check solutions and interpret constraints in context

  • U1-MG03: Secure evidence must show the student can meet this goal: Solve one-variable equations with equivalent transformations and verify and interpret solutions. Include enough visible reasoning or representation work to judge independence and precision.
  • U1-MG04: Secure evidence must show the student can meet this goal: Solve one-variable inequalities, represent solution sets on number lines, and interpret boundaries and constraints. Include enough visible reasoning or representation work to judge independence and precision.

Important Representations / Practices / Contexts: Include a defensible mix of Integer expressions, Fraction operations, Decimal operations, Number line models, Contextual quantities, Numerical expressions, Algebraic expressions, Substitution tables, Operation hierarchy, Contextual expression values. Require students to interpret meaning and connect representations when the source learning supports it.

Recommended Balance: Use a balanced paper-only mix of selected-response and constructed-response evidence. Constructed responses should make student reasoning visible; longer performance evidence may contribute additional portfolio evidence rather than being forced into the conventional test.

Meeting Evidence: Meeting does not require perfection. The body of secure evidence should be sufficient, accurate, and independent enough to demonstrate the Mastery Goals consistently.

Exceeding Opportunity: Exceeding may emerge when a student transfers the mastery learning to a less familiar representation, context, or multi-step reasoning demand. No separate mandatory “Exceeding question” is required.

Materials / Calculator / Reference Rules: The supplied source specifies a paper-only assessment but does not specify calculator or reference rules; retain the established local course policy. No special lab materials are required by the source.

Expected Time: Approximately 45 minutes, consistent with the supplied course source.

Reassessment / Alternate Forms: No specific reassessment rule is supplied. Any alternate form should preserve these same Mastery Goals, Learning Ladder expectations, and representation variety.

DOK: Depth of Knowledge is descriptive of the thinking required by each evidence opportunity, not a quota. Do not force DOK 4 into a conventional paper assessment.
