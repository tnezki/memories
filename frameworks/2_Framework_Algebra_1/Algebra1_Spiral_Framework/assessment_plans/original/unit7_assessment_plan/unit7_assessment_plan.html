Section Outline

Section 7.1: Recognizing Growth and Decay

Learning Target: Students will identify exponential relationships from patterns, tables, graphs, and situations.

I Can Statements

  • I can construct evidence from patterns, tables, graphs, and situations to support an exponential growth or decay relationship.
  • I can apply repeated multiplication and constant ratios to exponential patterns.
  • I can determine whether a relationship is exponential by checking how values change across representations.

Key Vocabulary / Notation

  • exponential growth
  • exponential decay
  • constant ratio
  • growth factor
  • decay factor

Key Representations

  • Tables with constant ratios
  • Graphs showing growth or decay curves
  • Verbal situations involving repeated percent change
  • Sequences of values or patterns
  • Equations in the form $y=ab^x$

Common Misconceptions / Failure Points

  • Using constant differences to justify an exponential relationship.
  • Confusing a decay factor with the percent decrease.

Modeling / Application / Practice Opportunities

  • Model population growth from a table of values
  • Model depreciation of an object over time
  • Connect repeated percent change to growth or decay factors
  • Sort evidence from tables, graphs, and contexts by type of change

Spiral Planning

Intro: Identify exponential relationships from patterns, tables, graphs, and situations.

Review: Solve quadratic equations using the quadratic formula and interpret solutions.

Mastery: Recognize and factor special polynomial patterns.

Section 7.2: Writing Exponential Equations

Learning Target: Students will write exponential equations from tables, graphs, and situations.

I Can Statements

  • I can build exponential equations using an initial value and a growth or decay factor.
  • I can use exponential equations to predict values from tables, graphs, and situations.
  • I can formulate exponential equations that represent repeated percent increase or decrease.

Key Vocabulary / Notation

  • initial value
  • growth factor
  • decay factor
  • exponential equation
  • percent change

Key Representations

  • Initial values and growth factors
  • Tables of input-output values
  • Graphs with visible intercepts and multiplicative change
  • Context statements with percent growth or decay
  • Equations such as $f(x)=a(1+r)^x$ and $f(x)=a(1-r)^x$

Common Misconceptions / Failure Points

  • Using the percent change itself as the multiplicative factor.
  • Switching the roles of initial value and growth/decay factor.

Modeling / Application / Practice Opportunities

  • Create savings or investment models with repeated percent growth
  • Create depreciation models for cars, technology, or equipment
  • Translate table values into exponential equations
  • Use an equation to forecast future values within a context

Spiral Planning

Intro: Write exponential equations from tables, graphs, and situations.

Review: Solve quadratic equations using factored form and interpret solutions.

Mastery: Identify common factors and use structure to rewrite polynomial expressions.

Section 7.3: Graphing and Analyzing Exponential Functions

Learning Target: Students will graph exponential functions and analyze key features.

I Can Statements

  • I can design graphs of exponential functions using key points, growth or decay factors, and asymptote behavior.
  • I can apply key features of exponential graphs to interpret domain, range, intercepts, and end behavior.
  • I can assess whether a graph is reasonable for an exponential equation or situation.

Key Vocabulary / Notation

  • asymptote
  • domain
  • range
  • intercept
  • end behavior

Key Representations

  • Coordinate graphs of exponential functions
  • Tables generated from exponential equations
  • Key points such as the y-intercept
  • Horizontal asymptote behavior
  • Domain and range statements

Common Misconceptions / Failure Points

  • Drawing an exponential graph through its horizontal asymptote.
  • Treating end behavior as linear or ignoring the effect of the growth/decay factor.

Modeling / Application / Practice Opportunities

  • Graph growth and decay models from equations
  • Connect an equation's parameters to graph behavior
  • Interpret asymptote behavior in real-world settings
  • Use key points to sketch and check exponential graphs

Spiral Planning

Intro: Graph exponential functions and analyze key features.

Review: Solve quadratic equations by completing the square and connect the process to vertex form.

Mastery: Connect factors, zeros, intercepts, and graphs of quadratic functions.

Section 7.4: Comparing Function Families

Learning Target: Students will compare linear, quadratic, and exponential functions using multiple representations.

I Can Statements

  • I can formulate comparisons among linear, quadratic, and exponential functions using rates, differences, ratios, and graph features.
  • I can use tables, graphs, equations, and situations to distinguish additive, quadratic, and multiplicative patterns.
  • I can critique claims about function families using evidence from multiple representations.

Key Vocabulary / Notation

  • constant difference
  • second difference
  • constant ratio
  • linear
  • quadratic
  • exponential

Key Representations

  • Tables showing first differences, second differences, and ratios
  • Linear, quadratic, and exponential graphs
  • Equations for multiple function families
  • Context descriptions of change over time
  • Feature comparisons such as intercepts, growth patterns, and turning points

Common Misconceptions / Failure Points

  • Using only graph shape instead of differences, ratios, and equation structure.
  • Confusing constant second differences with constant ratios.

Modeling / Application / Practice Opportunities

  • Choose a function family for a data pattern using evidence
  • Contrast additive growth with multiplicative growth
  • Analyze when an exponential model eventually exceeds a linear or quadratic model
  • Revise a model choice after checking multiple representations

Spiral Planning

Intro: Compare linear, quadratic, and exponential functions using multiple representations.

Review: Compare factoring, completing the square, and the quadratic formula and select efficient solution methods.

Mastery: Compare standard, vertex, and factored forms of quadratic functions and determine which form best reveals key features.

Section 7.5: Exponential Modeling with Data

Learning Target: Students will create and analyze exponential models using real-world data.

I Can Statements

  • I can construct exponential models from real-world data using an initial value and a growth or decay factor.
  • I can extend exponential models to make predictions and interpret results in context.
  • I can assess model fit and limitations when exponential data do not follow a perfect pattern.

Key Vocabulary / Notation

  • exponential model
  • initial value
  • growth/decay factor
  • prediction
  • model fit

Key Representations

  • Real-world data tables
  • Scatter plots with exponential trends
  • Exponential equations built from data
  • Predictions and residual reasoning
  • Contextual interpretations of parameters and outputs

Common Misconceptions / Failure Points

  • Assuming noisy data have a perfect constant ratio.
  • Making predictions without considering the meaningful domain or model limitations.

Modeling / Application / Practice Opportunities

  • Model viral sharing, population change, or compound growth
  • Model decay situations such as medicine concentration or depreciation
  • Use data to estimate a growth or decay factor
  • Check whether a model prediction is reasonable for the context

Spiral Planning

Intro: Create and analyze exponential models using real-world data.

Review: Use quadratic functions to model real-world situations and interpret maximums, minimums, and intercepts.

Mastery: Factor quadratic trinomials using patterns, products, sums, and structure.

  • Create and analyze exponential models using real-world data.

Mastery Goals

U7-MG01

Mastery Goal: Factor polynomial expressions by identifying a greatest common factor and use multiplication to verify equivalent forms.

Supporting Learning / Prerequisites

  • I can construct equivalent polynomial expressions by factoring out a greatest common factor.
  • I can apply structure to rewrite polynomial expressions in a more useful form.
  • I can determine whether a rewritten expression is reasonable by checking common factors and equivalent products.

Key Representations

  • Polynomial expressions in expanded form
  • Factored expressions with greatest common factors
  • Area models for common-factor structure
  • Tables of term coefficients and variable powers
  • Verbal contexts involving shared quantities

Recurring Practices

  • Use polynomial structure to factor efficiently
  • Connect symbolic factors to graphical zeros
  • Choose quadratic forms strategically

MEETING evidence should demonstrate: Independently demonstrates the goal across more than one appropriate representation or context, with accurate work, sufficient interpretation, and a defensible connection back to the original problem or situation.

Common Evidence Weaknesses / Misconceptions

  • Factoring out a quantity that is not common to every term.
  • Failing to verify the factored form by multiplication.
U7-MG02

Mastery Goal: Factor quadratic trinomials and special polynomial patterns by using product-sum reasoning and recognizable structure.

Supporting Learning / Prerequisites

  • I can build factored forms of quadratic trinomials using product-sum relationships.
  • I can use patterns in coefficients and constants to factor quadratic trinomials.
  • I can predict missing factors or terms by extending product-sum reasoning.
  • I can design a strategy for factoring special polynomial patterns.
  • I can apply difference-of-squares and perfect-square-trinomial patterns.
  • I can assess whether a polynomial fits a special factoring pattern before rewriting it.

Key Representations

  • Standard-form quadratic trinomials
  • Factored binomial products
  • Product-sum tables
  • Algebra tiles or area models
  • Partial-factor work showing structure
  • Difference-of-squares expressions
  • Perfect-square trinomials
  • Squared binomial forms
  • Pattern templates using variables and coefficients
  • Visual square and rectangle models

Recurring Practices

  • Use polynomial structure to factor efficiently
  • Connect symbolic factors to graphical zeros
  • Choose quadratic forms strategically

MEETING evidence should demonstrate: Independently demonstrates the goal across more than one appropriate representation or context, with accurate work, sufficient interpretation, and a defensible connection back to the original problem or situation.

Common Evidence Weaknesses / Misconceptions

  • Using factor pairs that multiply correctly but do not produce the required middle term.

  • Zeros and x-intercepts
  • Quadratic graphs

Recurring Practices

  • Use polynomial structure to factor efficiently
  • Connect symbolic factors to graphical zeros
  • Choose quadratic forms strategically
