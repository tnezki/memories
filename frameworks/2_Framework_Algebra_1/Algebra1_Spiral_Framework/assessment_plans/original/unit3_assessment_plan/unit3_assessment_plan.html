Section Outline

Section 3.1: Graphing and Elimination

Learning Target: Students will solve systems graphically and by elimination while interpreting the meaning of different solution types.

I Can Statements

  • I can construct graphical representations of systems and connect intersection points to solutions.
  • I can use elimination to solve systems and interpret the solution type.
  • I can determine whether a system has one solution, no solution, or infinitely many solutions from algebraic and graphical evidence.

Key Vocabulary / Notation

  • system of equations
  • intersection
  • elimination
  • one/no/infinitely many solutions

Key Representations

  • Graphs of two linear equations
  • Tables of paired values
  • Standard form equations
  • Intersection points
  • Solution-type statements

Common Misconceptions / Failure Points

  • Assuming every system has exactly one solution.
  • Eliminating terms without applying equivalent operations to an entire equation.

Modeling / Application / Practice Opportunities

  • Represent two competing plans as a system of equations
  • Interpret an intersection as a break-even point
  • Connect elimination steps to equivalent constraints
  • Use solution types to interpret whether a situation is possible, impossible, or always true

Spiral Planning

Intro: Solve systems graphically and by elimination while interpreting the meaning of different solution types.

Review: Graph linear functions and interpret key features.

Mastery: Connect tables, graphs, equations, and contexts that represent the same relationship.

Section 3.2: Solving Systems by Substitution

Learning Target: Students will solve systems using substitution and choose efficient forms for solving.

I Can Statements

  • I can formulate a substitution plan when one equation is already written in an efficient form.
  • I can apply substitution to solve systems and interpret the ordered-pair solution.
  • I can assess which algebraic method is more efficient for a given system.

Key Vocabulary / Notation

  • substitution
  • system
  • ordered-pair solution
  • equivalent equation
  • solution method

Key Representations

  • Slope-intercept form equations
  • Equations solved for one variable
  • Substitution work
  • Ordered-pair solutions
  • Contextual solution statements

Common Misconceptions / Failure Points

  • Substituting into only part of an expression or equation.
  • Failing to interpret the ordered pair in the original system.

Modeling / Application / Practice Opportunities

  • Represent one quantity in terms of another before solving
  • Use substitution to connect two related constraints
  • Interpret a solution in a two-variable situation
  • Select an efficient solving pathway based on equation structure

Spiral Planning

Intro: Solve systems using substitution and choose efficient forms for solving.

Review: Write linear equations from graphs, tables, and situations.

Mastery: Interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

Section 3.3: Writing and Solving Systems from Situations

Learning Target: Students will create and solve systems that model real-world situations.

I Can Statements

  • I can build a system of equations that represents two constraints in a situation.
  • I can predict the meaning of a solution before solving from the context and variables.
  • I can design a solution pathway that connects equations, calculations, and a contextual conclusion.

Key Vocabulary / Notation

  • constraint
  • system
  • variable definition
  • solution
  • break-even

Key Representations

  • Verbal situations
  • Variable definitions
  • Systems of equations
  • Graphs or tables for checking
  • Contextual conclusions

Common Misconceptions / Failure Points

  • Writing two equations that describe the same constraint instead of two distinct constraints.
  • Defining variables inconsistently with the equations or final interpretation.

Modeling / Application / Practice Opportunities

  • Create a system from ticket, mixture, cost, or comparison situations
  • Choose variables that make the constraints clear
  • Interpret both coordinates of the solution in context
  • Check whether a solution is reasonable for the situation

Spiral Planning

Intro: Create and solve systems that model real-world situations.

Review: Use linear models to represent and interpret real-world data.

Mastery: Write, solve, and interpret equations that model situations.

Section 3.4: Graphing Linear Inequalities

Learning Target: Students will graph and interpret linear inequalities.

I Can Statements

  • I can construct a boundary line and shaded region for a linear inequality.
  • I can use test points to interpret which region satisfies an inequality.
  • I can critique a graph of a linear inequality using the boundary, shading, and solution region.

Key Vocabulary / Notation

  • linear inequality
  • boundary line
  • solid/dashed line
  • test point
  • half-plane

Key Representations

  • Linear inequalities
  • Solid and dashed boundary lines
  • Shaded half-planes
  • Test points
  • Solution-region statements

Common Misconceptions / Failure Points

  • Using a solid boundary for a strict inequality or dashed boundary for an inclusive inequality.
  • Shading by memorized direction instead of testing a point.

Modeling / Application / Practice Opportunities

  • Represent limits such as budgets, minimums, and maximums
  • Use a test point to check a feasible region
  • Interpret boundary inclusion in context
  • Connect inequality symbols to shaded solution regions

Spiral Planning

Intro: Graph and interpret linear inequalities.

Review: Interpret slope as a measure of constant rate of change.

Mastery: Recognize common function families from graphs, tables, equations, and contexts.

Section 3.5: Linear Systems of Inequalities

Learning Target: Students will analyze and interpret systems of linear inequalities.

I Can Statements

  • I can formulate a system of inequalities that represents multiple constraints.
  • I can extend graphing strategies to represent overlapping solution regions.
  • I can apply feasible-region reasoning to interpret possible solutions in context.

Key Vocabulary / Notation

  • system of inequalities
  • feasible region
  • constraint
  • boundary
  • solution region

Key Representations

  • Systems of inequalities
  • Multiple boundary lines
  • Overlapping shaded regions
  • Feasible points
  • Constraint-based contexts

Common Misconceptions / Failure Points

  • Treating any point satisfying one inequality as feasible for the system.
  • Overlooking that the feasible region is the overlap of all constraints.

Modeling / Application / Practice Opportunities

  • Represent real-world restrictions with more than one inequality
  • Interpret feasible and non-feasible points in context
  • Use overlapping regions to model choices under constraints
  • Connect graphical solutions to decision-making situations

Spiral Planning

Intro: Analyze and interpret systems of linear inequalities.

Review: Analyze and compare linear relationships using multiple representations.

Mastery: Interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

Mastery Goals

Mastery Goal: Connect tables, graphs, equations, and contexts that represent the same relationship and use evidence to determine whether representations agree.

Supporting Learning / Prerequisites

  • I can construct a table, graph, equation, or context from another representation of the same relationship.
  • I can use features in one representation to work with a related table, graph, equation, or context.
  • I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

Key Representations

  • Tables of input-output pairs
  • Coordinate graphs
  • Equations and rules
  • Verbal contexts
  • Connections among multiple representations

Recurring Practices

  • Connect multiple representations
  • Use structure when rewriting expressions
  • Model with equations and interpret solutions

MEETING evidence should demonstrate: Independently demonstrates the goal across more than one appropriate representation or context, with accurate work, sufficient interpretation, and a defensible connection back to the original problem or situation.

  • Matching representations by visual appearance while ignoring scale or values.
  • Changing a table or graph without preserving the same ordered pairs or relationship.
U3-MG02

Mastery Goal: Interpret functions through inputs, outputs, rules, and family features, and distinguish common function families using representation evidence.

Supporting Learning / Prerequisites

  • I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.
  • I can apply an input-output rule to generate missing values and ordered pairs.
  • I can assess whether a rule gives one output for each input in a situation.
  • I can design examples of linear, quadratic, exponential, and absolute value relationships using more than one representation.
  • I can extend patterns in tables, graphs, equations, and contexts to work with common function families.
  • I can critique a proposed function family choice using evidence from rate of change, shape, or equation structure.

Key Representations

  • Input-output tables
  • Function rules
  • Ordered pairs
  • Mapping diagrams
  • Context-based input and output quantities
  • Linear patterns
  • Quadratic patterns
  • Exponential growth and decay patterns
  • Absolute value patterns
  • Family features across representations

Recurring Practices

  • Connect multiple representations
  • Use structure when rewriting expressions
  • Model with equations and interpret solutions

MEETING evidence should demonstrate: Independently demonstrates the goal across more than one appropriate representation or context, with accurate work, sufficient interpretation, and a defensible connection back to the original problem or situation.

Common Evidence Weaknesses / Misconceptions
