Section Outline

Section 8.1: Selecting Appropriate Models

Learning Target: Students will determine whether a situation is best modeled by a linear, quadratic, or exponential function.

I Can Statements

  • I can construct evidence from tables, graphs, and contexts to choose a linear, quadratic, or exponential model.
  • I can apply rate, second-difference, and ratio patterns to select an appropriate function family.
  • I can determine whether a chosen model is reasonable for a situation and its data pattern.

Key Vocabulary / Notation

  • model
  • linear
  • quadratic
  • exponential
  • difference/ratio pattern

Key Representations

  • Linear, quadratic, and exponential graphs
  • Tables showing first differences, second differences, and ratios
  • Equations in familiar function forms
  • Context descriptions with quantities and constraints
  • Verbal claims about growth, change, and turning behavior

Common Misconceptions / Failure Points

  • Choosing a model from one or two points without checking the pattern of change.
  • Using additive evidence to justify an exponential model or ratio evidence to justify a linear model.

Modeling / Application / Practice Opportunities

  • Sort situations by evidence rather than by surface words.
  • Choose a model for a data table and state the feature that supports the choice.
  • Revise a model choice when a new data point changes the pattern.
  • Connect real-world behavior to graph shape and equation structure.

Spiral Planning

Intro: Determine whether a situation is best modeled by a linear, quadratic, or exponential function.

Review: Compare linear, quadratic, and exponential functions using multiple representations.

Mastery: Compare factoring, completing the square, and the quadratic formula and select efficient solution methods.

Section 8.2: Transformations Across Function Families

Learning Target: Students will analyze transformations across multiple function families.

I Can Statements

  • I can build transformed function rules from parent functions across linear, quadratic, exponential, and absolute value families.
  • I can use key points and key features to graph transformations across multiple function families.
  • I can formulate a transformation description that connects parameter changes to key point shifts across function families.

Key Vocabulary / Notation

  • parent function
  • parameter
  • translation
  • reflection
  • stretch/compression

Key Representations

  • Parent function graphs
  • Transformed equations such as $f(x)+k$, $f(x-h)$, and $af(x)$
  • Key points before and after transformations
  • Feature tables for intercepts, vertex, asymptote, and direction
  • Context descriptions involving shifted or scaled models

Common Misconceptions / Failure Points

  • Applying a transformation rule as though it behaves identically in every algebraic position.
  • Moving one key feature without transforming the rest of the function consistently.

Modeling / Application / Practice Opportunities

  • Move key points to create a transformed model for a situation.
  • Predict how changing a parameter changes a graph and its meaning.
  • Use transformations to adapt a familiar model to a new context.
  • Check whether a transformed equation preserves important constraints.

Spiral Planning

Intro: Analyze transformations across multiple function families.

Review: Graph exponential functions and analyze key features.

Mastery: Solve quadratic equations by completing the square and connect the process to vertex form.

Section 8.3: Absolute Value Functions and Piecewise Thinking

Learning Target: Students will analyze and model situations involving absolute value functions.

I Can Statements

  • I can design an absolute value or piecewise representation for situations with distance, change in direction, or two-part behavior.
  • I can apply key features of absolute value graphs to interpret vertex, intercepts, and rate of change.
  • I can predict outputs and intervals from absolute value and piecewise rules in context.

Key Vocabulary / Notation

  • absolute value
  • piecewise function
  • vertex
  • interval
  • rate of change

Key Representations

  • Absolute value graphs with a vertex
  • Equations using $|x-h|$ structure
  • Piecewise rules and interval restrictions
  • Tables showing symmetry or two rates
  • Contexts involving distance from a target or changing direction

Common Misconceptions / Failure Points

  • Treating absolute value as ordinary linear behavior across the vertex.
  • Ignoring interval conditions in a piecewise rule.

Modeling / Application / Practice Opportunities

  • Model distance from a target value using absolute value.
  • Create a piecewise rule for a situation with different rates over intervals.
  • Connect a vertex to a minimum distance or turning point in context.
  • Use domain restrictions to make a model fit the situation.

Spiral Planning

Intro: Analyze and model situations involving absolute value functions.

Review: Identify exponential relationships from patterns, tables, graphs, and situations.

Mastery: Solve quadratic equations using factored form and interpret solutions.

Section 8.4: Modeling Investigation

Learning Target: Students will create and analyze mathematical models using real-world data.

I Can Statements

  • I can formulate a mathematical model from real-world data and state the assumptions used.
  • I can extend a model to make predictions within a reasonable domain.
  • I can critique how well a model fits data, constraints, and the situation being studied.

Key Vocabulary / Notation

  • model
  • assumption
  • domain
  • constraint
  • prediction

Key Representations

  • Real-world data tables
  • Scatterplots or plotted coordinate pairs
  • Candidate linear, quadratic, exponential, or absolute value models
  • Residual-style observations about overprediction and underprediction
  • Written interpretation of model parameters and limits

Common Misconceptions / Failure Points

  • Reporting a model without stating assumptions or a meaningful domain.
  • Treating a model prediction as exact even when data or constraints show limitations.

Modeling / Application / Practice Opportunities

  • Choose a model for a small data set and defend the choice with evidence.
  • Use a model to make and check a prediction.
  • Revise a model when the data or domain makes the first model weak.
  • Interpret parameters and outputs in the original context.

Spiral Planning

Intro: Create and analyze mathematical models using real-world data.

Review: Create and analyze exponential models using real-world data.

Mastery: Use quadratic functions to model real-world situations and interpret maximums, minimums, and intercepts.

Section 8.5: Function Synthesis and Capstone Analysis

Learning Target: Students will synthesize understanding of function families and representations to solve complex problems.

I Can Statements

  • I can construct a solution pathway that connects equations, graphs, tables, and contexts across function families.
  • I can use multiple representations to solve complex function problems and interpret results.
  • I can assess competing solution strategies and choose the representation that best supports the conclusion.

Key Vocabulary / Notation

  • function family
  • representation
  • model
  • key feature
  • strategy

Key Representations

  • Multiple function-family graphs
  • Tables, equations, and contexts used together
  • Function-feature summaries
  • Student-generated model comparisons
  • Written reasoning about model choice and solution meaning

Common Misconceptions / Failure Points

  • Choosing a representation by habit rather than by the information needed.
  • Combining results from different representations without checking that they describe the same relationship.

Modeling / Application / Practice Opportunities

  • Select efficient representations for multi-step function tasks.
  • Synthesize evidence from several function families to solve a problem.
  • Revise a model or solution when a representation reveals a conflict.
  • Communicate why a chosen model or strategy fits the problem conditions.

Intro: Synthesize understanding of function families and representations to solve complex problems.

Review: Write exponential equations from tables, graphs, and situations.

Mastery Goal: Solve quadratic equations by factoring and the zero product property and interpret solutions in graphs and contexts.

Supporting Learning / Prerequisites

  • I can construct factored quadratic equations from given zeros, intercepts, or contextual constraints.
  • I can apply the zero product property to solve quadratic equations in factored form.
  • I can determine whether solutions make sense in relation to a graph or context.

Key Representations

  • Factored quadratic equations
  • Zeros and $x$-intercepts
  • Tables of values
  • Graphs of parabolas
  • Contextual solution statements

Recurring Practices

  • Choose and justify quadratic solution methods
  • Connect equations, graph features, and solution types
  • Model and interpret optimization situations

  • Keeping factor values instead of solving each factor equation for the variable.
