Algebra 1 Mastery Spiral Mapping - Framework v7

Canonical mastery goals, exact Intro → Review → Mastery pipeline, separate Warm-Up fluency track, and rolling Exit Ticket reassessment.

Current design rule: Keep the eight Algebra 1 units and five-section structure. A section can carry three different strands at once: current-unit Intro, prior-unit Review, and older Mastery. The strands are placed where they make the most instructional sense; section numbers do not have to line up mechanically across units.

Pipeline rule: Intro in Unit N becomes Review in Unit N+1 and Mastery in Unit N+2. Also, Review in Unit N becomes Mastery in Unit N+1. The goal title and description stay canonical as the goal moves through the spiral; the stage changes the support and evidence demand, not the identity of the goal.
Intro
First learn the idea with support.
Review
Use the same skill again with less support, a new representation, or a slightly harder context.
Mastery
Use the skill independently; choose a representation or method when needed and explain when the task requires it.

Separate Warm-Up Fluency Track

Equation solving stays mostly outside the unit-section mastery map. Warm-Up Question 1 builds it through daily repetition:

one-step -> mixed one-step -> two-step -> combining like terms -> distribution -> multi-step -> variables on both sides -> rational coefficients -> cumulative mixed solving

Older types continue after harder types are introduced. Near the end of Algebra 1, solving can be assessed as its own cumulative proficiency.

Warm-Up Question 3 carries recurring integer/fraction work, distribution, combining like terms, exponent-law fluency, and other foundational prerequisites. Fraction/integer directions encourage trying without a calculator first while clearly allowing calculator use if needed.

Official Exit Ticket rhythm: Normal section = 2 new current-Mastery I Can evidence opportunities + 2 fresh parallel reassessments from the previous section. The chain continues across Unit boundaries. U1.1 is the only opening exception and its exact four-slot pattern remains intentionally open for the Bank/Exit map. Intro/Review are checked formatively elsewhere, with targeted reteach/recovery checks generated when needed.
Unit 1 - Mastery Window

Mastery-Window Essential Standard: Use graphs, slope, rules, and expressions as basic tools for Algebra 1.
U1-MG01
Coordinate-Plane Graphs

Mastery Goal: Use ordered pairs, axes, scales, and intercepts to read and create graphs.

I Can Statements

  • Plot and read ordered pairs.
  • Use the x- and y-axes correctly.
  • Read a graph using its scale.
  • Identify and interpret intercepts when they are shown.
U1-MG02
Slope in Four Views

Mastery Goal: Find slope or rate of change from a graph, table, equation, or context.

I Can Statements

  • Find slope from a graph.
  • Find slope from a table.
  • Find slope from an equation.
  • Find and interpret rate of change from a context.
U1-MG03
Evaluate Expressions

Mastery Goal: Evaluate numerical and algebraic expressions using substitution and order of operations.

I Can Statements

  • Substitute a value for a variable.
  • Use order of operations correctly.
  • Evaluate expressions with positive and negative numbers.
  • Check whether an answer is reasonable.
U1-MG04
Input / Output Rules

Mastery Goal: Use an input-output rule to find values, ordered pairs, and patterns.

I Can Statements

  • Use input/output language and ordered pairs.
  • Use a rule to find an output from an input.
  • Find a missing input or output when enough information is given.
  • Use a rule to build or extend a table.
Unit 2 - Mastery Window
Source: Prior-course readiness   |   Review: Unit 1   ->   Mastery: Unit 2
Mastery-Window Essential Standard: Compare relationships, recognize functions, move between representations, and solve simple inequalities.
U2-MG01
Compare Relationships

Mastery Goal: Compare relationships across graphs, tables, equations, and contexts using clear evidence.

I Can Statements

  • Compare two relationships shown in different representations.
  • Use values, rates, starting values, or patterns as evidence.
  • Explain which relationship is greater, faster, or starts higher when the question asks.
  • Support a comparison with information from the representations.
U2-MG02
One-Step Inequalities

Mastery Goal: Solve one-step inequalities and show the solution on a number line.

I Can Statements

  • Solve a one-step inequality.
  • Reverse the inequality sign when multiplying or dividing by a negative number.
  • Use an open or closed circle correctly.
  • Shade the correct direction on a number line.
U2-MG03
Function or Not a Function

Mastery Goal: Use inputs and outputs to decide whether a relationship is a function.

I Can Statements

  • Decide whether a table is a function.
  • Decide whether ordered pairs or a mapping are a function.
  • Use a graph to decide whether each input has only one output.
  • Explain why a relationship is or is not a function.
U2-MG04
Move Between Representations

Mastery Goal: Create a new representation of a relationship and check that the important values and pattern stay the same.

I Can Statements

  • Make a graph from a table.
  • Make a table from a rule or equation.
  • Use a context to make a table, graph, or rule when enough information is given.
  • Check matching inputs, outputs, and patterns to make sure the representations agree.
