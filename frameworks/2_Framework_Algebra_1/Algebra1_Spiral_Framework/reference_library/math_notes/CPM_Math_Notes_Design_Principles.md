# CPM-Informed Algebra Math Notes Design Principles

Purpose: calibrate the *role* and depth of Algebra Math Notes from the teacher-supplied CPM Algebra site. This is a design summary, not copied textbook prose.

## What strong CPM-style Math Notes do

- Function as a durable **Methods and Meanings** reference, not a tiny reminder label.
- Name/define important ideas and notation, then explain what they mean mathematically.
- Connect symbolic rules to visual or numerical representations.
- Include a compact worked/reference example when it helps students reread independently.
- Capture edge cases or distinctions that students need to remember (for example, how a feature changes across different graph cases).
- Emphasize why a representation/method works, not only a step list.

## Multiple-representation opportunity

The CPM Algebra source repeatedly treats a situation/context, table, equation, and graph as connected descriptions of one relationship. When an Algebra I-can is explicitly about representations, a high-value Math Notes block should actively consider showing all four forms together around one coherent example rather than merely listing their names.

Suggested compact structure:

| Graph | Equation |
|---|---|
| actual graph with one or two key features labeled/identified | actual equation with the same features interpreted |
| **Table** | **Context** |
| actual values that fit the same relationship | a concise real quantity interpretation that fits the same relationship |

The labels/order can vary. The important requirement is that the four artifacts truly represent the same mathematics and the notes explain the connection.

## Abundance

Useful Math Notes abundance is desirable. A section may contain several reference blocks if they serve distinct high-value ideas. The teacher can skip or move through them quickly. Do not add filler, but do not underbuild simply to shorten the document.
