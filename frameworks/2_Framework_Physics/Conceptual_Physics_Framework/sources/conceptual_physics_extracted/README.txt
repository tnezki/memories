Conceptual Physics section extraction package

This package uses a shared CSS folder at the same level as the section folders.

Structure:
  css/styles.css
  cp_section_1_1/index.html
  cp_section_1_1/images/
  cp_section_1_1/source/
  cp_section_1_2/index.html
  cp_section_1_2/images/
  cp_section_1_2/source/

Each section HTML links to ../css/styles.css.
Do not place duplicate CSS folders inside individual section folders.
