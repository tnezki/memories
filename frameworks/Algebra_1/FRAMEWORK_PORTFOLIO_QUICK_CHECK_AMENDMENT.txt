ALGEBRA 1 FRAMEWORK AMENDMENT - PORTFOLIO / QUICK CHECK
========================================================
STATUS: CURRENT
SCOPE: recurring short-evidence architecture, Portfolio status/rollup, evidence-source mapping, Bank practice routing, and recurring Portfolio presentation.

This amendment supersedes conflicting legacy Exit Ticket/Portfolio mechanics in the older Framework/Assessment Plan boilerplate while preserving exact Unit learning content.

1. CURRENT NAMES
- Common short evidence pulse: Quick Check.
- Prior name Exit Ticket is retired for current Algebra execution.
- Larger personalized six-question event: Checkpoint.
Legacy printed scans may be matched by old names as aliases, but current reports/data use Quick Check.

2. PORTFOLIO STATUS / ROLLUP
I Can: No Evidence / Developing / Mastered / Transfer.
Mastered normally requires at least two independent convincing demonstrations, normally from different opportunities and with one reasonably current demonstration. A rich artifact may suffice only when it genuinely contains multiple independent demonstrations. Teacher judgment resolves mixed/unusual cases. One later weak event does not automatically erase mastery.
A Mastery Goal is demonstrated at 2 of 4 I Cans Mastered or Transfer.
Unit/PowerSchool: I=0-1 MG, C=2, B=3, A=4, A+=4 plus meaningful transfer/extension. PowerSchool is one living Unit assignment; current status replaces prior status rather than averaging attempts.

3. QUICK CHECK SLOTS
Use curriculum/quick_check_slot_map.json. Reassessment targets are selected from live Portfolio need, not frozen months ahead.
Core sentence: The curriculum predicts the evidence slots; the Portfolio determines the just-in-time reassessment targets; the teacher approves the actual questions.

4. EVIDENCE-SOURCE MAPPING - HARD
For known recurring sources, use current maps under curriculum/quick_check_source_maps before interpreting handwriting.
Map the CLEAN TASK first, then judge the response.
Question number is not authority when parallel versions shuffle order.
A task may support more than one separately judgeable I Can when the task genuinely asks both evidence jobs. Those target judgments still share the same source opportunity unless independence is explicitly defensible.
Repeated prompts for the same I Can on one Quick Check are not automatically independent. When a source map specifies aggregation, synthesize one source-level I Can judgment while preserving useful item observations internally.

For Unit 1 Section 1 Quick Check 01 specifically, the movement-from-origin endpoint task provides separately judgeable IC01 and IC02 evidence; the two intercept prompts combine into one IC04 source-level judgment. Use the registered source map.

5. BANK ROLE
Bank = Mastery Goal -> exact I Can -> three materially different families. Student view is student.html grouped MG -> I Can -> A/B/C. Portfolio prints exact MG + I Can + recommended family and links to student.html#<family_id>. Direct links must visibly mark the exact target on desktop/mobile.

6. PORTFOLIO REPORT FIDELITY - HARD
The registered Portfolio template contract, HTML templates, and CSS own the recurring student/teacher report presentation. They own fixed headings, reflection prompts, table columns, card anatomy, category labels, and layout—not merely colors.
Job 18 fills data slots. It may not rewrite the report into a new feedback system, change reflection prompts, invent new teacher name buckets, rename the approved pages, or add a third tracker page.
Intentional redesign requires teacher approval and promotion of a new template version.

Student packet = exactly two pages: Current Progress Report; Unit Evidence Picture.
Teacher summary = combined 2x2 latest-evidence page, period 2x2 pages, final combined longitudinal Portfolio Evidence Sort.
The approved recent-evidence table may show Convincing/Partial/Limited/Unusable as compact evidence descriptors; other internal mechanics remain hidden.
Teacher name lists use first name + last initial when compact; period is a group header, not repeated after every name.

7. LEGACY RETIREMENTS
Retired for current execution: fixed Exit Ticket chain; active exit_evidence_map routing; Not Yet/Approaching/Meeting/Exceeding as Algebra Portfolio labels; Ticket A/B as current source naming; ad hoc recurring report redesign.

END - ALGEBRA 1 FRAMEWORK AMENDMENT
