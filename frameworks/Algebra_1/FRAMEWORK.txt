2. EXACT MASTERY SPIRAL + RECURRENCE — HARD
================================================================

FORMAL STAGE PIPELINE
Intro in Unit N -> Review in Unit N+1 -> Mastery in Unit N+2.
Review in Unit N -> Mastery in Unit N+1.

Unit 1 and Unit 2 are opening-year exceptions because there is not yet enough Algebra history for the same amount of true spacing available later in the course.

CANONICAL GOAL IDENTITY
If a goal appears as Review and later Mastery, keep the exact goal ID/title/description. Stage changes support and evidence demand:
  Intro = first learn the idea with support.
  Review = same skill again with less support, a new representation, or a slightly harder context.
  Mastery = independent use; choose representation/method when needed and explain when the task requires it.

FORMAL STAGE PLACEMENT IS NOT THE WHOLE SPIRAL
The course also uses a planned recurrence layer so a goal/I Can can reappear between its formal Intro, Review, and Mastery sections.

Canonical recurrence map:
  curriculum/mastery_recurrence_map.json
Teacher/dashboard view:
  curriculum/mastery_recurrence_map.html

RECURRENCE TARGET
- Unit 1 mastery goals: opening-course exception; approximately 3 meaningful section appearances is normal.
- Unit 2 mastery goals: transition exception; approximately 6 meaningful section appearances is normal.
- Unit 3+ mastery goals: aim for approximately 9 meaningful section appearances across the full Intro -> Review -> Mastery cycle.
- 3 Intro-stage + 3 Review-stage + 3 Mastery-stage appearances is the clean default when the formal section timing allows it.
- Late-introduced goals may use a nearby equivalent distribution such as 2+3+4 or 1+4+4 rather than pretending students practiced content before it was taught.

An appearance can be small: one mixed-practice question can create a section appearance. The goal is spacing and return, not a large block every time.

WARM-UPS ARE AN EXTRA LAYER
Warm-Up Q3/Q4 retrievals are intentionally additional exposures and do NOT inflate the section-appearance count in mastery_recurrence_map.json.

3. ALGEBRA WARM-UP ARCHITECTURE — HARD
================================================================

Every Unit has exactly 20 numbered Warm-Up sets:
  Warm-Up 1 ... Warm-Up 20
They are NOT numbered or owned by section.

Every Warm-Up has four stable jobs:

Q1 · SOLVE / EQUATION FLUENCY
A compact solving mini-set. Older solve types remain mixed after newer types appear. Difficulty comes from fluent execution and method choice, not arbitrary coefficient inflation.

COURSE-LONG SOLVE CEILINGS
Unit 1: one-step fluency -> simple two-step near the end.
Unit 2: two-step -> combine like terms -> distribution -> one-sided multi-step; very simple variables-on-both-sides preview late only.
Unit 3: complete linear-equation progression, including variables on both sides and reasonable rational/fraction coefficients.
Units 4-5: maintain full linear solving without uglier-for-its-own-sake arithmetic.
Unit 6: maintain linear retrieval; add quadratic solve methods only after instruction.
Units 7-8: cumulative linear/quadratic solving and method choice; no logarithmic/exponential-equation solving requirement.

Q2 · DIAMOND / FACTORING PATTERN
Number product-sum -> signed integer factor pairs -> trinomial structure -> special factoring patterns -> maintenance.

Q3 · PLANNED I CAN RETRIEVAL
Q4 · PLANNED I CAN RETRIEVAL
Q3/Q4 use approved Bank family architecture when available and display the exact canonical learning label:
  <I CAN CODE> — <FULL EXACT I CAN STATEMENT>

RETRIEVAL PREFERENCE
- Unit 1: readiness / foundational work plus already-taught Algebra only when useful; do not fake a prior Unit.
- Unit 2: favor Unit 1 I Cans; readiness may still fill gaps.
- Unit 3+: Q3 favors the previous Unit; Q4 favors two Units back plus deliberately chosen longer-range retrieval.
- Same-current-Unit retrieval is the exception because Practice/Activities already handle most within-Unit recurrence.

The exact 20-set progression and deterministic retrieval rotation are owned by:
  curriculum/warmup_progression_map.json

Algebra Warm-Ups remain exempt from universal Question Structure when the stable fluency/retrieval job does not need it.

4. QUICK CHECK ARCHITECTURE — HARD
================================================================

Current Algebra short evidence pulse is named QUICK CHECK. "Exit Ticket" is retired current terminology.

There is ONE four-question Quick Check per section = 20 source questions per Unit.

The teacher approves four source question architectures/anchors for each section through the Quick Check builder. Current Portfolio need may guide reassessment recommendations; teacher selection is final.

FOUR PRINT VERSIONS A-D
Each section prints four comparable versions from the same four approved source architectures.
Normal variation is:
- safe number/value/data swaps permitted by the family;
- deterministic question-order scrambling;
- answer-choice scrambling when applicable.
Do NOT invent four materially different architectures merely to create anti-copy versions.

Therefore:
  20 source questions per Unit
  -> 80 rendered A-D question instances
but only the 20 source questions/architectures count as distinct source design decisions.

Every Quick Check problem visibly prints exact I Can code + full exact I Can statement.

Current slot authority:
  curriculum/quick_check_slot_map.json
Current source-map rules:
  contracts/portfolio_quick_check_policy.json

Retired active routing:
  the former fixed exit_evidence_map chain.
Do not recreate or consult that retired map for current Algebra execution.

6. BANK STRATEGY — QUALITY FAMILY POOL / OFFLINE-READY SOURCE
================================================================

Canonical Bank organization:
  Mastery Goal -> exact I Can -> high-quality Question Families.

NO FIXED THREE-FAMILY LIMIT
The retired A/B/C-only requirement is no longer current Algebra policy.

QUALITY TARGET
- Healthy target: about 8-10 materially different high-quality families per I Can.
- A narrower I Can may stop around 6 when additional families would be filler.
- An I Can may exceed 10 when an additional family genuinely adds a worthwhile student action, representation, misconception route, inverse direction, context/application, or transfer job.
- Quality is the gate; letters do not carry difficulty/stage meaning.

Family IDs/labels remain stable once published. Existing A/B/C labels remain valid IDs; D, E, F... are normal additions. A letter is not an Intro/Review/Mastery badge and does not by itself imply core/alternate/reasoning.

FAMILY DISTINCTNESS
Number/name/context swaps alone do not create a new family. A new family must materially change how the I Can is demonstrated.

OFFLINE / DETERMINISTIC FAMILY CAPACITY
When mathematically safe, a family should carry enough executable metadata for local scripts to instantiate fresh reproducible questions:
- invariant/evidence job;
- parameter definitions and natural ranges;
- constraints;
- answer-generation rule;
- representation/table/graph generation rule;
- allowed inverse/direction changes;
- misconception/distractor rules when relevant;
- allowed contexts/units when relevant;
- allowed and forbidden variation axes;
- reproducible seed support;
- a small set of validated test seeds/instances.

Some rich families may remain static/AI-authored. Do not sacrifice quality to force full automation.

PRIMARY BANK CONSUMERS
- Notes Examples / You Try Its
- Practice / Extra Practice
- Activities
- Quick Checks
- Student/Teacher Practice Builder
- Personalized Checkpoints
- Unit Review
- Secure Summative architecture/forms

NOT REQUIRED IN THE INITIAL UNIT BUILD
CYU, Tarsia, Blooket/game exports, and similar optional generators are standalone teacher tools. They may use approved Bank families later without driving Bank size or initial Unit-build question counts.

WTC is retired from current Algebra architecture.

8. PRACTICE + ACTIVITY TARGET PLANS — HARD
================================================================

Normal classroom question sets are shorter and more cumulative than the retired 24-question 8/8/8 model.

DEFAULT SET SIZE
12 questions is normal.
Teacher/builder may use 12-16 when the section needs more room.

Each set normally contains:
- 4 CURRENT INTRO questions, using a useful variety of the four current Intro I Cans/families;
- 8-12 RECURRENCE questions selected from multiple Review/Mastery goals/I Cans according to mastery_recurrence_map.json.

The recurrence portion must NOT all come from one current Mastery Goal merely because that goal is formally assigned to the section. Current Mastery normally gets meaningful emphasis, but recent mastery, formal Review, and spaced prior goals can share the remaining slots.

PAIR A — SAME TARGET MIX
- Practice 1
- Activity Set 1
These use the same selected I Can/count plan but fresh families/instances.

PAIR B — SECOND TARGET MIX WITH INTENTIONAL OVERLAP
- Extra Practice
- Activity Set 2
These use a second selected I Can/count plan. High-priority recurrence targets should overlap with Pair A, while some counts/targets are rebalanced to broaden spacing.

ACTIVITY STRUCTURES
Stations, Find Someone Who, projection/team structures, and similar activity formats reuse the Activity Set questions for that set rather than authoring another hidden question inventory.

SET BUILDER / TEACHER OVERRIDE
The future/current teacher Set Builder should open with a strong recommended Target Plan A and Target Plan B derived from the recurrence map. The teacher may alter selected I Cans/counts/families before building. The system recommends first; the teacher edits rather than rebuilding the curriculum plan from scratch.

This target-plan/map should be visible from the Teacher Dashboard when the dashboard is reorganized.

9. REPRESENTATION SYSTEM
================================================================

Graph · Equation/Rule · Table · Context/Situation are the four core Algebra forms of meaning.

FOUR-VIEW CONTRACT
When an Algebra artifact intentionally presents FOUR views of one relationship, the four views are exactly:
  1. Equation / Rule
  2. Table
  3. Graph
  4. Context / Situation

Ordered pairs are correspondence notation, not a fifth independent representation and not a substitute for the Graph in a claimed four-view set.

REQUIRED GRAPH ROUTE
When Graph is required by the learning job, render an actual graph using the current registered Algebra graph tool. Do not replace a required graph with ordered pairs, prose, or a duplicated table.

Function language develops across the course:
  input/output -> function/not a function -> f(x) -> evaluation -> domain/range -> key features.

10. STUDENT QUESTION LABEL — HARD
================================================================

When a Bank-derived question is shown in Notes Example/YTI, Practice, Activities, Quick Checks, Checkpoints, Review, or another student-facing targeted artifact, display a compact exact learning label near the top-left of the question:

  U1-MG03-IC01 — Substitute a value for a variable.

Use exact canonical code + full exact I Can statement. Do not show code alone when the artifact is intended to help students learn/use the targeting system.

Warm-Up Q3/Q4 use the same label. Q1/Q2 fluency lanes do not need a forced MG/I Can label unless they naturally map to one.

11. SUMMATIVE / REVIEW
================================================================

UNIT REVIEW
Organize around current Unit Mastery Goals/supporting I Cans. Review may use approved nonsecure Bank families and Practice target plans. Do not create a second permanent Bank.

SUMMATIVE
Secure Algebra assessment uses six comparable forms V1-V6 under the accepted Unit evidence blueprint. Target approximately two secure evidence opportunities per current Unit Mastery Goal while keeping the complete form appropriate for about a 40-minute class period.

Prefer deterministic/seeded sibling generation for parallel secure forms when the approved family contracts safely support it; otherwise use reviewed secure authored parallels. Security and comparability matter more than surface novelty.
