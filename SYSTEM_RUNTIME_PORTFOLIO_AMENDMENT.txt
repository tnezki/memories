SYSTEM RUNTIME AMENDMENT - PORTFOLIO LOCAL DELIVERY / PRIVATE STATE ROUTING
==========================================================================
STATUS: CURRENT
SCOPE: Portfolio workflow only.
REVISION: 2026-09-28 - LOCAL STATE + LOCAL EMAIL PACKAGE

PURPOSE
-------
Portfolio is a private local state-and-report workflow. Student evidence, rosters, support files, Portfolio state, report outputs, PowerSchool exports, contacts, email notes, and delivery logs must never be written to GitHub.

CANONICAL PRIVATE ROOT - HARD
-----------------------------
Canonical Portfolio state after migration lives under:
  _portfolio_data/

Normal course/unit layout:
  _portfolio_data/<Course>/unit N/
    01 Evidence Inbox/
    02 Portfolio Data/
    03 Student Packets/
    04 Class & Intervention Summaries/
    05 PowerSchool Exports/
    06 Email Delivery/

Global private contact routing lives at:
  _portfolio_data/00 Contact Directory/student_support_contacts_current.csv

Google Drive is NOT canonical Portfolio state after migration. Normal grading, state updates, reports, PowerSchool exports, roster maintenance, teacher observations, and local email-PDF preparation use `_portfolio_data` only.

EMAIL SENDER BOUNDARY - HARD
----------------------------
The live Portfolio email sender must use the current local sender package created from `_portfolio_data`. It must not read old Portfolio rosters, MG grades, recipients, notes, or reports from the retired Drive-era Portfolio archive.

Local Portfolio email preparation creates:
  _portfolio_data/<Course>/unit N/06 Email Delivery/Current/Portfolio_Email_Sender_Package.zip

The package contains the teacher-selected current batch, current local recipient routing, MG display values, reviewed notes, and identity-verified PDFs. It is private transport and is not a Curriculum Transfer artifact.

The deployed teacher-authorized Google Apps Script sender is transport-only. The teacher explicitly uploads the current local package, reviews preflight, may send a teacher-only test, and explicitly confirms LIVE SEND.

Google Drive may be used only by that sender for its own private transient staging and persistent send log. Those files are not canonical Portfolio state and may not overwrite or resolve conflicts against `_portfolio_data`.

STUDENT DATA TOOLS - HARD
-------------------------
The normal private-work launcher is:
  Tools/student_data_tools/Student Data Tools.app

Student Data Tools starts the localhost Portfolio runtime, verifies its health endpoint, and provides a private landing page linking to Portfolio and the configured email sender. It does not contain student data and never performs an unattended send. The raw localhost home page does not open automatically when Student Data Tools launches the runtime.

The Portfolio runtime binds only to:
  127.0.0.1:8765

Because the workspace lives under ~/Documents, the runtime is intentionally started through an interactive Terminal process. Do not replace this with a LaunchAgent/background login helper unless macOS privacy behavior is deliberately revalidated.

NORMAL GRADING FLOW
-------------------
1. Student Data Tools starts the local Portfolio companion.
2. The course Portfolio panel builds a state-aware grading request from new evidence plus current local roster/learning/state identity.
3. ChatGPT interprets the new evidence and returns only the declared Portfolio grading result artifact.
4. Local Python validates exact parent state identity, updates longitudinal state/history/status/grades, rebuilds canonical reports and PowerSchool exports, archives state/results, and refreshes folders 03-05.
5. Google Drive is not read or written by this normal grading flow.

ROSTER / SUPPORT
----------------
The stored student_registry.csv is reused on ordinary runs. Roster updates are explicit local actions. Durable student ID reconnects history; missing students become inactive rather than deleted.

Support documents/contact files are private setup/support sources, never evidence. Keep student-to-support-staff routing in the global private contact directory. Do not infer missing email addresses from names.

REPORT / GRADE OUTPUT
---------------------
Official grading export is one current CSV per Mastery Goal per period; there is no overall Unit-grade CSV. Not assessed means the Mastery Goal has not been checked yet and therefore has blank PowerSchool Score. Needs first check means the individual I Can has not been checked yet.

Recurring Portfolio HTML must continue to use the exact registered Portfolio templates/CSS and pass the registered Portfolio validators. Report refreshes from valid current local state do not add evidence, change grades, or increment the state version.

EMAIL PREPARATION / DELIVERY
----------------------------
Local Portfolio email preparation is explicit and student-selectable. It may rebuild current individual HTML reports from local state, convert selected reports to identity-verified PDFs, create the local delivery manifest, and build Portfolio_Email_Sender_Package.zip under:
  06 Email Delivery/Current/

The sender package is built only from current local Portfolio state/contact files and the teacher-reviewed selected batch. Local preparation itself sends no email.

Live sending remains explicit teacher action in the authorized sender. The sender accepts only the current local sender package, validates attachment identity/hash and recipients, keeps a private duplicate-send log, retains a teacher-only test option, and requires a clearly labeled explicit LIVE SEND confirmation.

PRIVACY / TRANSFER BOUNDARY
---------------------------
- `_portfolio_data` is private and must never be initialized as a Git repository.
- Student-specific Portfolio requests/results are private workflow artifacts, not Curriculum Transfer payloads.
- Curriculum Transfer may update Portfolio software/contracts/templates only when no student-specific data is included.
- A local private runtime or sender failure must fail closed rather than falling back to public storage or GitHub.

All other SYSTEM_RUNTIME_CONTRACT rules remain in force.

END - PORTFOLIO LOCAL DELIVERY / PRIVATE STATE ROUTING AMENDMENT
