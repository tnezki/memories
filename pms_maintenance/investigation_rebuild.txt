PHYSICS INVESTIGATION REBUILD — SECTION DASHBOARD PILOT
========================================================

STATUS: PILOT
JOB: investigation_rebuild
ROLE: Rebuild exactly one existing Physics section Investigation from a section-level dashboard request.

This PM is intentionally narrow. It does NOT rebuild the Unit, Demo, Notes, Practice, Activities, Bank, Quick Check, Performance Task, Review, Warm-Ups, or Summative.

----

ONE GITHUB TRANSFER ZIP

============================================================================
4. REBUILD INTENT
============================================================================

teacher_inputs.direction has two allowed values:

improve
- treat the current investigation as the starting point;
- preserve what already works;
- implement the teacher's requested changes;
- do not redesign unrelated parts just because a different design is possible.

replace
- the teacher is intentionally replacing the investigation concept;
- use the current artifact for useful shell/print conventions only;
- build the new teacher-selected idea while preserving exact section scope/I-Cans.

If teacher notes clearly conflict with the selected direction, the explicit teacher note wins.

============================================================================
5. INVESTIGATION DESIGN RULES
============================================================================

Start from:
exact section I-Can/evidence intent -> phenomenon/question -> what students actually DO ->
data/observations -> representation/model -> interpretation -> claim/reasoning/discussion.

Use the teacher-supplied style_preferences and materials_constraints as the primary local design profile for this run.

Physics defaults when consistent with the teacher request:
- use a concrete, observable physical situation;
- prefer student action/data/observation over passive worksheet completion;
- conceptual meaning comes before mechanical formula use;
- equations/formulas describe relationships in the phenomenon;
- graphs/tables/diagrams/models must be used for evidence, not decoration;
- a prediction/initial claim is valuable when the outcome is not already given away;
- evidence and reasoning should follow what students actually measured/observed;
- keep student directions concise enough for real classroom use;
- do not over-script software/tool mechanics the teacher can demonstrate live;
- do not tell students what their data is supposed to show;
- keep the task feasible with the materials actually supplied/approved by the teacher;
- do not default to specialized equipment that the request does not authorize.

Simulation/video/data-based investigations are valid when they create a better evidence route than a weak physical setup. Use only teacher-approved links supplied in the request or already present in the current project artifact/resources.

============================================================================
6. STUDENT ARTIFACT
============================================================================

The student investigation must be classroom-ready and printable.

Include only pieces that the investigation actually needs, such as:
- title / short purpose or question;
- name/partner when appropriate;
- initial claim/prediction when useful;
- materials;
- concise procedure/setup;
- data table / observation structure;
- graph/model/representation space when useful;
- analysis / claim-evidence-reasoning / discussion;
- blank usable workspace.

Do not add decorative complexity.
Do not add long teacher-facing directions to the student page.
Do not reveal expected results or solutions.

Preserve the current course's print-conscious behavior. Use page breaks intentionally. Avoid avoidable blank pages, clipped content, microscopic text, and excessive toner-heavy blocks.

============================================================================
7. TEACHER GUIDE
============================================================================

The teacher guide must match the rebuilt student investigation exactly.

Include concise teacher-use information:
- purpose / exact section alignment;
- setup/materials;
- likely timing;
- teacher prep and launch;
- what students should physically do/collect;
- expected pattern/result only in teacher copy;
- useful discussion/press questions;
- likely misconceptions or measurement/setup problems;
- safety/setup cautions when relevant;
- answer/model guidance for student analysis prompts.

Do not turn the teacher guide into a second textbook chapter.
