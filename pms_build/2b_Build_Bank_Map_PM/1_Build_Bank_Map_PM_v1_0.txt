PURPOSE OF THE 2.5 MAP
----------------------
This PM separates curriculum/question DESIGN from question WRITING.

The output answers, before prose is authored:
- What exact I-can does each slot serve?
- What is the evidence/learning job?
- What question structure should be used?
- Is the slot a seed, parallel, adaptation, alternate, or retrieval item?
- What seed/parallel family does it belong to?
- What representation or tool is needed?
- Does it require a fresh graph/diagram/table/FBD/vector/model/image?
- What formula/relationship or vocabulary direction is appropriate?
- How short should the final prompt be?

The map MUST NOT contain finished student-facing question prose, answers, distractors, DOK, or Bloom labels.

GLOBAL PHYSICS DESIGN RULES
---------------------------
A. SHORT BY DEFAULT
A question gets extra context only when the context improves the Physics, the evidence, or the authenticity of the
measurement/model. "Context-rich" is a tool, not the default style. Default length contract = `short`.

B. VISUALS ARE EFFECTIVELY FREE
If a graph, FBD, vector diagram, motion diagram, table, image, or model materially improves or carries the evidence,
plan the actual representation. Do not ration visual production merely because another graph/image already exists.
Separate canonical questions should normally receive fresh purpose-built visuals. Parallel questions normally receive
fresh parallel visuals/data/orientations when a visual is part of the evidence.

Allowed intentional sharing: one coherent multipart WTC/FRQ may share one stimulus; the same canonical Bank item may
reuse its finalized visual downstream. Do not add decorative visuals that do not affect the task.

C. PARALLEL IS INTENTIONAL
Declared parallel forms are supposed to resemble their seed in skill, evidence job, and approximate difficulty.
Similarity is not a defect. Use `_question_structure.zip` to vary legitimate axes rather than merely swapping a name or
noun. Procedural items may use closer numeric parallels; conceptual/secure evidence needs enough variation to remain a
valid fresh instance.

D. PHYSICS MATH IS PHYSICAL
Do not map naked variable-assignment exercises such as "v=6, t=4, find d" as the student experience. A short physical
situation supplies the measurements. A formula/relationship may be supplied when appropriate; students then use,
choose, rearrange/invert, interpret, or combine it.

E. MULTI-STEP MEANS DEPENDENCY
A multi-step item is multi-step only when an intermediate result is required for the final result. Do not manufacture
multipart labels for unrelated questions.

F. PURPOSE BEFORE INVENTORY
Inventory is a container for planned instruction/evidence. Do not mechanically distribute I-cans just to fill counts.

DESTINATION CONTRACTS
=====================

1. WTC — 1 PER SECTION
-----------------------
Purpose:
- FRQ decomposition/navigation practice.
- Does NOT have to use the current section or current Unit's content.
- Does NOT count toward current-Unit I-can coverage.

Map each WTC as:
- one coherent shared stimulus/situation;
- 3-5 connected parts;
- parts should naturally progress through jobs such as interpret -> plan/model -> calculate/analyze -> justify/critique;
- include a real graph/diagram/table/model when useful;
- one multipart item may intentionally share one stimulus/visual.

WTC content may draw from previously learned or otherwise accessible Physics when that better teaches FRQ navigation.

2. EXAMPLE / YOU TRY IT — 4 PAIRS PER SECTION
---------------------------------------------
Purpose:
- Example models the thinking/application.
- YTI immediately gives the student a comparable opportunity to do it.

Rules:
- 4 Example/YTI pairs per section = 4 Examples + 4 YTIs.
- Example = seed.
- YTI = deliberate parallel/application of that Example.
- If the I-can naturally supports meaningful quantitative/formula work, strong Physics-math applications TAKE
  PRECEDENCE over generic vocabulary/conceptual filler.
- Keep both concise.
- If the pair uses a graph/diagram/FBD/etc., YTI normally gets its own fresh parallel representation.

3. PRACTICE — 24 SLOTS PER SET / 4 SETS PER SECTION
----------------------------------------------------
Purpose:
- Rich instructional menu and downstream source pool, especially for Activities.
- The 96 Practice slots per section are NOT a 96-question student assignment.
- Do not invent four unrelated 24-question inventories.

PRACTICE SET 1 = SEED SET
Exactly 24 planned seed slots per section using the default Physics composition:

A. VOCABULARY FAMILY — Q1-Q10 = 10 slots
- Use the section's important vocabulary.
- Usually allocate 1-2 seed slots per important term until 10 slots are filled.
- Do not let vocabulary dominate an I-can whose real job is quantitative/model/representation reasoning; vocabulary
  slots are serving vocabulary knowledge, not replacing the rest of the Practice architecture.
- Select approved vocabulary directions from `_question_structure.zip`.

Parallel vocabulary behavior:
- PS1 establishes each vocabulary family/relationship.
- PS2 intentionally inverts/changes direction where appropriate.
- PS3 uses another approved vocabulary direction.
- Extra Practice uses another legitimate parallel direction/presentation.
- Example progression may include term->definition, definition->term, concept/example->term, term->concept/example,
  or matching when efficient. Do not force every term through every direction if that becomes unnatural.

B. CONCEPTUAL FAMILY — Q11-Q20 = 10 slots
- 10 concise Physics-thinking seed questions.
- Choose structures because they fit the mapped I-cans, not to satisfy a variety quota.
- Useful structures may include predict, compare, classify, cause/effect, misconception/error analysis, evidence/model
  reasoning, brief explanation, graph/diagram interpretation, ranking, or representation translation.
- "Brief explanation" means brief. Do not add explanation wrappers merely to inflate rigor.

C. PHYSICS MATH FAMILY — Q21-Q24 = 4 slots
Default jobs:
- Q21 contextual direct quantitative application.
- Q22 contextual inverse/rearranged relationship.
- Q23 another useful quantitative application OR quantitative reasoning from a graph/table/diagram.
- Q24 dependent multi-step quantitative problem.

If the current section naturally supports quantitative Physics, use the section's important relationships.
If it does not, PRESERVE recurring Physics-math practice using an accessible current/prior Physics relationship in the
same spirit as the Warm-Up math slot. A formula may be supplied as needed. The physical situation supplies the
measurements. Do not fall back to naked variable assignments or generic algebra worksheets.

PRACTICE SETS 2, 3, AND EXTRA = CONTROLLED PARALLELS
- PS2 Qn is a parallel of PS1 Qn.
- PS3 Qn is another parallel of PS1 Qn.
- Extra Qn is another parallel of PS1 Qn.
- Preserve the same primary skill/evidence job and approximately comparable difficulty.
- Change legitimate axes as appropriate: solve direction/unknown, evidence set, values/units, dependency path,
  vocabulary direction, representation values/type, misconception target, context, or wording profile.
- Do not create fake novelty through only names/nouns/version labels.
- When a visual is part of the evidence, each parallel normally receives a fresh purpose-built visual/data instance.

4. CYU — 6 PER SECTION
-----------------------
Purpose:
- Short check of what students should now be able to do after instruction/practice.

Rules:
- 6 concise items per section.
- Adapt/select strong current-section Practice families rather than inventing six unrelated shells.
- Choose the six from the actual I-can/learning progression; do not mechanically force equal representation.
- Useful structures include calculate, identify, classify, interpret, brief explain/predict, graph/diagram read, or
  representation use when those jobs fit.
- CYU is not secure evidence; purposeful resemblance to Practice is acceptable.

5. WARM-UPS — 3 WARM-UPS x 4 QUESTIONS PER SECTION
---------------------------------------------------
Purpose:
- Predictable retrieval/bridge routine with controlled repetition.

Use this fixed four-job Physics pattern unless the CURRENT Framework explicitly supplies a more specific current rule:
- Q1 = current/recent Physics retrieval.
- Q2 = older/spiraled Physics retrieval.
- Q3 = concise conceptual/vocabulary/application retrieval.
- Q4 = recurring Physics math/formula skill.

Q4 math rule:
- use a short physical situation;
- supply an appropriate relationship/formula when needed;
- ask students to use/rearrange/invert/interpret it;
- do NOT use naked variable assignments as the default experience.

Warm-Up repetition is allowed and often desirable. Do not force novelty merely because a related idea appeared earlier.

6. EXIT TICKETS — 3 FORMS x 4 QUESTIONS PER SECTION
----------------------------------------------------
Purpose:
- Formative evidence of what students can do independently now.
- Evidence, not extra Practice.

MAP BEFORE PROSE:
For every section, map four distinct Exit A evidence slots FIRST.
- A1, A2, A3, A4 are FOUR UNIQUE SECURE SEED QUESTIONS.
- Each has its own mapped evidence job and primary I-can.
- The four jobs should collectively represent the most useful evidence for the section, not a mechanically equal quota.

Default four-slot shape when the I-can map supports it:
- Q1 core understanding: identify/classify/vocabulary-in-context/direct interpretation.
- Q2 conceptual reasoning: predict/compare/misconception/brief explanation.
- Q3 quantitative/application: contextual calculation, inverse/rearranged relationship, or graph/table calculation.
- Q4 strongest evidence/transfer: apply in a slightly different situation, use a graph/diagram/model, or complete
  dependent reasoning.

The evidence map may override that default when the section's I-cans require a different best-fit mix.

PARALLEL SECURITY FORMS:
- Exit B Q1 = parallel of Exit A Q1; B Q2 = parallel of A Q2; etc.
- Exit C follows the same four slot families.
- Preserve skill, structure, approximate difficulty, and evidence job.
- Do NOT copy exposed Practice, EX/YTI, CYU, or Warm-Up prompts into Exit A/B/C.
- Reusing the same learning target/family is fine; the secure stimulus/context/data must be a fresh instance.
- If a slot needs a graph/diagram/FBD/etc., A/B/C normally get fresh parallel visuals/data.
- Short by default: four questions should feel like an Exit Ticket, not a mini-test.

7. SUMMATIVE — 6 FORMS x 20 QUESTIONS PER UNIT
-----------------------------------------------
Purpose:
- Secure Unit mastery evidence.

MAP BEFORE PROSE:
A. V1 MASTER BLUEPRINT
- Map all 20 evidence slots before any Summative question is written.
- Every slot records exact primary I-can, evidence job, response mode, structure, representation, security role, and
  intended parallel variation axes.
- Use the current Framework's response-mode/profile requirements rather than inventing counts here.

B. V2-V4
- Deliberate parallel forms of V1.
- V1 Qn -> V2 Qn / V3 Qn / V4 Qn preserve the same blueprint slot, skill, response mode, approximate difficulty,
  evidence job, and representation demand.
- Change values/context/data/unknown/distractors/representation instances as appropriate.
- These forms SHOULD be recognizably similar because they are comparable same-day forms.

C. V5 ALTERNATE BLUEPRINT
- Map a second 20-slot secure blueprint against the same Unit mastery requirements.
- Keep overall coverage/rigor comparable to V1 while using meaningfully different evidence families, contexts,
  representations, or dependency paths where useful.

D. V6
- Current teacher-approved map rule: V6 is a deliberate parallel form of V5, using the same slot-by-slot relationship
  logic that V2-V4 use with V1.
- If the teacher later explicitly changes this current rule, follow that instruction.

SECURITY:
- Summative seeds may target the same I-cans/families taught in instruction, but do not copy exposed instructional
  prompts as the secure question instance.
- Selected-response distractors are planned as item-specific misconception/error evidence, not generic answer bags.
