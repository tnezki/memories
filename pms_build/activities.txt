ACTIVITIES PRINCIPLE
--------------------
Activities change HOW students participate around worthwhile mathematics.
They do not create a second curriculum, a second 24-question Practice bank, or a secure assessment.

THIS BUILD PRODUCES PER SECTION
-------------------------------
1. Activity Options / Directions page
2. One classroom-sized Activity Question Set + teacher solutions
3. Stations handout using that SAME Activity Question Set
4. Find Someone Who handout using that SAME Activity Question Set
5. Optional links/routing to the Practice-owned Tarsia and Blooket files when present

DO NOT BUILD
------------
- Practice 2
- Practice 3
- a second or third 24-question activity bank
- fake external activity links
- duplicate Tarsia or Blooket question inventories
- official Exit Tickets

========================================================
2. SECTION LEARNING BALANCE — HARD
========================================================

Every section Activity Question Set contains exactly 12 questions:

- 4 Intro
- 4 Review
- 4 Mastery

These are INTERNAL authoring allocations.
Do NOT visibly label every student question Intro / Review / Mastery unless the teacher explicitly requests it.

The set should feel like one coherent class activity, not three mini worksheets pasted together.

INTRO
- exact current section Intro Learning Target/I Cans
- accessible entry and representation work

REVIEW
- exact section Review goal/stage
- less support, fresh use, useful retrieval

MASTERY
- exact current Mastery Goal / supporting I Can
- use current Unit family Bank architecture
- fresh independent instances, not copied Bank exemplars

If Intro/Review point to another Unit in the spiral, do not require that future/other Unit Bank.
The exact Assessment Plan is enough to author fresh Intro/Review work.

========================================================
3. ACTIVITY QUESTION SET — ONE SET ONLY
========================================================

Create one reusable 12-question set per section.

Canonical filename:
  u{unit}_{section}_activity_questions_solutions.html

The page contains:
- 12 numbered student prompts
- teacher answer/solution immediately available in the teacher-facing version or clearly separated teacher area
- enough reasoning to support facilitation
- representation assets actually needed by the questions

The SAME 12-question set powers:
- projected whiteboards
- partners / Rally Coach
- Speed Dating Math
- Showdown
- Think, Trade, Agree
- Round Table
- Mathematical Hot Seat
- Stations
- Find Someone Who

Do NOT create Set 1 and Set 2 merely to imitate the retired Practice 2/3 architecture.

QUESTION MIX
------------
Across the 12:
- vary natural Question Structure families;
- include direct work when direct work is the right job;
- include some reasoning/compare/error/representation work when mathematically natural;
- use purposeful procedural repetition only when it earns instructional value;
- avoid twelve unrelated one-off gimmicks.

========================================================

========================================================

-> student action
-> structure
-> response mode
-> representation mode
-> executable route

Keep direct questions direct.

Difficulty comes from mathematics and independence, not inflated arithmetic.

========================================================

  Tools/QUESTION_FRESHNESS_CONTRACT.txt

B. current student Notes prompts for the same section

D. current Extra Practice
E. current CYU
F. current Tarsia prompts
G. current Blooket prompts

FAIL / REPAIR:
- exact repeated finished question
- same distinctive values/data + same prompt
- same graph/table/context used as the same task
- cosmetic rewrite of an existing student-facing item
- conversion of an existing prompt to a participation structure with no meaningful fresh instance

ALLOW:
- same target
- same I Can
- same family architecture
- same evidence job
- same mathematical procedure when repetition is genuinely useful

IMPORTANT
---------
The participation wrapper does NOT make a repeated question fresh.
A Practice question copied into Stations is still the same question.

When a collision occurs:
repair the NEW Activity question only, preserve the target, and vary meaningful axes.
