6B. PAGE 2 — TEACHER & STUDENT MOVES — RICH GUIDE REQUIRED

This is a TEACHER-FACING guide, not the student activity instructions.

For EACH section I-can:

- provide at least TWO matching Student Moves.

Teacher Moves should prompt the evidence demanded by that I-can, for example:
- name the relevant representation/evidence;

Student Moves should describe observable evidence behavior, for example:
- show the mathematical/physical evidence;
- state units/direction/reference frame when relevant;
- compare a result with the representation;
- explain why evidence supports the claim;

----------------------------------------------------------------------
6D. CANONICAL PARTICIPATION MECHANICS BY PAGE
----------------------------------------------------------------------

Use these mechanics as the minimum behavioral contract.
Physics-specific wording may be added, but do not erase the participation structure.

WHITEBOARD INDY — `dir-whiteboard-indy`
Structure:
  Individual -> independent practice
Setup:
  Each student has a whiteboard and marker, or the teacher-approved equivalent.
Directions must communicate:
1. Notes/resources may be used when allowed.
2. Try the problem before asking for an answer.
3. Write large and clearly enough to be checked from across the room.
4. Show reasoning/evidence, not only the final answer.
5. Use help appropriately; do not copy.
6. Correct mistakes and explain what changed.
Goal:
  individual accountability + low-stakes problem entry
Looks Like Success must be specific to visible individual work.
Doesn't Look Like must include waiting/copying/tiny-or-uncheckable work.

WHITEBOARD PARTNERS — `dir-whiteboard-partners`
Structure:
  fast partner practice
Setup:
  partners with one shared board/marker unless current teacher setup specifies otherwise
Directions must communicate:
1. Both partners stay engaged.
2. Alternate who writes/holds the marker.
3. The non-writer checks/asks questions rather than waiting.
4. Both partners must be able to explain the current step.
5. Resolve disagreements before moving on.
6. Fix mistakes together.
Goal:
  engagement + quick feedback
Looks Like / Doesn't Look Like must focus on balanced participation and shared reasoning.

RALLY COACH — `dir-rally-coach`
Structure:
  partner explanation + alternating solver/coach roles
Setup:
  partners with the approved writing surface(s)
Directions must communicate:
1. Partner A solves/explains while Partner B coaches.
2. Coach asks questions/hints; coach does not take over.
3. Solver states reasoning/evidence aloud.
4. Check the work together.
5. Switch roles for the next problem.
6. Continue alternating.
Goal:
  verbal reasoning + procedural/conceptual accuracy
Looks Like / Doesn't Look Like must distinguish coaching from answer-giving.

SPEED DATING — `dir-speed-dating-math`
Structure:
  paired practice -> timed rotation -> strategy sharing
Setup:
  teacher-arranged partner/seat rotation; each student keeps their own work
Directions must communicate:
1. Solve the projected/assigned problem with the current partner.
2. Each student records their own work.
3. Compare strategies/evidence, not only answers.
4. Ask at least one clarifying/checking question.
5. Rotate when directed.
6. With the new partner, begin the next problem and carry forward useful reasoning.
Goal:
  repeated explanation + exposure to multiple strategies
Looks Like / Doesn't Look Like must mention rotation and strategy exchange.

SHOWDOWN — `dir-showdown`
Structure:
  private solve -> simultaneous reveal -> compare
Setup:
  every student needs a response surface; group sizes as directed
Directions must communicate:
1. Work silently/independently during think time.
2. Commit to a complete solution before reveal.
3. Reveal responses together when cued.
4. Compare differences.
5. Explain why a method/result is supported.
6. Revise only after discussion/evidence.
Goal:
  individual accountability before group comparison
Looks Like / Doesn't Look Like must protect private think time and simultaneous reveal.

THINK–TRADE–AGREE — `dir-think-trade-agree`
Structure:
  think alone -> trade reasoning -> agree/revise
Setup:
  individual work first, then partner exchange
Directions must communicate:
1. Solve/form a claim independently.
2. Mark the evidence/reasoning you used.
3. Trade explanations with a partner.
4. Ask a clarifying question.
5. Identify agreement/disagreement.
6. Reach a defensible shared conclusion or record why disagreement remains.
Goal:
  independent thinking + evidence-based revision
Looks Like / Doesn't Look Like must distinguish agreement by evidence from answer copying.

ROUND TABLE — `dir-round-table`
Structure:
  small-group sequential contribution
Setup:
  one shared response surface or teacher-approved group format
Directions must communicate:
1. First person begins the solution/explanation.
2. Pass to the next person after a meaningful step.
3. Each student must add/check/explain something before passing.
4. Group members may question a step but should not erase ownership of it.
5. Continue until the solution/explanation is complete.
6. Group reviews the full reasoning together.
Goal:
  distributed participation + connected reasoning
Looks Like / Doesn't Look Like must prevent one student completing the whole task.

MATHEMATICAL HOT SEAT / HOT SEAT — `dir-mathematical-hot-seat`
Structure:
  one student explains/describes while teammates question/check
Setup:
  one student in the active role; teammates can see the prompt/work as the current shell permits
Directions must communicate:
1. Hot-seat student explains the solution/representation/next step.
2. Teammates ask evidence or clarification questions.
3. Teammates do not simply give the answer.
4. Hot-seat student may revise after questions.
5. Confirm the final reasoning as a group.
6. Rotate the hot-seat role.
Goal:
  precise explanation + accountable questioning
Looks Like / Doesn't Look Like must distinguish questioning from answer feeding.

RALLY COACH II — `dir-rally-coach-ii`
Structure:
  solver/coach roles switch every problem with explicit check
Setup:
  partners and approved writing surface(s)
Directions must communicate:
1. Solver owns the written solution and explanation.
2. Coach listens for evidence, units, direction, representation use, or other section-specific needs.
3. Coach asks questions before offering a hint.
4. Pair checks the completed problem.
5. Switch roles for the next problem.
6. Repeat.
Goal:
  sustained partner coaching + equal role ownership
Must not be a duplicate of generic Rally Coach prose; the explicit check/evidence role should
distinguish this version.

DESMOS — `dir-desmos-activity`
When a real current Desmos link/code exists:
- show the link/code;
- explain how students enter/use the activity;
- specify individual vs partner use;
- specify what students should record/discuss;
- specify completion/check expectations.
When no real link/code exists:
- clearly say teacher-selected Desmos activity/code required;
- do NOT fabricate an activity/code;
- keep the page useful as a setup placeholder, not a fake student task.

STATIONS — `dir-stations`
Structure:
  small-group station rotation
Setup:
  station materials/pages distributed according to the current Stations companion
Directions must communicate:
1. Begin at assigned station.
2. Work the station's problems collaboratively while each student remains accountable.
3. Record/leave a readable strategy as required.
4. Compare methods and resolve disagreements.
5. Rotate only when directed.
6. Continue until assigned stations are complete.
Goal:
  collaborative practice + multiple problem encounters
Include direct Set 1 / Set 2 Stations links.
Looks Like / Doesn't Look Like must mention rotation and shared-but-accountable work.

FIND SOMEONE WHO — `dir-find-someone-who`
Structure:
  partner search + explain/check + signature
Setup:
  each student has their own Find Someone Who sheet
Directions must communicate:
1. Find a partner for a problem.
2. Solve/explain/check the problem together.
3. A signature is earned only after an explanation/check, not by showing an answer.
4. Record reasoning you understand on your own sheet.
5. Move to a different partner for another problem when directed/required.
6. Continue until the assigned work is complete.
Goal:
  repeated peer explanation + individual written evidence
Include direct Set 1 / Set 2 Find Someone Who links.
Looks Like / Doesn't Look Like must mention meaningful explanation before signatures.

TARSIA PUZZLE — `dir-tarsia-puzzle-activity`
Structure:
  collaborative matching puzzle
Setup:
  use the Practice-owned Tarsia pieces/file
Directions must communicate:
1. Match prompt/answer edges using mathematics/physics reasoning.
2. Explain why a proposed match belongs before locking it in.
3. Teammates check neighboring matches for consistency.
4. Revise mismatches rather than forcing pieces.
5. Continue until the puzzle is complete.
6. Be prepared to justify selected matches.
Goal:
  retrieval + explanation + collaborative error correction
Link only to the Practice-owned Tarsia.
Do not regenerate Tarsia content.
