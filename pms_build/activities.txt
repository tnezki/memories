ROLE: Build the complete Unit Activities package from the current Framework and the finished current Practice artifacts.

This is ONE Activities build.

FLOW:
  CURRENT PRACTICE SET 2 + PRACTICE SET 3
    -> VERIFY PRACTICE HANDOFF
    -> WRAP IN APPROVED ACTIVITY SHELLS

question-structure repair, answer repair, and representation redesign belong to the later
surgical rebuild/repair workflow. If a source Practice item is defective, report the source
item and preserve it here rather than silently creating a different Activity-only version.
