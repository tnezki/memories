4. PARALLEL-AUTHORING RULE — INTENTIONAL
========================================================

Set 1 is intentionally a parallel version of Practice 1.
Set 2 is intentionally a parallel version of Extra Practice.

This means Activities MAY preserve:
- question order;
- target;
- stage;
- I Can;
- family architecture;
- response mode;
- representation type;
- procedural structure;
- prompt skeleton when useful.

Activities MAY create freshness primarily through:
- changed numbers;
- changed ordered pairs;
- changed table values;
- changed graph parameters;
- changed names/quantities/context details;
- changed signs/directions;
- another valid family variation axis.

A number/data/context swap is ACCEPTABLE here when it creates a valid fresh parallel
and preserves the intended mathematical evidence.

Do NOT force every Activity parallel to become a different question family.
The purpose is reusable classroom parallel practice, not a third novel curriculum.

HARD LIMIT:
- never copy a Practice/Extra question verbatim;
- never reuse the exact same distinctive values/data/stimulus;
- never copy a Bank exemplar verbatim.

This Activities-specific intentional parallel rule overrides the default
"cosmetic parallel — repair by default" behavior in the shared freshness contract
for Set 1/Set 2 versus their owning Practice source.

Exact duplicates still FAIL.
