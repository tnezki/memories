I CAN PROGRESS - LOCAL RUNTIME
------------------------------
Current family-facing states:
1. Not Yet Assessed - class has not had an assessment opportunity for the I Can yet and no stronger student evidence exists.
2. Started - class has had at least one opportunity, but the student has not yet shown meaningful progress; absence/missed checks/unsuccessful evidence may land here.
3. Developing - meaningful partial understanding is visible.
4. Progressing - one independent CONVINCING demonstration OR the deterministic repeated-partial threshold (three independent PARTIAL opportunities).
5. Mastered - two independent CONVINCING demonstrations.
6. Extended - Mastered plus meaningful transfer/extension evidence.

Legacy state codes are migration inputs only; regenerate current display/status from the ledger.

MASTERY GOAL MODEL
------------------
Let n = exact I Can count in the current goal.
- C: at least ceil(.75*n) I Cans are Progressing or better.
- B: C coverage is met AND at least ceil(.50*n) I Cans are Mastered/Extended.
- A: all n are Mastered/Extended.
- A+: A plus at least one Extended I Can.

Below C:
- 0 class opportunities -> Not Yet Assessed; PowerSchool blank.
- 1 class opportunity -> report grade box dash/blank; PowerSchool blank.
- 2+ class opportunities + meaningful growth -> Falling Behind; PowerSchool blank.
- 2+ class opportunities + no meaningful growth -> F; PowerSchool F.

Meaningful growth means at least one I Can in that goal is Developing or better.

Never expose/export I / In Progress as the current MG grade.
