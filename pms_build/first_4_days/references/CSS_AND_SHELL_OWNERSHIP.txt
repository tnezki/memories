REFERENCE-ONLY CONTENT

Bundled copies of the current family CSS and canonical HTML references exist to prevent renderer reconstruction from memory. This includes base, Notes, Warm-Up, Practice, Activity, Investigation/teacher-guide, and Exit references used by the First 4 Days workflow.
They are NOT a second live deployed CSS tree.

At build time:
- read the current course Framework and current live CSS/path contracts;
- use the Framework/current family if newer;
- deploy First 4 Days HTML using the live course-root CSS paths;
- only deploy first_4_days.css for special opening-only artifacts that need classes not owned by a normal resource family;
- use bundled plane.png only as a reference/canonical byte source when the current course supplies the same approved printable or explicit current instruction authorizes it.

The universal PM does not freeze a course Framework. The current Framework should be packaged by the controller/request with each run so Algebra, Physics, and Calculus remain course-specific. A frozen Framework copy inside this universal PM would create exactly the stale-authority problem this architecture is meant to prevent.
