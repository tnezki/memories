4A NOTES MAP SOURCE CONTRACT — v1.6
============================

REQUIRED CURRENT AUTHORITIES
- Curriculum Philosophy
- Physics Framework
- Complete/materialized Unit Bank
- Physics Notes Image Toolkit

PINNED RETRIEVAL — HARD
- Use only request-pinned repository snapshots.
- Read the exact Curriculum Philosophy text file named by the request and this PM from the pinned memories snapshot; resolve the Physics Framework through its stable gateway/manifest; read the Unit Bank and the Framework-declared Physics Notes Image Toolkit from the pinned Physics course snapshot.
- Expanded text/directory authorities are read directly from their pinned repository trees. 4A may inspect selected toolkit images through the repository interface; no request-package copy of the toolkit is required.
- For the Physics Framework, resolve through `frameworks/MANIFEST.json`; read `frameworks/Physics/FRAMEWORK.txt` and only the supporting files listed by `frameworks/Physics/MANIFEST.json` that PM Section 0 requires.
- Open the Framework-declared course catalog `resources/Physics_Notes_Image_Toolkit/IMAGE_CATALOG.json` before inspecting selected image assets.
- Normal retrieval is silent. Do not web-search, provenance-hunt, or substitute lower-authority deployed artifacts.
- If a prescribed pinned path fails, fail closed with exact repo/commit/path rather than exploring alternate authority routes.

FAIL CLOSED IF
- the Unit Bank is missing/incomplete;
- exact section/I-can structure cannot be resolved from the Framework/Bank;
- canonical EX/YTI or WTC anchors referenced by the Bank cannot be resolved;
- the Physics Notes Image Toolkit catalog cannot be opened;
- selected image IDs/paths cannot be verified against the toolkit;
- any Stop & Discuss source_image_ids value is not a valid current-toolkit PHYS-XXXXXXXXXXXX ID;
- any Stop & Discuss expected_reasoning_evidence_to_listen_for value is an image ID or is not teacher-facing reasoning/evidence text;
- Stop & Discuss source-image and expected-reasoning fields are swapped or overloaded.

DO NOT REQUIRE
- the retired Question Structure and Visual Toolkit;
- _question_structure/;
- final Notes HTML/CSS source files;
- manually supplied images when the course-owned toolkit already contains the needed source image;
- a memories/Tools copy of the Physics Notes Image Toolkit.

v1.2 FINGERPRINT CONTRACT
- source Bank provenance is content-stable, never raw ZIP bytes.
- primary: STAGE_3E_HANDOFF.json canonical_authored_content_sha256 -> stage3e-canonical:<hash>.
- fallback: deterministic extracted-content manifest -> content-manifest:<hash>.
- raw sha256:<zip-bytes> handoffs are forbidden.
