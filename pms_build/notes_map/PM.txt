4A · BUILD PHYSICS NOTES MAP PM v1.7
====================================
TEXTBOOK-SPINE FAST PATH — 2026-08-29

ROLE
----
Build the Physics Notes map for one Unit by adapting the already-existing Physics textbook flow into a classroom-length Notes lesson plan.

4A is NOT a second textbook authoring stage, NOT a Bank audit, and NOT an image-discovery project.

The Physics textbook already owns the conceptual teaching flow. The Unit Bank already owns the WTC and canonical EX/YTI pairs. The Physics Notes Image Toolkit owns canonical source-image bytes. 4A only decides what textbook material to KEEP / CONDENSE / DROP and where the existing curriculum pieces are inserted.

The target is a compact map that 4B can execute quickly into a 30–40 minute lesson per section.

======================================================================
0. OPERATING MODEL — HARD
======================================================================

4A is a CUT + INSERT mapper.

For each course section:
1. resolve exact section title / Learning Target / I-cans;
2. open the matching Physics textbook section;
3. preserve the textbook's conceptual order;
4. mark textbook blocks KEEP, CONDENSE, or DROP;
5. preserve useful textbook images in their existing logical locations;
6. insert the existing WTC early;
7. insert every canonical Notes EX/YTI pair at a logical concept boundary;
8. add at most the Stop & Discuss moments genuinely needed;
9. map Vocabulary Preview, Summary, and Common Mistakes targets;
10. stop.

4A MUST NOT:
- invent a new conceptual sequence when the textbook already provides one;
- write final Notes prose;
- write student-facing vocabulary definitions;
- create new worked examples when canonical Bank EX/YTI already exist;
- copy Bank prompts/solutions into the map;
- re-audit the full Bank;
- search all toolkit images for a better story when the textbook already embeds appropriate images;
- reread the full textbook when only the target Unit/section files are needed;
- run broad repository audits unrelated to the map;
- fail because of optional polish.

- canonical WTC wording/data/figures/solutions;
- canonical Notes Examples;
- canonical Notes YTIs;
- EX/YTI pair identity;
- exact Bank IDs and I-can linkage.

PHYSICS NOTES IMAGE TOOLKIT OWNS

4A OWNS ONLY
- KEEP / CONDENSE / DROP decisions on textbook flow;
- insertion points for WTC / EX-YTI / S&D;

- selection of any extra course-authored figure only when the textbook lacks a needed representation;
- Summary/Common Mistakes targets;
- generated-representation needs.

======================================================================
3. BULK LOOKUP RULE — HARD
======================================================================

Do not retrieve mapped objects one-by-one through repeated GitHub calls.

BANK
- load the Unit Bank JSON once;
- build an in-memory lookup by exact Bank ID;
- filter/select only Notes WTC/EX/YTI anchors for the target Unit.

IMAGES
- load `IMAGE_CATALOG.json` once;
- build an in-memory lookup by image_id, toolkit_path, basename, and source_catalog_path.

TEXTBOOK
- read each target section HTML once;
- extract its ordered headings, explanatory blocks, figures, checkpoints/sidebars, and source image paths.

Mapping dozens of existing anchors is a data-routing task, not a sequence of individual repository lookups.

======================================================================
4. TEXTBOOK FLOW MAPPING — PRIMARY METHOD
======================================================================

For each course section, use the actual textbook HTML as the instructional spine.

Identify ordered source blocks such as:
- textbook subsection heading;
- explanatory paragraph group;
- figure;
- checkpoint / question / sidebar;
- extended anecdote/history/application;
- practice/answer material;
- synthesis passage.

Assign one action to each relevant source block:

KEEP
- concise and directly useful for the current LT/I-cans;
- retain the idea/order in 4B, normally paraphrased/adapted rather than copied verbatim.

CONDENSE
- useful concept or phenomenon but too long for a 30–40 minute Notes lesson;
- 4B should preserve the idea/flow while shortening substantially.

DROP
- outside the current target;
- redundant with Bank practice;
- long historical/personal tangents not necessary for the lesson;
- answer sections / media-link clutter / extensions not needed in Notes;
- material that would push the section beyond the time budget.

Do not write the condensed prose in 4A.

======================================================================
5. LESSON-TIME BUDGET — HARD DESIGN TARGET
======================================================================

Each finished section should normally fit a 30–40 minute class period.

Map toward this rough student-time budget:
- opening + Vocabulary Preview: 3–4 min;
- WTC: 3–5 min;
- textbook-derived reading/images: 8–12 min total;
- canonical EX/YTI pairs: 12–16 min total;
- Stop & Discuss: 0–3 min normally;
- vocabulary definitions / summary / mistakes close: 3–4 min.

This is a design budget, not a stopwatch.

When the source textbook is long, CUT IT. Do not preserve material merely because it is interesting.

Prefer:
- 3–5 concise conceptual chunks;
- the strongest explanatory examples/phenomena;
- the few source images that actually teach the target;
- no more than one Stop & Discuss in a normal section unless a second is clearly necessary.

======================================================================
6. WTC + EX/YTI INSERTION
======================================================================

Resolve every canonical Notes anchor in the Unit Bank.

WTC
- one canonical WTC per section when the Bank provides it;
- place early, normally after LT/I-cans + Vocabulary Preview and before the main explanatory flow;
- map by exact bank_id only;
- do not copy or rewrite WTC content into the map.

EX/YTI
For each canonical pair record only:
- example_bank_id;
- yti_bank_id;
- i_can_id;
- insertion_after source block / flow step;
- concept being processed.

HARD
- every canonical Notes EX/YTI pair exactly once;
- Example immediately paired with its YTI;
- no split pair;
- no rewritten pair;
- no substitute pair;
- do not invent additional EX/YTI.

======================================================================
7. IMAGE RESOLUTION — TEXTBOOK PLACEMENT WINS
======================================================================

Do NOT use `curriculum_section` as the primary placement authority. It is incomplete and may conflict with filenames or source locations.

PRIMARY PLACEMENT TRUTH
The actual textbook section HTML determines where a textbook image belongs instructionally.

For each retained textbook `<img>`:
1. record its source path/basename from the textbook section;
2. resolve that image against the pinned Physics Notes Image Toolkit catalog using source_catalog_path, basename, provenance, alt_text, and image metadata;
3. record the resolved canonical image_id and toolkit_path;
4. keep it attached to the same conceptual source block unless the map explicitly drops that block.

If filename prefix, `curriculum_section`, or other metadata disagree with the actual textbook placement, do NOT silently reassign the image. Use the actual textbook section placement and record the metadata conflict as a non-blocking warning.

EXTRA COURSE FIGURES
Only search/select a non-textbook toolkit figure when:
- the current I-can requires a representation the textbook section does not adequately provide; or
- the section is explicitly a synthesis/application section and a course-authored figure is the stronger instructional choice.

For an extra figure, verify it semantically against the LT/I-can; never invent a path.

DO NOT perform a full toolkit audit.

======================================================================
8. STOP & DISCUSS
======================================================================

Map a Stop & Discuss only when the textbook-derived flow needs a brief processing moment not already handled by WTC or the canonical EX/YTI pair.

For each S&D record:
- after_flow_id;
- i_can_ids;
- discussion_job;
- prompt_skeleton;
- source_image_ids;
- expected_reasoning_evidence_to_listen_for.

`source_image_ids` contains image IDs only and each non-empty value must match:
^PHYS-[A-F0-9]{12}$

Do not write a polished teacher script in 4A.

======================================================================
9. VOCABULARY / SUMMARY / COMMON MISTAKES
======================================================================

For each section map:

VOCABULARY PREVIEW
- exact required terms from current course authority.

VOCABULARY DEVELOPMENT
- optional first-flow-location for important terms.

Do NOT write final definitions in 4A.

SUMMARY TARGETS
- short bullet concepts students should leave knowing.

COMMON MISTAKES TARGETS
- section-specific misconceptions/errors the Notes should explicitly repair.

======================================================================
10. GENERATED REPRESENTATIONS
======================================================================

Only map a generated graph/FBD/vector diagram/motion diagram/table/model when neither the textbook nor the canonical Bank/toolkit already supplies what the lesson requires.

Record:
- representation_type;
- purpose;
- i_can_id;
- what must be shown;
- answer-neutrality constraints;
- student-facing or teacher-only.

Do not generate the final asset in 4A.

======================================================================

PRIMARY METHOD — stage3e-canonical-v1
1. Read `banks/unitN/STAGE_3E_HANDOFF.json` from the pinned course commit.
2. Read `canonical_authored_content_sha256`.
3. Validate 64 hexadecimal characters.
4. Record exactly:
   source_bank_fingerprint_method = "stage3e-canonical-v1"
   source_bank_fingerprint = "stage3e-canonical:<lowercase-64-hex>"

Do NOT recompute or re-audit the full Bank when Stage 3E identity exists.

FALLBACK METHOD — content-manifest-v1
If Stage 3E identity is unavailable and the current authority permits proceeding, use the canonical memories helper:
`Tools/stable_bank_fingerprint.py`

Use the helper output consistently in both 4A and 4B.

FORBIDDEN
- legacy raw-ZIP form `sha256:<...>`;
- omitting either fingerprint field.

======================================================================
14. DIRECT BLOCKERS — ONLY REASONS TO FAIL CLOSED
======================================================================

FAIL CLOSED only when:

A. REQUIRED AUTHORITY MISSING
- current Assessment Plan / Framework / PM cannot be retrieved from the pinned snapshot;
- required target textbook section cannot be retrieved from the pinned textbook snapshot.

B. EXACT TARGET MISMATCH
- section title / LT / I-can cannot be reconciled to the current original Assessment Plan.

C. BANK DEPENDENCY MISSING
- required WTC/EX/YTI ID does not exist or canonical EX/YTI pair identity is broken.

D. SELECTED IMAGE DEPENDENCY MISSING
- a retained/mapped image cannot be resolved to a real canonical toolkit asset and no valid alternative exists.

E. MAP CANNOT BE MADE VALID
- canonical map JSON cannot parse or lacks required routing/provenance fields.

A missing or malformed derived `NOTES_MAP_HANDOFF.json`, HTML view, or report is a LOCAL OUTPUT DEFECT. Repair/regenerate it from the valid map JSON; do NOT redo the mapping.

DO NOT fail for:
- unrelated Bank issues;
- unused toolkit metadata defects;
- metadata disagreements that can be resolved by actual textbook placement;
- optional stylistic polish;
- broad architecture warnings unrelated to the map.

REVISION NOTE

This revision keeps the existing v1.7 map/handoff schema strings and core provenance contracts while changing 4A's job fundamentally: the Physics textbook is now the instructional spine. 4A trims and routes existing material instead of inventing a parallel story.
