SELECTED RESPONSE — HARD
------------------------
If `response_mode = selected_response`:
- store complete choices;
- visibly render complete choices in student_html;
- use the course/default choice count unless the map explicitly says otherwise;
- key the correct answer;
- distractors come from plausible task-specific errors/misconceptions;
- missing/placeholder/duplicate choices = FAIL.

TABLES — HARD
-------------
If the representation is a small table/data set:
- student_html contains a real semantic table;
- use `<table class="values">` for the existing compact centered Base-CSS data-table treatment;
- include readable headers/units;
- never render final data as pipe-delimited text or space-aligned rows.

DIAGRAMS / FBD / VECTORS — HARD
--------------------------------
Use an approved Framework/course/source visual or approved deterministic diagram route.

WTC — HARD
----------
WTC is difficult FRQ-navigation practice, not a loose preview list.
Each WTC:
- one shared coherent Physics stimulus/representation;
- normally 3–5 connected labeled parts;
- actual evidence-bearing representation/shared stimulus;
- representation interpretation/extraction;
- dependency/use of an earlier conclusion;
- planning/model-choice/justification;
- may use prior/current/future Physics;
- coverage_role = wtc_frq_practice;
- does not satisfy current Unit coverage floors.

If content is untaught, keep the navigation/unpacking work structurally accessible without making the WTC trivial.

Do not generate generic vocabulary filler when the I-can/map calls for quantitative/model evidence.
