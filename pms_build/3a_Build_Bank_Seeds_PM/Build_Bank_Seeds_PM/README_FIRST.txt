3A BUILD BANK SEEDS v2.0
========================

PURPOSE
Build only the high-value instructional seed layer from the audited Bank Map before any large expansion.

FIRST TASK
READ THE CURRENT CURRICULUM PHILOSOPHY COMPLETELY.

INPUTS
1. This PM package
2. Current course Framework
3. unitN_bank_map_audited.zip with map_audit.final_status = PASS
4. Current Philosophy and _question_structure.zip (normally bundled automatically)

AUTHORS ONLY
- WTC
- Example
- YTI
- Practice Set 1

For the current five-section Physics Unit architecture this is normally 165 items, but the audited map owns the count.

DOES NOT AUTHOR
Practice 2/3/Extra, CYU, Warm-Ups, Exit Tickets, Summatives, or downstream resources.

OUTPUT
unitN_bank_3a_seeds.zip

SAVE THE ZIP, STILL ZIPPED, AT
<course>/banks/unitN_bank_3a_seeds.zip

DO NOT unzip it or replace the deployed <course>/banks/unitN/ folder. This is a nondeployable checkpoint.

NEXT
3B Build Instructional Variants consumes this checkpoint plus the same audited map, verifies the handoff/fingerprint, preserves all 3A work, and adds PS2/PS3/Extra/CYU/Warm-Ups.

FULL BUILD CHAIN
2.5 Map -> 2.6 Map Audit -> 3A Seeds -> 3B Instructional Variants -> 3C Exit Tickets -> 3D Summative Bank -> 3E Final Audit + Materialize

RETENTION
Keep all checkpoint ZIPs through 3E. After 3E materializes and verifies the permanent unitN/ folder and preserves the map/audit provenance inside it, the temporary Unit build ZIPs may be manually deleted.
