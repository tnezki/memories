CURRENT TEACHER-APPROVED PHYSICS BANK-MAP CONTRACT
---------------------------------------------------
This PM audits against the current approved map architecture. If an older Framework/Bank PM contains a superseded
portable default, use the current explicit teacher-approved rules below unless a newer explicit teacher instruction
changes them.

GLOBAL RULES
A. SHORT BY DEFAULT.
   Extra context only when it improves the Physics/evidence. `context_rich` is a tool, not the default.

B. VISUALS ARE EFFECTIVELY FREE.
   If a graph, FBD, vector diagram, motion diagram, table, image, or model materially improves/carries evidence, plan a
   purpose-built representation. Do not reuse one asset across separate canonical questions merely to save production
   effort. Parallel visual questions normally get fresh parallel data/visuals. A coherent multipart WTC may share one
   stimulus; downstream reuse of the SAME canonical item may reuse that item's finalized visual.

C. PARALLEL IS INTENTIONAL.
   Declared parallels should resemble their seed in skill/evidence/difficulty. Similarity is not a defect. The map must
   plan legitimate variation axes rather than fake novelty through only names/nouns/version labels.

D. PHYSICS MATH IS PHYSICAL.
   Plan short physical situations whose measurements feed a relationship. A formula may be supplied. Do not plan naked
   variable-assignment worksheets as the student experience.

E. MULTI-STEP MEANS DEPENDENCY.
   An intermediate result must be needed for the final result.

F. PURPOSE BEFORE INVENTORY.
   Counts are containers. They do not manufacture evidence jobs.

DESTINATION CONTRACTS TO AUDIT
------------------------------
1. WTC
- 1 per section.
- FRQ decomposition/navigation practice.
- May use Physics outside current section/unit.
- Does NOT count toward current-Unit I-can coverage.
- One coherent shared stimulus with 3-5 connected parts.
- Useful sequence may include interpret -> plan/model -> calculate/analyze -> justify/critique.
- Representation planned when useful; shared within the multipart item is allowed.

2. EXAMPLE / YTI
- 4 pairs per section.
- Example = seed; YTI = deliberate parallel/application.
- When an I-can naturally supports useful quantitative/formula work, strong Physics-math applications take precedence
  over generic vocabulary/conceptual filler.
- Short by default.
- Visual YTIs normally plan fresh parallel representations.

3. PRACTICE
Purpose: rich instructional menu/downstream Activity source pool, not a 96-question assignment.

Practice Set 1 = 24 SEEDS per section:
- Q1-Q10: 10 vocabulary-family slots. Usually 1-2 questions per important term until 10 are filled. Use approved
  vocabulary directions; do not let vocabulary replace the I-can's real reasoning elsewhere.
- Q11-Q20: 10 concise conceptual Physics-thinking slots. Choose best-fit structures: predict, compare, classify,
  cause/effect, misconception, evidence/model reasoning, brief explanation, graph/diagram interpretation, ranking,
  representation translation, etc. No forced variety quota.
- Q21-Q24: 4 Physics-math slots:
    Q21 contextual direct quantitative;
    Q22 contextual inverse/rearranged relationship;
    Q23 another useful quantitative application OR graph/table/diagram quantitative reasoning;
    Q24 dependent multi-step quantitative.
  If section math is light, preserve recurring Physics-math practice using an accessible current/prior relationship in
  the Warm-Up spirit. A formula may be supplied. Keep the situation physical.

Practice Set 2 / Set 3 / Extra:
- Qn is a controlled parallel of PS1 Qn.
- Preserve primary skill/evidence job and approximate difficulty.
- Map legitimate variation axes appropriate to the structure.
- Visual parallels normally require fresh visual/data instances.

4. CYU
- 6 concise items per section.
- Adapt/select strong current-section Practice families rather than inventing six unrelated shells.
- Purposeful resemblance to Practice is acceptable; CYU is not secure evidence.
- Actual I-can progression chooses the six; no forced equal quota.

5. WARM-UPS
- 3 Warm-Ups x 4 questions per section.
- Fixed four-job pattern unless current Framework explicitly supplies a more specific rule:
    Q1 current/recent Physics retrieval;
    Q2 older/spiraled Physics retrieval;
    Q3 concise conceptual/vocabulary/application retrieval;
    Q4 recurring Physics math/formula skill.
- Q4 uses a short physical situation, supplied relationship when useful, and use/rearrange/invert/interpret work.
- Repetition is allowed and often desirable.

6. EXIT TICKETS
- 3 forms x 4 questions per section.
- MAP EVIDENCE BEFORE PROSE.
- Exit A has FOUR UNIQUE secure seed slots A1-A4, each with its own evidence job and primary I-can.
- Default shape only when supported by the I-can map:
    Q1 core understanding;
    Q2 conceptual reasoning;
    Q3 quantitative/application;
    Q4 strongest evidence/transfer.
  The evidence map may override this default.
- B1 parallels A1, B2 parallels A2, etc.; C does the same.
- Preserve evidence job/skill/structure/approximate difficulty.
- Do not plan direct copies of exposed Practice/EX-YTI/CYU/Warm-Up prompts as secure instances.
- Fresh secure stimuli/data/visuals as appropriate.
- Short by default; four questions should remain an Exit Ticket.

7. SUMMATIVE
- 6 forms x 20 questions per Unit.
- MAP EVIDENCE BEFORE PROSE.
- V1 = 20-slot master secure blueprint using current Framework response-mode requirements.
- V2-V4 = deliberate slot-by-slot parallels of V1.
- V5 = second 20-slot alternate secure blueprint with comparable Unit coverage/rigor and meaningfully different evidence
  families/contexts/representations/dependency paths where useful.
- V6 = current approved deliberate slot-by-slot parallel of V5.
- Secure seeds may assess taught I-cans/families but should not plan exposed instructional prompts as the secure instance.
- Selected-response distractor planning is item-specific misconception/error evidence, not a generic answer bag.

WHAT "FRESH EYES" MUST CHECK
============================
Audit BOTH the whole map and every planned canonical slot. The map must not pass merely because counts reconcile.

SLOT-LEVEL CHECKS
-----------------
Every non-WTC slot receives these checks. WTC uses N/A where current-Unit I-can/security fields do not apply.

1. `authority_alignment` — PASS/FAIL
- exact I-can ID/text are real and belong where claimed;
- section/content relationship makes sense;
- formula/vocabulary/representation content is consistent with Framework/Assessment Plan;
- WTC content target is legitimate even when cross-Unit.

2. `resource_purpose` — PASS/FAIL
- the slot serves the destination's philosophical purpose;
- Practice is learning/menu material, Exit/Summative are evidence, WTC is FRQ navigation, Warm-Up is retrieval, etc.

3. `evidence_job` — PASS/FAIL
- evidence/learning job is specific enough to author from;
- it is not generic filler such as "show understanding";
- assessment evidence jobs actually support the mapped I-can and Unit Assessment Plan.

4. `structure_plan` — PASS/FAIL
- chosen structure is appropriate to the evidence job/I-can;
- structure exists in or is a legitimate application of current Question Structure authority;
- multi-step is truly dependent;
- no forced explain/justify wrapper merely to inflate rigor.

5. `wording_length_plan` — PASS/FAIL
- default is `short` unless context genuinely earns space;
- `context_rich` is used intentionally, not as a default;
- WTC may use `frq_multipart`;
- the plan is not setting the author up for verbose prompt shells.

6. `representation_plan` — PASS/FAIL/N/A
- if representation is materially needed, the actual representation mode is planned;
- if no visual helps, N/A is valid — do NOT create decorative visual quotas;
- separate canonical visual questions do not casually plan reuse of one asset merely to save work;
- parallel visual items normally mark fresh parallel assets/data;
- the planned representation actually supports the evidence job rather than giving away the answer.

7. `parallel_variant_plan` — PASS/FAIL/N/A
- seed/parallel/adaptation/retrieval/alternate role is correct;
- seed link and parallel family resolve;
- variation axes fit the question structure;
- intentional similarity is protected;
- fake novelty and meaningless noun swapping are not treated as sufficient when a richer parallel is required;
- procedural parallels may legitimately stay close.

8. `security_plan` — PASS/FAIL/N/A
- Exit/Summative slots are planned as fresh secure instances rather than exposed prompt reuse;
- secure parallels preserve comparability without becoming literal exposed copies;
- instructional destinations normally use N/A.

9. `physics_math_plan` — PASS/FAIL/N/A
- quantitative jobs are physical, concise, and mathematically appropriate;
- formula/relationship handling fits the intended skill;
- no naked variable assignment is planned as the default student experience;
- Q24 Practice multi-step has a real dependency chain;
- if no math is involved, N/A.

10. `inventory_links` — PASS/FAIL
- slot ID is unique;
- destination/set/version/section/slot numbering is correct;
- required seed/adaptation links resolve;
- required fields are populated;
- no question prose, answer, DOK, or Bloom has leaked into the map.

J. Exit B/C resolve to A slot-by-slot.
K. Summative V2-V4 resolve to V1; V6 resolves to V5.
