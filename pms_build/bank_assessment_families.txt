If a profile revision changes any contract or slice consumed by the stage being entered, or if explicit compatibility is absent, FAIL CLOSED rather than assuming compatibility.

EXECUTABLE STRUCTURE / RENDER GATES — HARD
------------------------------------------
Every secure seed must execute the mapped structure, response mode, representation, and tool route.

Selected response:
- complete visible choices;
- keyed correct answer;
- plausible misconception/error distractors.

Small table:
- real semantic HTML table;
- `<table class="values">` for compact data;
- never pipe-delimited text.

Graph:
- use registered `graph_tool` when supported;
- inspect actual render.

Diagram/FBD/vector/model:
- approved source or deterministic route;
- no crude, low-resolution, physically incorrect, or answer-leaking visual;
- missing approved route -> fail the item.

Representation-required item with no visible representation = FAIL.

DOWNSTREAM NOTES ROUTE HANDSHAKE — HARD
---------------------------------------
When finalizing BANK_MANIFEST.json, publish the Notes route contract explicitly:

  "downstream_contracts": {
    "notes_route": {
      "schema": "bank-notes-route/1.0",
      "route_field": "paths.notes",
      "route_template": "<exact current BANK_MANIFEST.paths.notes value>",
      "producer_stage": "3C_assessment_families"
    }
  }

Rules:
- `downstream_contracts.notes_route.route_template` must exactly equal `BANK_MANIFEST.paths.notes`.
- `route_field` must be exactly `paths.notes`.
- This is a producer/consumer handshake for downstream Notes jobs; it does not replace `paths.notes`.
- A future incompatible route schema must use a new schema/version rather than silently changing this contract.
