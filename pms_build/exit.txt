NEW-EVIDENCE PARALLEL RULE
--------------------------
Students may have practiced the same skill or family in:
- Notes
- Practice 1
- Extra Practice
- CYU
- Activities
- Warm-Ups

That is expected.

For straightforward procedural/direct tasks, it is ACCEPTABLE for an Exit question to be a
clean fresh parallel that keeps the same prompt skeleton and changes the values/data.

Examples of acceptable fresh parallelism:
- same solve/evaluate structure with new values;
- same table-reading structure with new table values;
- same slope-from-two-points structure with new points;
- same input/output structure with a new rule and values.

For a DISTINCTIVE task surface, change more than numbers when practical:
- graph
- table with unusual pattern
- context/stimulus
- error-analysis setup
- reasoning/decision prompt
- shared data set

For those, prefer changing at least one additional meaningful axis such as:
- representation details;
- direction;
- missing information;
- context relationship;
- misconception;
- comparison target;
- decision.

Do NOT force novelty that weakens the evidence job.

========================================================
6. Q3-Q4 REASSESSMENT — COMPARABILITY FIRST
========================================================

This is the key repeat rule.

A reassessment question must preserve:

- same source evidence job as prior Q1/Q2;
- same Mastery Goal / I Can target;
- SAME FAMILY ID by default;
- same family invariant;
- same response mode;
- same representation mode by default;
- similar usable difficulty;
- similar amount of reasoning/work.

The purpose is to measure the same evidence again.

REASSESSMENT FRESHNESS OVERRIDE
-------------------------------
For official Exit-to-Exit reassessment:

A number/data/value swap is EXPLICITLY ACCEPTABLE and OFTEN PREFERRED.

Examples:
- new coordinates on the same type of coordinate-plane task;
- new values in the same evaluation structure;
- new slope values in the same graph/table architecture;
- new input/output rule with the same missing-value job;
- new scale/intercepts on the same kind of graph-reading task.

Do NOT change family merely to make the repeat "look fresh."

Do NOT add a new representation or reasoning demand unless the family/source evidence already
permits it and comparability remains strong.

Still prohibited:
- exact previous question repeated;
- same distinctive values/data/stimulus;
- same graph/table reused;
- same answer accidentally preserved through trivial renaming when the whole task is effectively identical.

This Exit-specific repeat rule OVERRIDES the shared freshness contract's normal
"cosmetic parallel — repair by default" behavior for Q3-Q4 reassessment.
