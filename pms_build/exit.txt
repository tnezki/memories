ROLE: Build TWO official Algebra 1 Exit Tickets per section from the exact section evidence jobs
in the coursewide Exit evidence map and the current family Bank, with a continuous 2-new + 2-reassess
ticket-to-ticket evidence chain.

CORE PURPOSE
------------
Exit Tickets are official evidence events.

Each section has:
- Ticket A
- Ticket B

Each ticket has four evidence jobs:
- 2 NEW current-section Mastery evidence opportunities
- 2 REASSESSMENT opportunities from the immediately previous ticket's new pair

The chain advances EVERY TICKET, not merely every section.

Example:
Section 1.2 Ticket A
- New: Section 1.2 evidence jobs
- Reassess: Section 1.1 Ticket B new pair

Section 1.2 Ticket B
- New: fresh second opportunity on the SAME Section 1.2 evidence jobs
- Reassess: Section 1.2 Ticket A new pair

Section 1.3 Ticket A
- New: Section 1.3 evidence jobs
- Reassess: Section 1.2 Ticket B new pair

========================================================
3. EXACT SECTION ARCHITECTURE — TWO TICKETS
========================================================

Every normal section has exactly:

  Ticket A
  Ticket B

Each ticket has exactly 4 evidence jobs.

CANONICAL EVIDENCE ORDER
------------------------
Internal canonical evidence slots:

  N1 = current-section new evidence job 1
  N2 = current-section new evidence job 2
  R1 = reassessment of immediately previous ticket N1
  R2 = reassessment of immediately previous ticket N2

Canonical/projector display order:
  Q1 = N1
  Q2 = N2
  Q3 = R1
  Q4 = R2

Do NOT create Ticket C.

========================================================
4. ROLLING "BUMP" CHAIN — HARD
========================================================

The reassessment source is the immediately previous OFFICIAL TICKET'S NEW PAIR.

Within a normal section:

Ticket A:
- N1/N2 = current section's two mapped evidence jobs
- R1/R2 = previous section Ticket B N1/N2

Ticket B:
- N1/N2 = FRESH second opportunities on the SAME current section evidence jobs
- R1/R2 = current section Ticket A N1/N2

Then the next section Ticket A reassesses the previous section Ticket B N1/N2.

CHAIN EXAMPLE
-------------
1.1 A -> 1.1 B -> 1.2 A -> 1.2 B -> 1.3 A -> 1.3 B -> ...

The "bump" is always:
  current ticket N1/N2
      becomes
  next ticket R1/R2

This creates a continuous evidence chain.

========================================================
5. U1.1 OPENING RULE
========================================================

U1.1 has no prior Algebra Exit Ticket.

Ticket A:
- use the four opening evidence jobs from the U1.1 evidence-map exception;
- internally designate the first mapped pair as N1/N2;
- the remaining two opening jobs fill R1/R2 positions ONLY AS OPENING NEW EVIDENCE;
- do not label them as reassessment in metadata.

Ticket B:
- N1/N2 = fresh second opportunities on the designated U1.1 N1/N2 evidence jobs;
- R1/R2 = fresh reassessments of U1.1 Ticket A N1/N2.

From that point forward, use the normal rolling chain.

========================================================
7. TICKET B NEW EVIDENCE — SECOND OPPORTUNITY
========================================================

Ticket B does NOT invent new section targets.

Ticket B N1/N2:
- target the SAME two mapped section evidence jobs as Ticket A N1/N2;
- use fresh instances;
- may use the same family when that gives the cleanest evidence comparison;
- may use another Exit-allowed family when it is materially equivalent and still executes the exact evidence job;
- preserve useful difficulty.

The point is:
- another opportunity to show current-section evidence;
- not a different curriculum target.

========================================================
8. REASSESSMENT RULE — COMPARABILITY FIRST
========================================================

R1/R2 preserve the immediately prior ticket's N1/N2 evidence architecture.

By default preserve:
- same MG / I Can / evidence job;
- SAME FAMILY ID;
- same family invariant;
- same response mode;
- same representation mode;
- comparable amount of reasoning/work;
- comparable useful difficulty.

EXIT-TO-EXIT FRESHNESS OVERRIDE
-------------------------------
A fresh number/data/value swap is EXPLICITLY ACCEPTABLE and OFTEN PREFERRED.

Examples:
- new coordinates in the same coordinate-plane job;
- new table values in the same rate job;
- new input/output values in the same rule job;
- new scale/intercepts in the same graph-reading job;
- new values in the same direct procedural structure.

Do NOT change family merely to make a reassessment look more novel.

Still prohibited:
- exact repeated finished question;
- exact prior values/data/stimulus;
- same graph/table reused as the same task;
- accidental identical surface with only a name change.

========================================================
9. INSTRUCTIONAL PARALLELS FOR NEW EVIDENCE
========================================================

For Ticket A/B N1/N2, students may have seen the same family or prompt structure in:
- Notes
- Practice 1
- Extra Practice
- CYU
- Activities
- Warm-Ups

That is expected.

For straightforward procedural/direct evidence:
- a fresh number/data swap may be sufficient.

For distinctive surfaces such as:
- unusual graph
- distinctive table
- context/stimulus
- error analysis
- reasoning/decision task

prefer one additional meaningful variation axis when practical.

Do not force novelty that weakens the intended evidence.

========================================================

  Version 4

  N1, N2, R1, R2

Each version uses FRESH PARALLEL INSTANCES.
Do NOT simply print the exact same four questions in a different order.

VERSION ROTATION — HARD
-----------------------
Rotate the four EVIDENCE JOBS through visible question positions.

Use this exact cyclic position map:

Version 1:
  Q1=N1, Q2=N2, Q3=R1, Q4=R2

Version 2:
  Q1=N2, Q2=R1, Q3=R2, Q4=N1

Version 3:
  Q1=R1, Q2=R2, Q3=N1, Q4=N2

Version 4:
  Q1=R2, Q2=N1, Q3=N2, Q4=R1

Each version:
- same four evidence jobs;
- fresh parallel values/data/stimuli;
- comparable difficulty;
- same family by default for each evidence job;
- no answer leakage.

This rotation prevents neighboring students from having the same evidence job in the same visible position.
