4A · BUILD PHYSICS NOTES MAP PM v1.8
====================================
TEXTBOOK-CHUNK / NOTABILITY FLOW — 2026-08-29

ROLE
----
Build the Physics Notes map for one Unit by trimming the existing Physics textbook into a classroom-length lesson and routing the exact course-owned Notes components through that retained textbook flow.

4A is a CUT + ROUTE mapper.
It is NOT a second textbook authoring stage, NOT a Bank audit, and NOT an image-discovery project.

The Physics textbook owns the explanatory spine. The Unit Bank owns the canonical WTC and Notes EX/YTI pairs. The Physics Notes Image Toolkit owns canonical source-image bytes. 4A decides:
- what textbook material stays;
- how much it is trimmed;
- where natural reading chunks begin/end;
- which ONE processing event follows each reading chunk;
- where overflow EX/YTI pairs go after the reading when there are more canonical pairs than natural insertion points.

The target is a coherent 30–40 minute Notes lesson that still sounds and reads like the Physics textbook rather than a newly written summary.

======================================================================
0. OPERATING MODEL — HARD
======================================================================

For each course section:
1. resolve the exact section title / Learning Target / I-cans;
2. open the matching Physics textbook section;
3. preserve the textbook's conceptual order;
4. divide the useful source into a small number of coherent reading chunks;
5. mark source material KEEP / CONDENSE / DROP;
6. preserve useful textbook figures at their natural source locations;
7. insert the canonical WTC early;
8. after each retained reading chunk, map at most ONE processing event:
   - PHYSICS NOTE, or
   - canonical EX/YTI pair, or
   - STOP & DISCUSS, or
   - NONE;
9. if canonical EX/YTI pairs remain after all natural concept boundaries are used, queue those remaining intact pairs AFTER the final reading chunk;
10. map Vocabulary Preview, Vocabulary definitions target, Summary, What I Figured Out, and Common Mistakes;
11. stop.

HARD RHYTHM RULE
----------------
Do NOT place a Stop & Discuss and an EX/YTI pair at the same reading boundary.
Do NOT stack a Stop & Discuss immediately on top of an EX/YTI pair merely because both exist.
Reading should breathe:

READING CHUNK -> ONE PROCESSING EVENT -> NEXT READING CHUNK

The only intentional exception is the post-reading EX/YTI queue when the Bank contains more required pairs than the textbook has natural insertion points.

4A MUST NOT:
- invent a new conceptual sequence when the textbook already provides one;
- write final Notes prose;
- rewrite the textbook into short generic summaries;
- write final vocabulary definitions;
- create new worked examples when canonical Bank EX/YTI already exist;
- copy Bank prompts/solutions into the map;
- re-audit the full Bank;
- search all toolkit images for a different story when the textbook already embeds appropriate images;
- run broad repository audits unrelated to this map;
- fail because of optional polish.

======================================================================
4. TEXTBOOK CHUNK MAPPING — PRIMARY METHOD
======================================================================

Use the actual textbook HTML as the instructional spine.

Create 3–6 coherent reading chunks when the source allows it. A chunk should normally contain enough explanation to teach one connected idea and should be short enough that 4B can keep its heading/reading/figure together sensibly for Notability.

For every source block assign:

KEEP
- directly useful for the current LT/I-cans;
- preserve its idea, order, and recognizable explanatory language;
- 4B should trim by omission/light editing before rewriting.

CONDENSE
- useful but too long or repetitive;
- preserve the source's conceptual progression and as much useful original wording/structure as practical;
- cut repetition, side anecdotes, extended history, and duplicated examples first.

DROP
- outside the current target;
- redundant with Bank practice;
- long tangents not necessary for the lesson;
- answer/media-link clutter;
- material that would push the section beyond the time target.

SOURCE-TEXT FIDELITY
For each retained chunk record one of:
- CLOSE: keep source wording/paragraph logic as much as practical; trim mostly by omission;
- LIGHT_CONDENSE: preserve recognizable source explanation but remove repeated/detail-heavy sentences;
- STRONG_CONDENSE: preserve only the essential source idea when time demands it.

Default toward CLOSE or LIGHT_CONDENSE. STRONG_CONDENSE should be uncommon.

Each retained reading chunk should record:
- flow_id;
- source_heading;
- source_block / source span description;
- action = KEEP|CONDENSE;
- text_fidelity;
- transition_heading_target;
- purpose;
- i_can_ids;
- retained_images;
- processing_after = physics_note|ex_yti|stop_discuss|none.

Do not write final prose in 4A.

======================================================================
5. LESSON-TIME BUDGET — HARD DESIGN TARGET
======================================================================

Each finished section should normally fit a 30–40 minute class period.

Design roughly toward:
- Vocabulary Preview + WTC + Let's Get Started: 5–7 min;
- textbook-derived reading/images: 10–15 min total;
- canonical EX/YTI pairs: 10–16 min total;
- S&D / Physics Note processing: 2–5 min total;
- Vocabulary + Summary + What I Figured Out + Common Mistakes: 3–5 min.

This is a design budget, not a stopwatch.

When the source textbook is long, CUT BY OMISSION FIRST. Do not automatically replace strong source exposition with short newly authored summaries.

Prefer:
- several developed reading chunks;
- source figures in their natural locations;
- one processing event per natural boundary;
- no more than one S&D in a normal section unless a second is clearly necessary.

======================================================================
6. OPENING / CLOSING MAP
======================================================================

OPENING ORDER
1. exact section title / LT / I-cans;
2. Vocabulary Preview + prior-knowledge sort;
3. canonical WTC;
4. Let's Get Started skim activity immediately before close reading.

LET'S GET STARTED target:
- skim headings/figures;
- record ONE thing noticed;
- record ONE thing wondered.

Do not use a large three-prompt prediction task unless a current Framework explicitly requires it.

CLOSING ORDER
1. Vocabulary definitions;
2. bulleted Summary;
3. What I Figured Out;
4. Common Mistakes;
5. any final general Notability workspace only when genuinely useful.

WHAT I FIGURED OUT
Map this as a brief student reflection connected to the opening notice/wonder and the Summary. It is part of the normal close, not an optional add-on.

======================================================================
7. WTC + EX/YTI INSERTION
======================================================================

WTC
- one canonical WTC per section when the Bank provides it;
- place early after title/LT/I-cans + Vocabulary Preview;
- map by exact Bank ID only;
- do not copy/rewrite WTC content into the map.

EX/YTI
For each canonical pair record:
- example_bank_id;
- yti_bank_id;
- i_can_id;
- insertion_after flow_id OR `post_reading_queue`;
- concept being processed.

HARD
- every canonical Notes EX/YTI pair exactly once;
- Example immediately paired with its YTI;
- no split pair;
- no rewritten pair;
- no substitute pair;
- no invented additional EX/YTI.

PLACEMENT RULE
Use a pair after a reading chunk when it naturally processes that exact concept. Never force a pair into the middle of a source explanation just to distribute tasks evenly.

If no clean reading boundary remains, place the untouched pair in `post_reading_ex_yti_queue` after the final reading chunk.

======================================================================
8. PHYSICS NOTE
======================================================================

A Physics Note is a compact instructional sidebar, not another question bank.

Map one only when it improves understanding of the immediately surrounding textbook idea by doing one of these jobs:
- make a relationship explicit;
- name/interpret an equation or representation;
- show a compact modeling convention;
- connect a figure to the physical meaning;
- clarify a vocabulary distinction students need before continuing.

For each Physics Note record:
- after_flow_id;
- title_target;
- note_job;
- i_can_ids;
- source_basis;
- representation/image IDs if any.

Do not write final prose in 4A.
Do not map a Physics Note merely to fill space.

======================================================================
9. STOP & DISCUSS
======================================================================

Map S&D only when the preceding reading chunk needs verbal/conceptual processing not already handled by a mapped EX/YTI pair.

Each S&D MUST map 2–4 questions and include:
- at least one vocabulary-use question tied to the preceding reading;
- at least one conceptual question answerable from the preceding text/figure;
- optional compare/predict/evidence question when useful.

Record:
- after_flow_id;
- i_can_ids;
- discussion_job;
- 2–4 prompt_skeletons;
- source_image_ids;
- expected_reasoning_evidence_to_listen_for as bullets.

`source_image_ids` contains image IDs only; non-empty values must match:
^PHYS-[A-F0-9]{12}$

HARD
- S&D and EX/YTI may not occupy the same reading boundary;
- do not put an S&D immediately after a canonical EX/YTI unless a new reading chunk intervenes;
- do not write a polished teacher script in 4A.

======================================================================
10. IMAGE RESOLUTION — TEXTBOOK PLACEMENT WINS
======================================================================

PRIMARY PLACEMENT TRUTH
The actual textbook section HTML determines where a textbook image belongs instructionally.

For each retained textbook `<img>`:
1. record source path/basename;
2. resolve it against the pinned Physics Notes Image Toolkit catalog using source_catalog_path, basename, provenance, alt_text, and metadata;
3. record canonical image_id and toolkit_path;
4. keep it attached to the same reading chunk unless that chunk is dropped.

Metadata disagreement is a warning, not a reason to move the image. Actual textbook placement wins.

Only select a non-textbook toolkit figure when the current I-can requires a representation the textbook/Bank does not already provide.

Do not perform a full toolkit audit.

======================================================================
11. VOCABULARY / SUMMARY / COMMON MISTAKES
======================================================================

VOCABULARY PREVIEW
- exact required terms from current course authority.

VOCABULARY DEVELOPMENT
- optional first-flow-location for important terms.

SUMMARY TARGETS

WHAT I FIGURED OUT TARGET

COMMON MISTAKES TARGETS
- section-specific misconceptions/errors the Notes should explicitly repair.
