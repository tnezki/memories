2. RUN MODES
===========================================================
A request may contain one or more operations in the same run:

A. EVIDENCE UPDATE
- One or more student evidence files are supplied.
- Preserve raw evidence, judge/update evidence state, grades, reports, and PowerSchool exports.

B. ROSTER UPDATE
- Runs only when roster_update_requested=true.
- A current PowerSchool roster/template CSV is explicitly supplied.
- Compare the supplied roster to the stored registry before applying changes.
- Student Num is the durable identity key when present.
- Added students become active. Students absent from the new roster become inactive; never delete their historical evidence.
- Exact existing student numbers reconnect to prior history, including returning students.
- Name changes on the same student number update the current display name without creating a new student.
- Ambiguous/duplicate/malformed identity rows go to review_queue.csv; do not guess.
- A normal evidence run with roster_update_requested=false reuses the stored roster and requires NO roster upload.

C. STUDENT SUPPORT UPDATE
- Runs when one or more files are explicitly classified as student_support_files.
- Accepted examples include IEP, 504, accommodation plan, case-manager accommodation summary, or another teacher-authorized support document.
- These are private support/setup sources, never student evidence.
- Preserve each source unchanged under 02 Portfolio Data/Student Support/Source Files with SHA-256/import timestamp.
- Match to the current registry using exact Student Num when available, otherwise unique exact normalized student name; unresolved identity goes to student_support_review.csv. Never fuzzy-guess.
- Extract only classroom/assessment information needed to apply the student's documented support accurately. Do NOT transcribe diagnoses, medical history, family details, disability narrative, or unrelated sensitive content into normalized Portfolio state.
- student_support_current.csv should contain only actionable support fields such as student_key, source hash/date, accommodation/modification label, concise operational description, applies_to, and review/expiration metadata when explicitly present.
- Approved accommodations do not lower the learning standard or evidence status of a valid demonstration. Use the support state to interpret conditions of administration and to honor required access supports.
- A support-only run may occur with no new student evidence and must not alter evidence_ledger.csv, I Can status, Mastery Goal grades, or PowerSchool grades.

8. INTERVENTION ROUTING - THREE TEACHER LANES
===========================================================
The teacher report is intervention-first. Translate longitudinal evidence into exactly three lanes:

WHOLE CLASS
- Use only when current evidence supports a genuinely broad shared instructional need suitable for normal class time.
- Do not recommend whole-class reteach from raw frequency alone, from No Evidence, or merely because many students have different problems on one I Can.
- Identify the shared target(s), shared misconception/pattern, affected students/count, and concise instructional need.
- If evidence does not support a classwide intervention, say no whole-class intervention is recommended and do not create a separate Whole Class page.

PRIORITY DAY GROUP
- Teacher-led Crewtime reteach groups.
- Group students only when at least two students share the SAME current substantial-gap bundle of 2-4 exact I Cans.
- The bundle is the grouping key. Example: students needing IC01+IC02 belong together; students needing IC01+IC02+IC03 are a different group.
- Never create a Priority Day Group from a single shared I Can alone.
- Never place `Brief guided practice` language on the teacher report.
- Each group card shows the exact I Can code + full statement for every bundle target, student names, evidence-backed shared need/misconception, and concise teacher move.
- Students with 3-4 substantial gaps who do not share an exact bundle with another student remain inside the Priority Day lane as compact teacher-review rows; do not invent a fourth intervention lane.

PULL IN STUDENTS
- Student-centered, not I-Can-centered.
- Use for students with 1-2 current small/actionable gaps that fit short individualized help and personalized practice while the teacher circulates among 3-4 students.
- Show student name, exact 1-2 I Can targets, and concise practice/check need.
- Do not group these students under a shared I Can heading.

Students who only need another independent demonstration and do not need practice/reteach stay out of all three intervention lanes; show them only in the detailed evidence appendix/reference state.
