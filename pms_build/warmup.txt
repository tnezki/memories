---------------------------

- finished Warm-Up questions are NOT Bank inventory;
- author from curriculum/warmup_progression_map.json + recurring profile;
- require map schema algebra-warmup-progression-map/1.1 or a later compatible schema;
- the map is COURSE-LONG authority and must already contain all eight Units;
- default = 3 daily Warm-Ups per section unless teacher/calendar changes it;

  Q1 Solve / Equation Fluency

2. ALGEBRA DAILY AUTHORING — HARD
---------------------------------
Build the requested number of days INSIDE each section row.

Q1 · SOLVE / EQUATION FLUENCY
- default mini-set = 2 equations;
- 3 equations allowed only when all are very short one-step retrieval;
- 1 equation allowed when the method is substantially longer;
- across the normal three days, newly introduced work should appear gradually and earlier types should remain alive;
- do not make every Q1 equation the newest type;
- do not use coefficient inflation as fake difficulty;
- obey the Unit solve ceiling exactly.

Q2 · DIAMOND / FACTORING PATTERN
- normally one job per day;
- vary known/missing cells when mathematically useful;
- stay inside the section's numeric/factoring progression;
- do not jump from number product-sum directly to symbolic factoring before the map permits it.

Q3 · SKILL REVIEW
- follow the section's planned prerequisite/review theme;
- normally one short job;
- a 2–3 item mini-set is allowed only when all items serve one coherent narrow fluency purpose;
- the lane is intentional prerequisite runway, not random review;
- it may preview a prerequisite but must not teach unreached course content as a second lesson.

Q4 · CHALLENGE
- one short reasoning job;
- keep it accessible enough that everyone can attempt it;
- full completion is not required for every student;
- across the section's days, vary thinking when useful:
  pattern / explain / compare / error analysis / representation / generalize / model / critique;
- do not merely increase arithmetic length.

3. THREE-DAY SECTION RHYTHM
---------------------------
For the default three days:
- Day 1 may emphasize clean entry/retrieval.
- Day 2 may emphasize the new or expanding fluency named in the section row.
- Day 3 should mix/strengthen the row and keep earlier fluency alive.

This is a planning tendency, NOT three separate stages and NOT a rigid template.
If a section row contains no new solve type, all three days may be cumulative maintenance with useful variation.

Freshness:
- do not clone Day 1 and only change numbers for Days 2–3;
- repeated routines are good; accidental duplicate questions are not;
- the four job identities stay stable while instances vary.

4. MATHEMATICAL QUALITY
-----------------------
Keep concise, routine-friendly wording.
Use natural numbers/coefficients.
Prefer mentally readable arithmetic when the target is reasoning rather than computation.
Representations must be accurate and answer-neutral.
Challenge may use a representation, but should not require a large multi-step project.

Warm-Ups create learning/retrieval; they are not official evidence events.
Do not label questions Intro / Review / Mastery.
