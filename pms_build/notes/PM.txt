======================================================================
5. 30–40 MINUTE LESSON CONTRACT
======================================================================

Each section is a classroom lesson, not a miniature textbook chapter.

Use the map's 30–40 minute target as a hard design constraint.

Typical student-time budget:
- KWL + Vocabulary Preview: 3–4 min;
- WTC: 3–5 min;
- adapted textbook reading/images: 8–12 min total;
- canonical EX/YTI pairs: 12–16 min total;
- Stop & Discuss: 0–3 min normally;
- vocabulary definitions + Summary + Common Mistakes close: 3–4 min.

When the textbook section is long:
- keep the conceptual sequence;
- keep the strongest phenomenon/example/image;
- compress repeated explanations;
- remove long tangents/history/personal essays/media-link clutter unless directly required by the LT/I-can;
- do not preserve source length merely because the source is good.

The finished explanatory reading should normally be several concise developed chunks, not a wall of text and not one-sentence fragments.

======================================================================
6. TEXTBOOK ADAPTATION RULES
======================================================================

Walk the 4A map in order.

For a textbook_block marked KEEP:
- preserve the source concept/order;
- adapt/paraphrase into clear high-school Physics Notes prose;
- preserve necessary equations/relationships and the mapped source image;
- trim incidental details that do not help the current target.

For CONDENSE:
- preserve the essential physics idea and its role in the flow;
- substantially shorten it;
- normally use one concise paragraph or a small cluster rather than reproducing the source block.

For DROP:
- omit it.

COPYRIGHT / SOURCE RULE
Do not reproduce long textbook passages or captions verbatim. Paraphrase/adapt the source. Short technical terms, equations, labels, and unavoidable concise wording may be preserved.

SOURCE FLOW RULE
Do not reorder the conceptual sequence merely to make the Notes sound different. The textbook spine is deliberate unless the map explicitly changes it.

======================================================================
7. SECTION ASSEMBLY ORDER
======================================================================

For each section:
1. Start from the established/current Notes HTML shell and required CSS links.
2. Insert exact section title, Learning Target, and I-cans.
3. Add the brief KWL opening.
4. Add Vocabulary Preview + required prior-knowledge sort.
5. Insert the exact mapped WTC early.
6. Walk the mapped textbook flow:
   - KEEP/CONDENSE source blocks into concise Notes reading;
   - reference mapped source images in place;
   - insert EX/YTI exactly where mapped;
   - insert mapped S&D with concise final wording.
7. Create only mapped generated representations.
8. Add Vocabulary with concise definitions.
9. Add mapped bulleted Summary.
10. Add mapped Common Mistakes.
11. Add required generous Notability/student workspace.
12. Finalize STUDENT HTML.
13. Derive TEACHER HTML from the finalized student structure; add only solutions/guidance.
14. Run quick section QA and move on.

Do not stop the whole Unit for a repairable section formatting issue.

======================================================================
8. CORE PHYSICS NOTES DESIGN
======================================================================

Physics Notes should feel like a concise, illustrated Conceptual Physics lesson interrupted at logical points for students to think and apply.

Use direct, concrete, precise high-school Physics language.

READING SHOULD EXPLAIN
- what changes / what stays the same;
- cause/effect or relationship;
- what evidence/measurement/model matters;
- how the representation connects to the physical idea;
- common misconception contrasts when mapped.

AVOID
- plug-and-chug variable dumps with no physical situation;
- generic filler;
- unnecessary historical exposition;
- one-sentence stacking;
- long textbook-like walls of prose.

11. STOP & DISCUSS
======================================================================

Write final S&D wording only where 4A mapped it.

GOOD
- specific to the immediately preceding concept/image/model;
- compare, predict, explain, rank, infer, identify evidence, or resolve a misconception;
- normally 1–3 focused prompts.

BAD
- generic stock prompts;
- automatic S&D after every pair;
- hidden second question bank.

Teacher copy adds expected reasoning/evidence-to-listen-for.
