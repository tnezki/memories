======================================================================
5. 30–40 MINUTE LESSON CONTRACT
======================================================================

Each section is a classroom lesson, not a miniature chapter and not a thin outline.

Typical budget:
- Vocabulary Preview + WTC + Let's Get Started: 5–7 min;
- retained textbook reading/images: 10–15 min;
- canonical EX/YTI: 10–16 min;
- S&D / Physics Note processing: 2–5 min;
- Vocabulary + Summary + What I Figured Out + Common Mistakes: 3–5 min.

When the source is long:
- cut repetition/details/tangents first;
- keep conceptual sequence;
- keep the strongest source phenomena and figures;
- prefer selective omission/light editing over replacing good source exposition with new summary prose.

======================================================================
6. SOURCE-TEXT FIDELITY — HARD
======================================================================

Physics Notes should still feel recognizably based on the Physics textbook.

For text_fidelity = CLOSE:
- preserve source paragraph logic and as much useful original wording as practical;
- trim mainly by omission;
- make only the edits needed for classroom clarity, current terminology, or length.

For LIGHT_CONDENSE:
- preserve the source explanation and sequence;
- remove repeated examples/details;
- keep enough source language that the result reads like a shortened textbook passage, not a newly authored abstract.

For STRONG_CONDENSE:
- reduce to the essential idea while preserving the source's conceptual role;
- use only when 4A explicitly mapped it.

Do not expand CONDENSE material beyond the map.
Do not replace KEEP/CLOSE material with generic one-paragraph summaries.

Use source material consistent with the permissions and source-use expectations of the curriculum system. The preferred editorial operation is CUT, not unnecessary rewrite.

Do not add a Notes Exit Ticket / Exit Check.

======================================================================
8. NOTABILITY / PAGINATION CONTRACT — HARD
======================================================================

STUDENT NOTES ARE NOTABILITY-FIRST.

Use the existing CSS-supported keep-together containers so atomic instructional units do not split awkwardly across pages. Prefer the established contracts already supported by `css/notes.css`, including:
- `.vocab-preview-section` for the complete Vocabulary Preview/sort;
- `.notes-wtc` for the complete WTC unit;
- `.skim-section-task` for Let's Get Started;
- `.notes-ican-start` for a compact close-reading chunk when it fits the intended block size;
- `.math-notes` shell for a mapped Physics Note unless a current Physics-specific shell is already supported;
- `.notes-discuss-task` for Stop & Discuss;
- `.notes-task` / `.notes-task-content` / `.notes-task-workspace` for each Example or YTI task;
- `.figure-block` / established figure wrappers so figure + caption stay together;
- `.notes-mistakes-block` / mistake table contracts for Common Mistakes.

CHUNK SIZE RULE
Do not place an enormous multi-page reading inside one avoid-break wrapper. 4A mapped compact reading chunks for this reason. Keep heading + a reasonable reading block + its associated figure together when practical.

FORCED PAGE BREAKS
Do NOT use `.page-break`, `break-before: page`, or `page-break-before: always` in ordinary Notes flow.

A forced page break is allowed only for a genuinely special purpose, such as:
- a deliberately separate full-page Notability workspace explicitly required by the map/Framework;
- another course contract that explicitly requires a new page.

Never force a page break merely because a heading, answer block, or teacher note looks crowded. Let keep-together containers move intact blocks naturally.

======================================================================
9. LET'S GET STARTED / WHAT I FIGURED OUT
======================================================================

LET'S GET STARTED
Use the existing skim shell, but the student job is intentionally small:
- skim the section headings/figures;
- record ONE thing you notice;
- record ONE thing you wonder.

Do not add a prediction row unless current Framework explicitly requires it.

WHAT I FIGURED OUT
Near the end, after Summary, give students a small reflection box that asks them to state what they figured out and, when useful, connect back to their opening notice/wonder.

This is the completion half of the opening skim—not an Exit Ticket.

======================================================================
11. PHYSICS NOTE
======================================================================

Render only Physics Notes mapped by 4A.

Use the established Notes sidebar shell (currently `.math-notes` is the supported compact keep-together shell) but label it visibly `Physics Note` and give it a short concept-specific title.

A Physics Note should be concise and explanatory. It may include a relationship/equation/representation, but it is not a second worked-example bank.

If a Physics-specific class is already supported by the pinned CSS, prefer it. Do not create a third stylesheet merely for the label.

======================================================================
12. STOP & DISCUSS
======================================================================

Render only S&D mapped by 4A.

Each S&D:
- 2–4 focused questions;
- at least one vocabulary-use question;
- at least one conceptual question answerable from the immediately preceding reading/figure;
- may include one compare/predict/evidence question;
- generous but not excessive response space.

Do not create generic stock discussion prompts.
Do not put S&D immediately after an EX/YTI without a new reading chunk between them.

======================================================================
13. TEACHER COPY — HTML VIEW FIRST
======================================================================

The teacher copy preserves the exact student order/content but is optimized for on-screen teacher use, not student Notability pagination.

TEACHER COPY MUST:
- keep all student content visible;
- collapse/remove fixed-height student writing-space requirements so content flows naturally;
- allow extra vertical teacher-only information; space is not a problem;
- keep answers clearly teacher-only;
- show answers in RED;
- present Answers / Acceptable Reasoning as easy-to-scan BULLETS whenever there is more than one idea/part;
- present Teacher Moves as a bulleted list;
- present Student Discourse Moves as a bulleted list;
- avoid dense teacher paragraphs when bullets communicate the same information more clearly.

Teacher support should be provided for the major interactive anchors:
- WTC;
- each EX/YTI pair;
- each S&D;
- mapped Physics Note when facilitation guidance is useful.

Preferred teacher-support sequence:
1. Answer / acceptable reasoning — red bullets;
2. Teacher Moves — bullets;
3. Student Discourse Moves — bullets;
4. Likely misconception / listen-for — bullets when needed.

For canonical Bank tasks, use the Bank solution exactly for the mathematical/physics answer; formatting it into bullets is allowed without changing meaning.

Teacher support must not alter the student task.
