C. STANDARD GENERATED CONTENT
=====================================================

Author directly from the exact section Learning Target / I Cans.
Do not conduct a separate research pass.

[ ] C1. Section Introduction
    - short meaningful opening
    - not fake career relevance
    - not a restatement of the Learning Target

[ ] C2. Vocabulary Preview
    - useful section vocabulary/notation only
    - Know for sure | Recognize | Don't know yet

[ ] C3. Section Preview
    - exactly two rows:
      What I noticed
      What I wonder

[ ] C4. Close Reading Directions
    - one global directions box
    - no repeated Talk to the Text boxes

[ ] C5. For each exact section I Can:
    1. robust reading
    2. substantive Math Notes
    3. Example
    4. You Try It
    5. Stop and Discuss

[ ] C6. Robust reading
    - normally 2–4 concise paragraphs
    - teaches the idea
    - connects words to representations
    - contains substance worth annotating

[ ] C7. Math Notes
    - actual mathematics must be visible
    - use real equations/rules, tables, graphs, contexts, mappings, diagrams, or processes
    - styled labels alone do not count

[ ] C8. Representation system — FOLLOW FRAMEWORK EXACTLY
    If four views of one relationship are intentionally shown, use exactly:
      Equation/Rule | Table | Graph | Context/Situation
    Ordered pairs may appear as correspondence notation, but are not a fifth independent view.

[ ] C9. Representation fidelity — HARD
    If the prompt names a representation, render it literally.

    TABLE:
      real semantic HTML table

    GRAPH:
      actual graph stimulus, or actual blank coordinate plane for construction

    MAPPING:
      actual mapping diagram

    ORDERED PAIRS:
      ordered-pair notation when ordered pairs themselves are the intended representation/job

    CONTEXT:
      actual situation/context

    Missing named representation -> NOTES_REQUIRED_REPRESENTATION_MISSING

[ ] C10. Graphs
    - use the current registered Algebra graph tool
    - do not hand-build coordinate SVG as a substitute
    - do not inspect old graph scripts for examples/patterns
    - do not restyle the registered graph tool inside Notes
    - if the registered tool cannot produce a required graph:
      report NOTES_REQUIRED_GRAPH_MISSING with owner GRAPH_TOOL_REPAIR
