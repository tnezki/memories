Use this workflow to assess scanned student work, connect evidence to course I-can statements, and maintain a growing student portfolio over time.

Previous Portfolio output ZIP

Upload the most recent Portfolio output ZIP from the previous run.

First run: there is no previous output ZIP, so just upload the PM and scanned assessment PDF.
Important: the previous Portfolio ZIP is the continuing evidence state. Do not replace it with only the newest student's files or a partial folder.

What the Portfolio PM does

  • Uses the blank assessment pages to identify the questions and intended evidence.
  • Connects each meaningful response to the appropriate I-can statement and learning progression.
  • Evaluates evidence cautiously using mathematical accuracy, conceptual understanding, reasoning, representation/communication, and independence/transfer when those dimensions apply.
  • Distinguishes minor execution slips from deeper procedural or conceptual misconceptions.
  • Looks at the student's accumulated body of evidence instead of simply averaging scores.
  • Updates recommendations that can connect to the Progress Tracker.
  • Flags ambiguous scans, uncertain mappings, or questionable evidence for teacher review instead of guessing.

What is in the output ZIP

The returned ZIP is designed to become the current Portfolio state for all students. It may contain:

  • student-by-student evidence records;
  • current I-can / learning-progression status recommendations;
  • the rubric version used to interpret the evidence;
  • misconceptions and whether they appear new, repeated, improving, or resolved;
  • student summaries and teacher-facing evidence notes;
  • Progress Tracker update recommendations;
  • mapping/audit information showing how assessment items were connected to learning targets;
  • a teacher-review queue for anything that should not be decided automatically.
Save the entire returned ZIP. This becomes the Previous Portfolio output ZIP that you upload with the next batch of student work.

The scanned assessment PDF itself is source evidence for the current run and is not intended to be duplicated inside every future Portfolio ZIP.

How to use the output next time

  1. Keep the returned Portfolio ZIP intact.
  2. Prepare the next scanned assessment PDF with blank pages first and student work after them.
  3. Start a new Portfolio run by uploading:
    • 17_Portfolio_PM.zip
    • the new scanned assessment PDF
    • the most recent Portfolio output ZIP
  4. The new output should preserve the prior evidence and add the new evidence rather than starting over.

Current pilot limits

The early Portfolio workflow is intentionally cautious. It is primarily being used to test evidence judgments and Progress Tracker alignment with Exit Tickets and similar formative evidence.

  • Do not treat one weak Exit Ticket as automatically erasing an established body of strong evidence.
  • Do not treat one easy correct answer as automatic mastery.
  • Unclear or conflicting evidence should be surfaced for teacher review.
  • PowerSchool export, family email workflows, and final grade conversion can be added to the Portfolio family later without replacing the evidence system.
