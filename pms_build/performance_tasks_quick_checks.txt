10. MATHJAX — HARD
======================================================================

When mathematics is present, use EXACTLY:

<script>
window.MathJax = {
  tex: {
    inlineMath: [['$','$']],
    displayMath: [['$$','$$']],
    processEscapes: true
  }
};
</script>
<script async src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js"></script>

Configuration precedes library.

All visible TeX syntax must be inside delimiters.
Inline: `$...$`
Display: `$$...$$`
Escape currency: `\$`.

A page that loads MathJax but visibly leaves raw `x^2`, `\frac`, `_1`, etc. has FAILED.

If current Framework manifest declares a final-byte MathJax fixer:
- direct-fetch it;
- run against unzipped staging root;
- rerun QA;
- do not package tool.
If not declared, do not search for one.
