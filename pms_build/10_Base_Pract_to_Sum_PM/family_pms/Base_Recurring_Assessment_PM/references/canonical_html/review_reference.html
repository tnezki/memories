Mastery Goal 1

Coordinate Graphs & Meaning

Back to top
Mastery Goal

Interpret and create graphs on the coordinate plane while connecting points, axes, intercepts, and graphical information to mathematical situations.

I can...

  • I can read and plot ordered pairs using the x-coordinate first and the y-coordinate second.
  • I can identify the x-axis, y-axis, and intercepts from a graph.
  • I can explain what a point or intercept means in a mathematical situation.

What to remember

  • An ordered pair $(x,y)$ tells how far to move horizontally first, then vertically.
  • A point on the y-axis has $x=0$; a point on the x-axis has $y=0$.
  • An intercept is where a graph crosses an axis. In context, it should be interpreted using the quantities on the axes.
  • Graph scale matters: read tick marks and units before using coordinates or rates.
Key words:coordinate planeordered pairx-coordinatey-coordinatex-axisy-axisintercept

Common traps

Reversing coordinates

Reading $(x,y)$ as vertical then horizontal.

Ignoring scale

Assuming every grid mark represents 1 when the axis may use another scale.

DOK 1

Locate or name a coordinate, axis, or intercept.

DOK 2

Use several graph features together or connect them to a situation.

DOK 3

Justify an interpretation when scale, context, or multiple features must be coordinated.

Input–Output Patterns & Rules

Back to top
Review Target

Identify patterns and represent relationships using input-output rules, tables, words, and symbols.

I can...

  • I can describe how outputs change as inputs change in a table.
  • I can translate a verbal input-output rule into symbols.
  • I can use a rule to generate or check outputs.

What to remember

  • Inputs are the values put into a rule; outputs are the resulting values.
  • A table, a verbal rule, and a symbolic rule can describe the same relationship.
  • Look for what happens when the input increases by 1, then check that the pattern works for every row shown.
  • Substituting an input into a rule is a quick way to verify that the rule matches a table.

Review Focus 3

Constant Rate of Change

Back to top
Review Target

Recognize constant rate of change in tables, graphs, visual patterns, and situations.

I can...

  • I can calculate change in output divided by change in input.
  • I can decide whether a rate of change is constant across a relationship.
  • I can interpret a constant rate using the quantities and units in a situation.

What to remember

  • A constant rate means equal changes in input produce equal changes in output.
  • From two points, compute rate as $\dfrac{y_2-y_1}{x_2-x_1}$.
  • In a table with input steps of 1, the output difference is the rate.
  • Always attach meaning or units when the relationship comes from a context.
Key words:rate of changeconstant ratechange in inputchange in outputslopeunits

Rate from two points

$m=\dfrac{\Delta y}{\Delta x}=\dfrac{y_2-y_1}{x_2-x_1}$

For $(2,3)$ and $(6,11)$: $m=\dfrac{11-3}{6-2}=2$.

Common traps

Using only the output change

Rate compares output change to input change.

Checking one interval

A constant rate must stay the same across the relationship.

DOK 1

Compute a rate from a straightforward pair of points or table.

DOK 2

Determine whether the rate stays constant and interpret it.

DOK 3

Use rate evidence to justify or reject a claim about a relationship.

Review Focus 4

Comparing Relationships

Back to top
Review Target

Compare relationships using equations, graphs, tables, visual patterns, and contexts, then justify conclusions.

I can...

  • I can compare rates of change from different representations.
  • I can compare starting values or y-intercepts when they are meaningful.
  • I can justify a comparison using specific numerical or graphical evidence.

What to remember

  • Use the same features to compare two relationships: rate, starting value, intercepts, and values at the same input.
  • Two equations can have the same rate but different starting values.
  • Two tables can be compared by matching input values and checking output changes.
  • In context, state what the comparison means instead of reporting numbers alone.
Key words:comparerate of changestarting valuey-interceptparallelevidence

Same rate, different start

$A: y=2x+1$    $B: y=2x-4$

Both have rate 2. Their y-intercepts are 1 and -4, so the graphs are parallel distinct lines.

Common traps

Comparing unlike features

Do not compare one relationship’s rate to another relationship’s starting value.

Claim without evidence

Name the value, pattern, or feature that supports the comparison.

DOK 1

Identify a rate or intercept from a familiar representation.

DOK 2

Compare two relationships using one or more common features.

DOK 3

Justify which relationship better fits a condition or claim.

Review Focus 5

Representing Linear Relationships

Back to top
Review Target

Represent linear relationships using tables, graphs, equations, and contextual descriptions.

I can...

  • I can identify the constant rate and starting value of a linear relationship.
  • I can write a linear equation from a table, graph, or context.
  • I can connect the rate and intercept in an equation to features of a graph or situation.

What to remember

  • A linear relationship has a constant rate of change.
  • In $y=mx+b$, $m$ is the rate of change and $b$ is the y-intercept or starting value.
  • From a table, find the constant change and the output when $x=0$ when available.
  • From a context, identify the starting amount and the amount added or subtracted per unit.

Depth of thinking

DOK perspective

DOK describes the kind of thinking a task asks for. It is not a proficiency score.

DOK 1 · Recall / Execute

Read or calculate

  • Name coordinates or intercepts.
  • Evaluate a rule.
  • Compute a straightforward rate.
DOK 2 · Connect / Represent

Use relationships among ideas

  • Translate a table into a rule.
  • Compare rates or starting values.
  • Write a linear equation from another representation.
DOK 3 · Reason / Justify

Defend a conclusion

  • Use multiple features to support a comparison.
  • Critique a rule or model using evidence.
  • Explain why representations do or do not match.
Extended thinking

Only when the task genuinely requires it

  • Collect or analyze richer data over time.
  • Build, test, and revise a model across several connected steps.
Final check

Before you call yourself ready

Without notes

  • Read points, axes, and intercepts.
  • Find and interpret a rate.
  • Identify a starting value.

Across representations

  • Move among tables, words, symbols, and graphs.
  • Compare two relationships using the same features.
  • Write a linear equation from evidence.

Explain your thinking

  • Use values or features as evidence.
  • Attach units or context when appropriate.
  • Check that your answer matches the original relationship.
