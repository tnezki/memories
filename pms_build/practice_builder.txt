BUILD / RUN PRACTICE BUILDERS - BANK FAMILY GENERATION
======================================================
STATUS: CURRENT
JOB: practice_builder
REVISION: 2026-09-27 v2.1

ROLE
Provide targeted Algebra practice from selected exact I Cans using the current resolved approved Bank family pool.

TWO SURFACES
1. STUDENT PRACTICE BUILDER
   Public/course resource:
     algebra/practice_builder___p7r4x/student_practice_builder.html
   Students select I Cans and receive practice from the approved student pool.

2. TEACHER PRACTICE BUILDER
   Teacher-only local control:
     _algebra_teacher_tools/tools/practice/teacher_practice_builder.html
   It must not remain as an active public control page in the Algebra repository.
   Saved finished practices may remain shareable course products/library entries.

SOURCE GATE
Resolve the selected Unit Bank through BANK_RESOLUTION.json. Use base + extension + current revision overlay and only current APPROVED, nonsuperseded families. There is no three-family A/B/C limit; family letters are stable IDs only.
Do not invent unsupported I Cans or unrelated question architectures.

SELECTION / GENERATION
For each selected I Can:
- rotate across approved useful families rather than cloning one prompt;
- prefer deterministic/seeded generation when family contracts support it safely;
- otherwise use approved prebuilt unique instances or author a fresh family-faithful instance under the current run/build route;
- avoid duplicate finished question IDs within the packet;
- independently verify answers.

Every question visibly shows:
  <I CAN CODE> — <FULL EXACT I CAN STATEMENT>

If there are not enough safe unique instances to satisfy the requested count, fail/limit transparently rather than duplicating a finished question silently.

OUTPUT
Preserve current student packet + teacher key behavior and source lineage. A New Version action should create another valid selection of sibling instances, not merely reshuffle identical finished questions when additional valid instances exist.
Teacher-saved practice products append to their library and never overwrite normal section practice_sets.

DELIVERY
Tool-code changes use ONE github_transfer / 2 ZIP. Runtime student packet behavior follows the deployed tool's current browser/local contract. No Git operations.

END - PRACTICE BUILDERS
