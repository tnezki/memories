================================================================
4. QUESTION STRUCTURE — HARD
================================================================

Every mapped FINISHED QUESTION/TASK must resolve through:
learning/evidence target -> evidence job -> student action -> Question Structure -> response -> representation -> executable route.

A structure ID existing in the catalog is not enough. Verify actual semantic fit.

HARD GUARDS
- CONSTRUCT/PLOT/CREATE/DRAW/BUILD: collect the construction on a real answer-neutral response surface. Do not substitute read-only recognition.
- MULTISTEP CHAIN: use only when a genuine intermediate result/decision must carry forward; record the dependency.
- ERROR DIAGNOSIS: require a specific misconception, supplied worked-solution error, and diagnose/repair action.
- MIXED REPRESENTATIONS: every named representation must have an executable route.
- STUDENT-CONSTRUCTED graph/number line/table: keep the surface answer-neutral.
- DIRECT READ/IDENTIFY/EXTRACT: keep it direct; do not inflate it merely to fit a more elaborate structure.
- Metadata presence alone never earns semantic PASS.

Warm-Ups follow the Framework exception and are outside Bank.
Seeds are not finished questions; Question Structure applies when a seed becomes a finished task.

================================================================
6. DESTINATION CONTRACTS
================================================================

EXIT — HARD
Follow curriculum/exit_evidence_map.json exactly.
For normal Algebra sections:
- Q1-Q2 = two NEW current-Mastery evidence jobs;
- Q3-Q4 = two fresh parallel reassessments of the previous section carry-forward pair.
U1.1 uses the Framework opening exception.
Do not remap Intro/Review into official Exit slots unless the current Framework says so.

SUMMATIVE — HARD
Build the secure blueprint from current Unit Mastery Goals + Exit evidence plan.
For Algebra:
- target about TWO secure evidence opportunities per current Unit Mastery Goal;
- design each complete form for about a 40-minute class period;
- exact item count comes from actual goal count + task complexity/time, not a hard-coded eight;
- V1 = anchor form;
- V2-V4 = parallel forms preserving evidence/difficulty;
- V5-V6 = additional secure forms under the same blueprint/comparable rigor.
Record estimated total time and explain meaningful deviations.

PRACTICE 1 — HARD
For Algebra, exactly 24 questions PER SECTION:
- 8 Intro
- 8 Review
- 8 Mastery

Use visible stage headings.
Intro = current section Intro learning.
Review = exact current Review goal at Review demand.
Mastery = exact current Mastery goal at independent demand, informed by Exit evidence without copying secure prompts/stimuli.
Distribute each 8-question block for useful repetition/coverage; do not force fake equal I Can quotas.

WTC — HARD WHEN CANONICAL
One coherent shared stimulus first, then exactly the current profile-defined ordered parts.
For current Algebra: Part A, Part B, Part C, Part D.
All parts belong to the same situation/stimulus.
Parts may be independent or naturally connected. Record dependency only when the mathematics genuinely requires it.
Authenticate every part's evidence job, student action, Question Structure, response mode, and representation routes.

SEEDS
No filler quota.
Map profile-approved Unit seeds unless explicitly rejected by the teacher or invalidated by a higher authority.
Add other seeds only when they preserve a genuinely reusable context, dataset, representation, misconception, visual/source idea, or setup.
