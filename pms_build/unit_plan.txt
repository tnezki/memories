2. PURPOSE / BOUNDARY
======================================================================

PURPOSE:
Create one concise teacher-facing Unit Plan that lets a teacher understand and navigate the Unit without reopening the full Framework for routine planning.

The Unit Plan should communicate:
- what students are learning and expected to master;
- important prerequisite/retrieval connections;
- unit vocabulary / representations / recurring practices;
- high-value essential questions;
- mastery/evidence architecture;
- live unit and section resources;
- an actionable pacing sequence.

HARD BOUNDARY:
- do not change upstream I-cans, Mastery Goals, learning targets, stage/source terminology, evidence rules, or assessment architecture;
- do not invent a competing Unit curriculum map;
- do not turn the Unit Plan into a Bank, Framework, or Assessment Plan duplicate;
- synthesis for teacher readability is allowed only when it preserves the meaning and scope of the authoritative sources.

D. DATES / MARKING PERIOD
Use only current declared pacing/calendar information.

E. INSTRUCTIONAL DAYS
Use current Framework/course pacing.
Do not force `15 Days` or three days per section when the course defines another rhythm.
Preserve the Gold Standard table architecture and express the current Unit's instructional/flex expectation as compact text.

F. VOCABULARY / NOTATION / REPRESENTATIONS
Build a scan-friendly whole-Unit list from the exact Assessment Plan / Framework.
Include important notation and representations when they are genuinely part of the course.
Do not turn vocabulary into fake I-can statements.

G. ESSENTIAL QUESTIONS
Write approximately 8–10 high-value teacher-facing questions spanning the whole Unit.
They should emphasize meaning, reasoning, representation, modeling, interpretation, evidence, comparison, conditions, or verification as appropriate.
Do not write a list of procedural `How do I solve...?` prompts.

H. COMMON FORMATIVE ASSESSMENTS
Use current Philosophy + Assessment Plan portfolio/body-of-evidence language.
Name current course evidence opportunities only where useful.
Do not make DOK a quota or turn this cell into a product catalog.

I. COMMON SUMMATIVE ASSESSMENT
Use the exact current Unit summative title/link and current Assessment Plan evidence expectations.
Do not repeat stale template claims about required DOK distributions or performance-task roles when current Philosophy/Framework differs.

J. UNIT LEARNING LADDER / PROGRESSION
Prefer the exact current Unit Learning Ladder/progression when the Assessment Plan defines one.
If the current course uses another named progression, preserve that exact architecture.

Do NOT automatically manufacture an 8-rung DOK ladder from section I-cans.
Only synthesize/condense a ladder when the current Assessment Plan/Framework explicitly requires a Unit Plan ladder but does not supply display-ready wording; in that case preserve the authoritative progression and label semantics.

K. COMPLETED DATA PROTOCOLS
Leave blank unless current explicit teacher instruction says otherwise.
