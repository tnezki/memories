Problem 17

For $f(x)=(x+5)(x-6)$, state the zeros and x-intercepts.

Answer:

Zeros $x=-5,6$; intercepts $(-5,0),(6,0)$.

Problem 18

A quadratic graph crosses the $x$-axis at $x=-3$ and $x=6$. Write a monic factored form.

Answer:

$f(x)=(x+3)(x-6)$.

Problem 19

Explain the connection among a factor $(x-7)$, the zero $x=7$, and the graph.

Answer:

The factor equals zero at $x=7$, so the function value is zero and the graph has an $x$-intercept at $(7,0)$.

Problem 20

Write a factored form with zeros $-5$ and $2$, then verify both zeros by substitution.

Answer:

$f(x)=(x+5)(x-2)$; substituting either zero makes one factor equal to $0$.

Problem 21

For $f(x)=(x-3)(x+6)$, state the $x$-intercepts and direction of opening.

Answer:

Intercepts $(3,0),(-6,0)$; the positive leading coefficient means the parabola opens upward.

Problem 22

A student claims $g(x)=(x-2)^2-4$ opens downward. Critique the claim.

Answer:

The leading multiplier is positive, so the parabola opens upward. The claim is false.

Problem 23

Which feature is most visible in $h(x)=2(x-5)^2-2$? State it.

Answer:

The vertex $(5,-2)$ is visible immediately.

Problem 24

Connect $p(x)=(x+8)(x-7)$ to two graph features.

Answer:

The $x$-intercepts are $(-8,0)$ and $(7,0)$; the positive leading coefficient means the parabola opens upward.
