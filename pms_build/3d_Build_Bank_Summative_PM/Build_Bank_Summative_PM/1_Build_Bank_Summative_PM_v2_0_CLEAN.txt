WHY THIS STAGE EXISTS
---------------------
Summative questions are the most secure evidence in the Bank. They are authored last so the builder can inspect all exposed instruction and all Exit tasks before writing them. This reduces accidental reuse while keeping the assessment tightly aligned to the approved evidence blueprint.

SUMMATIVE BLUEPRINT FIRST
-------------------------
The audited Bank Map must already define the Summative evidence blueprint before prose.

Before authoring, reconcile every V1 and V5 slot against:
- exact I-can;
- evidence job;
- response mode;
- question structure;
- representation requirement;
- approximate difficulty;
- security/freshness requirement;
- parallel or alternate relationship.

If the map is materially incomplete or contradictory, FAIL CLOSED rather than inventing a new assessment blueprint.

V1 CONTRACT - MASTER SECURE FORM
--------------------------------
V1 is the master secure assessment form.

For every V1 slot:
- author a real secure question that performs the mapped evidence job;
- preserve the mapped response mode;
- keep wording concise unless context carries real Physics evidence;
- create the mapped graph, diagram, table, model, or other representation when required;
- independently solve and verify the final item;
- selected-response distractors must be item-specific and physically plausible, not drawn from a generic distractor bag.

V2-V4 CONTRACT - DELIBERATE PARALLEL FORMS
-------------------------------------------
V2, V3, and V4 are close same-day security parallels of V1.

For each corresponding slot, preserve:
- I-can;
- evidence job;
- response mode;
- structural family;
- approximate difficulty;
- representation demand.

Change legitimate evidence details as appropriate:
- numerical values/data;
- givens/unknown;
- physical situation;
- representation values/layout;
- misconception/evidence set;
- item-specific distractors;
- wording when useful.

These forms SHOULD be similar. Do not force novelty merely to avoid resemblance.
They must not be literally identical finished evidence when the map calls for a parallel variation.

V5 CONTRACT - ALTERNATE SECURE FORM
-----------------------------------
V5 is the alternate assessment family.

It must satisfy the same Unit-level evidence requirements and overall difficulty while using meaningfully different evidence families, contexts, or representations where the audited map calls for them.

V5 is not a reordered copy of V1.

V6 CONTRACT - PARALLEL OF V5
----------------------------
V6 is the deliberate parallel form of V5.

For each slot, preserve the V5 evidence job, response mode, structural family, approximate difficulty, and representation demand while changing legitimate evidence details as appropriate.

SECURITY / FRESHNESS
--------------------
Inspect the entire Stage 3C Bank before authoring Summative questions.

A Summative item MAY assess the same I-can, formula, representation type, or reasoning students encountered during instruction or Exit Tickets. It must NOT simply reproduce an exposed instructional question, Exit question, distinctive data set, or distinctive figure.

Security does not require artificial novelty. It requires fresh evidence.

GLOBAL WRITING RULES
--------------------
SHORT BY DEFAULT.
Context-rich is a tool, not the default style. Remove setup that does not change the Physics or evidence demand.

VISUALS ARE CHEAP, NOT A QUOTA.
If a graph, FBD, vector diagram, motion diagram, table, or model improves or carries the evidence, create a purpose-built one. Parallel forms normally receive their own corresponding data/visual instance when the evidence depends on it. Do not reuse an old instructional or Exit visual merely to save production work.

Exact visual uniqueness is NOT itself a requirement. Judge correctness, usefulness, and security.

PHYSICS BEFORE ALGEBRA SHELLS.
Quantitative questions use concise physical situations. The situation supplies the measurements and students use, choose, rearrange, interpret, or combine the physical relationship. Do not write naked variable-assignment prompts.

NO UPSTREAM REPAIRS IN THIS STAGE.
If an earlier item appears flawed, record it in STAGE_3D_REPORT.txt under UPSTREAM REVIEW NOTES. Preserve it unchanged. Stage 3E will audit the complete Bank independently.

SELECTED-RESPONSE CHOICE ORDER
------------------------------
Do NOT distort canonical Bank authoring to force A/B/C/D answer-position balance.

Stage 3D owns:
- correct question content;
- correct choice content;
- exactly one defensible correct answer when selected response is used;
- item-specific distractors;
- correct answer/solution metadata.

The downstream Summative artifact builder / Practice-to-Summative workflow will run the approved deterministic choice-scramble Python tool as its LAST assembly step, then update answer keys and verify the final form. Answer-letter distribution is therefore NOT a Stage 3D quality target.
