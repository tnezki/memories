# Math Examples

## Vocabulary directionality
For `slope`:
- term -> definition
- definition -> term
- graph/example -> term
- term -> identify examples/nonexamples

## Formula / relationship variation
For `d = rt`:
- direct: given rate and time, find distance
- inverse: given distance and time, find rate
- inverse: given distance and rate, find time
- dependent transfer: infer rate from one trip, then use it on a second trip
- representation: read rate from a table/graph, then predict distance/time

Do not force every target to use every mode. The I-can design map decides what fits.
