# _question_structure v2.1 — READ FIRST

This package is the authority for question-design planning, reusable question-family architecture, representation alignment, and parallel variation. It does not replace Curriculum Philosophy, Base PMs, course Frameworks, Assessment Plans, or course-specific visual/graph tools.

## Authority / precedence
1. current explicit teacher instruction
2. current Curriculum Philosophy
3. current executable Base PM
4. current course Framework + exact Assessment Plan/I-can map
5. **this `_question_structure` package for question-design/family/variation behavior**
6. current visual/source toolkit for graphics, source examples, and enrichment

## Core workflow
**Map target → evidence job → student action → canonical family → response/representation → parameters → author → independently solve/verify → derive metadata.**

## Canonical math-family architecture
For reusable math questions use, in order:
1. `QUESTION_STRUCTURE_CORE.md`
2. `contracts/math_question_family_schema.json`
3. `catalogs/math_family_library_manifest.json`
4. the exact family source resolved by that manifest
5. the exact course-map source resolved by that manifest
6. `guides/math_family_architecture.md`
7. `guides/math_family_quality.md`
8. `guides/parallel_family_rules.md`
9. `guides/wording_profiles.md`

The manifest currently composes the LE–8 base registry/maps and the Algebra 1 extension/map. One family may appear in several courses; never clone a shared family just to give it another grade label.

## Direct / concise math wording
`direct_concise` is the default for routine worksheets, Quick Checks, and ordinary practice unless context is mathematically functional.

## Source-reference rule
Teacher-provided parallel forms and external worksheet catalogs may be studied for skill scope, recurring task architecture, representations, parameter/property options, difficulty progression, and response modes. Do not store or reproduce their wording, numbers, names, choices, diagrams, or layouts.

## Legacy libraries
The universal/stem libraries remain reference menus for unusual destinations and non-math work. They are not canonical math worksheet generators and may not override a current math family contract.

## Scope levels
artifact → section → I-can → family → item. Variety is not a quota; use the family that actually fits the evidence job.
