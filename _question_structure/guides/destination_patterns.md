# Destination Design Patterns

## WTC
One coherent FRQ-style shared stimulus with connected parts. Optimize for decomposition/navigation moves, not a grab bag of section questions. Keep the normal Bank card format; do not create a separate worksheet visual system.

## Example / YTI
Example models; YTI applies. For formula-capable targets, prefer strong contextual quantitative anchors over generic vocabulary/conceptual filler. Related, not identical.

## Practice
Build an I-can-specific menu before writing. Possible modes include direct formula, inverse formula, vocabulary, matching, graph, diagram/FBD, short answer, misconception diagnosis, multi-step, context transfer, representation translation. No universal percentages.

## Warm-Up
Preserve predictable retrieval routines. Repetition is a feature when it supports retrieval.

## Exit Ticket
Four questions should not default to four versions of the same shell. Plan different evidence modes within each ticket and across A/B/C where the target supports it. Destination security rules come from the course Framework.

## Summative
Plan form-level evidence before authoring. Same-day parallel forms may share families; alternate forms require genuinely different stimuli/structures. Family IDs must remain semantic and stable across forms.
