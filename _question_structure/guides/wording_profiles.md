# Wording Profiles

Use after the evidence job and family/structure are selected. Wording never overrides the family contract.

## Direct / Concise — DEFAULT for math worksheets, quick checks, and routine practice
Ask the mathematical action with the minimum prose needed for accuracy.

Examples of shape only (not source questions):
- `Solve for x: ...`
- `Find the scale factor from Figure A to Figure B.`
- `Use the graph to find the constant of proportionality.`

Rules:
- one clear action verb whenever possible;
- put the equation/graph/table/diagram on the page instead of describing it in prose;
- keep units and conditions that affect the mathematics;
- do not add a student name, shopping story, classroom scenario, or explanation sentence unless it changes the evidence job;
- do not restate the same task before and after the representation.

## Standard
Givens/situation first; action/question last. Use when the givens need a sentence but a full context is unnecessary.

## Inverted
Action/quantity first; givens follow. Use only when it reads naturally.

## Context-rich
Use a short authentic situation only when the context carries mathematical information, modeling decisions, interpretation, units, or transfer. End in one clear task.

### Anti-wordiness gate
Reject or rewrite a prompt when removing a sentence leaves the mathematics and evidence demand unchanged. Context that does not affect the model, inference, operation, units, or interpretation is decorative and should be removed.

### Parallel-family rule
Changing wording profile alone does not create a new family or a secure parallel.
