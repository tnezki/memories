# Question Metadata — v1.0

Question metadata is optional descriptive/provenance information attached to a finished or planned item. It never substitutes for the executable evidence-response-representation chain.

Recommended fields:
- `curriculum_topics`: framework topic codes, e.g. `AP 1.14` or `1.14`.
- `course_framework`: framework name/version when useful.
- `textbook_section`: local instructional-spine section.
- `source_type`: uploaded exercise bank, AP topic adaptation, teacher-authored parallel, etc.
- `source_ref`: traceable file/problem/topic reference.
- `source_treatment`: verbatim-user-source, adapted, or parallel-original.
- `mathematical_practices`: applicable practice/skill codes.
- `task_verb`: evaluate, justify, interpret, estimate, represent, etc.
- `calculator_policy`: not_permitted, permitted, required, or neutral.
- `ap_exam_style`: course, AP-style, released-like, etc.
- `difficulty_stage`: Intro, Review, or Mastery when the destination uses stages.
- `dok`, `bloom`, `question_family_id`, `audit_status`: assign from the finished task, not as quotas.

For copyrighted third-party source packets, `source_ref` may record the packet/topic while `source_treatment` records an original adaptation rather than reproducing protected question text.
