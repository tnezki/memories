# Representation Selection

Choose representations from the evidence job, not from a quota.

Possible modes:
- `none_direct`
- `equation_relationship`
- `diagram_model`
- `free_body_diagram`
- `vector_diagram`
- `graph`
- `data_table`
- `photo_phenomenon`
- `multi_rep_translation`

For each I-can, record:
- natural representation modes
- required tool if any
- whether student reads, constructs, critiques, compares, translates, or annotates
- answer-neutrality requirements
- N/A reason when a representation would be decorative

When a graph/diagram is the evidence, provide the actual representation. A prose description is not equivalent evidence.
