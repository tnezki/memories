# Parallel Family Rules

A `question_family_id` names the semantic evidence family, not the file slot, version, or question number.

Good family IDs:
- `constant-rate-transfer`
- `force-diagram-sliding-slowing`
- `equilibrium-support-weight`
- `graph-slope-to-velocity`

Bad family IDs:
- `secure-v3-q12`
- `practice2-item07`
- `exit-b-04`

## Instructional parallels
May share the same procedure/family. Change enough evidence features to avoid purposeless cloning. Numeric-only variants are acceptable when procedural fluency is the explicit purpose.

## Parallel worksheet forms — math
When teacher-supplied Version A/B/C/etc. worksheets intentionally mirror one another, treat the matching positions as evidence of a **shared generator family**, not as separate question banks.

For a legitimate parallel form, keep invariant:
- the same I Can / learning target;
- the same evidence job and student action;
- the same question-family architecture;
- the same response mode and representation role;
- approximately the same difficulty and computational load.

Appropriate variation includes:
- numerical values and clean-answer parameters;
- names and surface contexts;
- answer-choice order and misconception distractor values;
- exact model counts, dimensions, coordinates, or diagram orientation when evidence-equivalent;
- problem order when the destination permits it.

Do **not** call a form parallel if changing the numbers changes the underlying reasoning demand, introduces a new operation, removes a required representation, or changes the target from recognition to construction.

The number of forms is not part of the family identity. A family may support 1, 2, 3, 4, or more generated forms. Current tools may expose a smaller UI range, but the canonical family definition is not version-count-specific.

When multiple teacher examples exist, infer the family from what stays invariant across versions before authoring new instances. Do not store or reproduce the source questions themselves.

## Secure parallels
Same I-can/broad family may recur, but secure independence requires a new evidence stimulus. Version/order/noun/number swaps alone are not sufficient.

## Family planning
Before writing a large family, record:
- what stays invariant because it defines the family;
- what may vary;
- what must vary for secure forms;
- what parameter combinations would change the intended difficulty;
- what would create a mathematically, physically, visually, or grammatically invalid variant.
