# Vocabulary Question Patterns

Approved directions:
1. `term_to_definition`
2. `definition_to_term`
3. `concept_to_term`
4. `term_to_concept`

Approved presentation modes:
- single short answer
- matching set
- selected response when destination permits and distractors are item-specific
- classify/sort when several terms are meaningfully contrasted

Avoid generic vocabulary filler when the exact I-can is primarily quantitative, representational, or modeling-based.
