CURRICULUM SYSTEM RUNTIME CONTRACT
=================================

1. Canonical GitHub stores readable authorities and long-lived readable artifacts expanded. ZIP is a handoff/transport format only unless the resource is intrinsically an archive/binary bundle. A staged build checkpoint may remain a ZIP only when the PM explicitly treats the archive boundary/integrity as part of that temporary checkpoint contract.
2. Resolve and pin the memories commit and selected course commit once at job start. Never mix later commits into the run.
3. Resolve authorities through SYSTEM_MANIFEST.json and the relevant registry/manifest. Do not guess versioned filenames.
4. DECLARED AUTHORITY DIRECT-FETCH RULE — HARD: when a required curriculum authority or resource is declared by the system manifest, Framework manifest, course manifest, artifact manifest, Bank manifest/index, or request snapshot, fetch that exact declared resource at the pinned commit. Do not use generic web search, repository-wide search, similarly named files, lightweight/alternate views, archived copies, ZIPs, prior uploads, or chat copies to discover, verify, supplement, or substitute a canonical curriculum source.
5. TOOL ROUTING GATE — HARD:
   a. A PM/profile may declare `web_search_allowed = false`, `web_fetch_allowed = false`, `external_research_allowed = false`, or equivalent tool-policy fields. Those declarations are executable constraints, not commentary.
   b. When web search is forbidden, do not invoke a browser/web-search tool for discovery, validation, freshness checking, examples, supplementation, question writing, source comparison, or convenience.
   c. When web fetch is forbidden, do not open/fetch public-web URLs as an alternate way to read a declared curriculum authority. Use the declared GitHub/course resource at the pinned snapshot instead.
   d. Repository search is also forbidden for locating a source whose exact path is already declared. Direct path fetch is required.
   e. If a required declared source cannot be fetched directly, FAIL CLOSED and name the exact missing repo/path/resource. Do not search around the failure.
   f. Bank-v2 steps 2.5/2b, 3A, 3B, and 3C are NO-WEB curriculum-authoring jobs by default. For those jobs, web search, public-web fetch, and external research are forbidden unless the teacher explicitly requests outside research in the current request. A Framework/profile hint, source note, or model judgment that outside research might be useful does not override this rule.
6. Read only the files the selected PM requires. Heavy source/resource trees are on-demand resources, not default authority payloads. When a manifest declares a purpose-specific canonical file, use that file directly instead of opening a broader aggregate and searching inside it.
7. Fail closed if a required manifest, entrypoint, or canonical course artifact is missing at the pinned commit. Do not fall back to old uploads/chat copies or alternate representations.
8. One output file is returned directly. Multi-file folders may be zipped for handoff, but the ZIP is extracted before canonical GitHub sync.
9. PMs own procedure; manifests own stable discovery; Framework/course profiles own course-specific behavior; Git history owns version history.
