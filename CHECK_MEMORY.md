1. Find this exact file, `memories/CHECK_MEMORY.md`, under the user's mirrored GitHub workspace. Do not select a historical backup/transfer copy with the same basename. If the mirror is unavailable, say so and use only reliable current-session context.
2. Identify the project from the teacher's request, then read `PORTABLE_MEMORY/INDEX.md` for exact authority paths. Do not read every historic PM or conflate course folders with the current executable tool.
3. Consult `memories/SYSTEM_MANIFEST.json` and its named runtime/transfer contracts when performing curriculum BUILD/MAINTENANCE. These established authorities **remain in charge**. This file never supersedes them.

6. When a document contradicts the current teacher request or a declared source-of-truth contract, stop and reconcile using `PORTABLE_MEMORY/MAINTENANCE_RULES.md`. Do not silently promote an older summary to authority.

All private student data, rosters, grades, guardian contacts, Portfolio evidence, login details, secrets, and generated personalized assessments stay OUT of this public/repository memory index.

Portable memory is not ChatGPT's built-in saved memory. Reading it in a new chat requires a usable connected Drive or an explicitly supplied file, and a user instruction such as **"check memory"**.
