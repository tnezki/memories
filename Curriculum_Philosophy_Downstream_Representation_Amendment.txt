CURRICULUM PHILOSOPHY - DOWNSTREAM REPRESENTATION AUTHORITY AMENDMENT
====================================================================
STATUS: CURRENT
REVISION: 2026-10-01

PURPOSE
Prevent downstream assessment/build conversions from bypassing representation rules that were already established by the Bank, Question Structure, Framework, or registered tools.

1. DOWNSTREAM CONVERSION DOES NOT RESET AUTHORITY - HARD
When a downstream artifact converts, instantiates, scrambles, or adapts an approved family, the source family's evidence job, representation demand, and declared tool/render route remain authoritative unless the teacher explicitly changes the learning/evidence design.

Changing response mode (for example constructed response -> multiple choice) does not authorize a different representation engine.

2. REGISTERED REPRESENTATION TOOL SURVIVES THE PIPELINE - HARD
When the source family or current Framework requires a mathematical graph and the registered graph tool supports that graph, every downstream instance must use the registered graph tool.

Do not replace that graph with:
- hand-authored coordinate SVG;
- CSS/browser axes;
- canvas plotting;
- improvised line art;
- generative imagery;
- a visually similar graph copied from another artifact.

The graph may contain fresh secure values, bounds, points, labels, or contexts, but its rendering route remains canonical.

3. TEMPORARY / AI-AUTHORED FAMILIES ARE NOT AN EXCEPTION - HARD
A temporary family, AI-authored conversion, makeup parallel, replacement family, or personalized extension must obey the same representation/tool rules as a permanent Bank family.

Temporary status never permits a lower-quality or unregistered renderer.

4. SOURCE-FAMILY POOL / PURPOSEFUL VARIETY
When several approved families are eligible for the same I Can and destination, the downstream builder should treat them as an explicit source pool and select reproducibly from that pool rather than silently treating one family as universal.

A single assessment does not need to use every family in the pool. Selection should serve coverage, comparability, security, and evidence quality. The selected source family and available pool should remain visible in provenance.

5. FRESHNESS WITHOUT VISUAL DRIFT
Secure or parallel forms may change legal values, graph data, contexts, or other authorized variation axes. Freshness must be achieved inside the approved family/tool architecture, not by inventing a new renderer.

6. FAIL CLOSED
If a required representation has no approved supported route, fail the item/family and request repair rather than substituting an easier or improvised representation.

END - DOWNSTREAM REPRESENTATION AUTHORITY AMENDMENT
