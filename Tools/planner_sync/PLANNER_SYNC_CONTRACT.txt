PLANNER SYNC CONTRACT
=====================

STATUS: CURRENT
REVISION: 2026-09-29 - HOSTED SHARED AGENDA

PURPOSE
-------
Provide explicit teacher-controlled repository sync for the local Planners and their published shared outputs.

SYNC REPOSITORIES - HARD
------------------------
Planner/Local Tools sync operates only on:
- memories
- algebra
- physics
- apcalc
- teacher_shared

PUBLISHED AGENDA OWNERSHIP - HARD
---------------------------------
Student-facing agendas remain in the course repositories.

Co-teacher agendas are generated from the local Planner but their canonical published files live only in teacher_shared:
- teacher_shared/algebra/index.html
- teacher_shared/physics/index.html
- teacher_shared/calc/index.html

The public/unlinked hosted destinations are:
- https://tnezki.github.io/teacher_shared/algebra/
- https://tnezki.github.io/teacher_shared/physics/
- https://tnezki.github.io/teacher_shared/calc/

Local Planner URLs under /shared/... are preview/troubleshooting surfaces only. They are never the link supplied to a co-teacher.

PULL ALL REPOS
--------------
For each declared repository:
- require a valid Git work tree;
- require no merge or rebase already in progress;
- require a clean working tree;
- run git pull --ff-only;
- never stash, merge, rebase, commit, or push as part of Pull All.

COMMIT + PUSH ALL REPOS
-----------------------
For each declared repository:
- require a valid Git work tree;
- require no merge or rebase already in progress;
- git add -A;
- create one timestamped commit only when staged changes exist;
- git pull --rebase;
- abort a failed rebase;
- git push;
- never force-push.

SCHOOL NETWORK AUTH
-------------------
For tnezki-owned repositories, the sync helper may normalize:
  https://github.com/tnezki/<repo>.git
to:
  git@github.com:tnezki/<repo>.git

before sync. This avoids the school HTTPS proxy/credential prompt while preserving the same GitHub remote.

BOUNDARIES
----------
- Curriculum Transfer remains a separate Dock app.
- Planner Sync is an explicit Git-action tool.
- Curriculum Transfer itself remains Git-free.
- Student-specific Portfolio data is outside Planner Sync.
- No conflicts are resolved automatically.

END


OWNER-PAGE LINK RULE - HARD
---------------------------
Every local Planner owner page must link Co-Teacher Agenda directly to the hosted
teacher_shared destination, never to localhost /shared/...:
- Algebra 1 -> https://tnezki.github.io/teacher_shared/algebra/
- Physics -> https://tnezki.github.io/teacher_shared/physics/
- AP Calculus AB -> https://tnezki.github.io/teacher_shared/calc/

SYSTEM REPOSITORY SYNC
----------------------
Local Tools Sync includes memories so canonical local-tool/runtime changes are
available on both teacher computers.
