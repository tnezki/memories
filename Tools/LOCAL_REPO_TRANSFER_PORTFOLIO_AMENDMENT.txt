CURRICULUM TRANSFER CONTRACT AMENDMENT - PORTFOLIO
==================================================
STATUS: CURRENT

Portfolio evidence/state operations are not Curriculum Transfer jobs. Their request ZIP is INPUT transport into ChatGPT and their student-specific outputs remain inside the authorized private local Portfolio workflow.

Student evidence, student names, grades, email addresses, accommodations, Portfolio state, and other private student data MUST NOT be wrapped in a curriculum_transfer package.

A Curriculum Transfer ZIP is appropriate only for a separate system/repository change that changes Portfolio PMs, templates, Frameworks, Bank viewers, Control Panel code, Student Data Tools software, or other canonical/non-student-specific system files.

All other Tools/CURRICULUM_TRANSFER_CONTRACT.txt rules remain in force.
