LOCAL REPOSITORY TRANSFER CONTRACT AMENDMENT - PORTFOLIO
========================================================
STATUS: CURRENT

Portfolio evidence/state operations are not repository-destination builds. Their request ZIP is only INPUT transport into ChatGPT. Student evidence and private Portfolio state remain in the canonical private Drive; generated report/grade outputs are returned as the Portfolio results ZIP and MUST NOT be wrapped in a github_transfer package.

Normal Portfolio automation writes only 01 Evidence Inbox and 02 Portfolio Data. Print-ready student/teacher HTML and Mastery Goal PowerSchool CSVs are returned in the private results ZIP for teacher-controlled local PDF printing and manual placement into Drive folders 03-05.

A github_transfer ZIP is appropriate only for a separate repository-change job that changes Portfolio PMs, templates, Frameworks, Bank viewers, Control Panel code, or other canonical GitHub files. Such a transfer must contain NO student-specific Portfolio data.

All other LOCAL_REPO_TRANSFER_CONTRACT.txt rules remain in force.
