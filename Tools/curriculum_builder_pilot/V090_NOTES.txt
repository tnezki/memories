Curriculum Builder v0.9.0
=========================

Adds Algebra 1 Notes as the second Builder workflow.

Normal Notes flow:
1. Select Build Notes and click Start Notes.
2. Builder resolves the exact Assessment Plan, complete Bank, Notes profile/template/CSS, WTC, Exit, and current system authorities locally.
3. One AI handoff ZIP is created in Documents/Curriculum Builder/AI Exchange.
4. ChatGPT returns one ALG1_U#_NOTES_AI_RESULT.zip.
5. Put that ZIP in Downloads/_github_transfers and run Apply Curriculum Transfers.command.
6. Click Continue Notes.
7. Builder assembles student/teacher Notes from the canonical template, inserts exact Bank WTC, renders graphs with the registered graph tool, checks generated Example/YTI tasks against Unit Exit items, runs Notes/finalization QA, and creates ALG1_U#_NOTES_TRANSFER.zip.
8. Teacher applies the final transfer and reviews changes in GitHub Desktop.

Safety:
- no public web or File Library in local Builder runs
- no Git commands
- no direct repository writes
- AI result ZIP installs only to Curriculum Builder AI Exchange
- final Notes changes use the existing github_transfer / 2 helper
