PLANNER GITHUB ROW CONTROL AMENDMENT
====================================
STATUS: CURRENT
REVISION: 2026-09-29

The owner Planner keeps the familiar page layout.

Directly below Teacher Resources and before Current State, the familiar GITHUB
row contains exactly five controls in this order:
1. Pull All Repos
2. Commit + Push All Repos
3. Apply Changes + Update Agendas
4. Undo Changes
5. Jump to Current Week

The Planner Editor - All Weeks section no longer displays duplicate copies of
Apply / Undo / Jump. Their original controls remain in the DOM and the visible
row triggers them, preserving existing Planner behavior.

No Planner content/state is restored from old backups as part of this UI change.
The floating Top button remains.
