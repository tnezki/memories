LOCAL TOOLS
===========

Use Local Tools.app as the single Dock entry point for:

1. Student Data
   - Portfolio
   - reports
   - email workflow

2. Planner
   - Algebra 1
   - Physics
   - AP Calculus AB
   - Open All

3. Sync
   - Pull All Repos
   - Commit + Push All Repos

4. Curriculum Transfer
   - apply Curriculum Transfer ZIPs

The old individual apps are not deleted. Keep them until Local Tools is tested.
After that, they can be removed from the Dock while remaining available on disk.

Manual fallback:
  Start Local Tools.command
