PLANNER TOP SYNC NAVIGATION AMENDMENT
=====================================
STATUS: CURRENT
REVISION: 2026-09-29

The owner Planner keeps repository synchronization controls in one place only:
the top Planner action row beside Apply Changes, Undo Changes, and Jump to
Current Week.

Visible controls:
- Pull All Repos
- Commit + Push All Repos

The older lower-page GITHUB resource block is retired. In user-facing language,
these are "Sync" controls rather than a separate GitHub resource section.

The floating Back to Top control remains.

END
