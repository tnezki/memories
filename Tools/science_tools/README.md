# Science Tools — MAPS (Foundation 1)

Double-click **Start Science Tools.command** in Finder. The local dashboard opens at <http://127.0.0.1:8784/>. Python 3 is required; there are no third-party Python dependencies.

This is a working read-only shell, not yet the complete science course application. The Curriculum Library searches only public original interactive files from `~/GitHub/physics/lessons` and opens supported resources locally. No assessment, lesson, roster, accommodation, report or student-data folder is read or modified.

For the architecture audit, installation strategy and next steps, see `docs/START_HERE.md`.

Validation: `python3 -m unittest discover -s tests -v` from this folder.
