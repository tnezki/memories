GITHUB SYNC
===========

Dock-friendly global repository controls for the teacher workspace.

Main app:
  GitHub Sync.app

Fallback launcher:
  Start GitHub Sync.command

Local page:
  http://127.0.0.1:8771/

Actions:
  Pull
  Commit
  Push
  Commit + Push

The network/authentication preflight runs before any network workflow that could otherwise leave partial work behind.
