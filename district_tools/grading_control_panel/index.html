Build a grading request

Only student evidence is required. A roster, rubric, and teacher notes are optional.

Best results: one file per student with the student's name in the filename. Combined class scans are also okay when student names are visible in the work.
    Strongly recommended for combined handwritten class scans. CSV, spreadsheet, PDF, document, or text rosters are fine. The roster is used only to match names, identify unmatched/missing evidence, and preserve class order.
      A rubric or scoring guide gives the analysis explicit criteria. It can also control the optional grade/score when selected below.
        Convincing / Limited / Incorrect / Not Observed
        Every student report uses this evidence language. Not Observed means there is not enough usable evidence; it is not the same as Incorrect.
        This choice is authoritative. The evidence rating still appears either way. If you choose rubric scoring, attach the rubric above. If you choose a recommended grade, ChatGPT may make a teacher-review recommendation from the submitted evidence and any grading directions you add below.
        Useful hints you can add: click any idea to place it in your notes, then edit it as needed.
        Add the required fields and at least one evidence file.

        What happens next?

        1

        Complete this form and download the request ZIP.

        2

        Upload that ZIP to ChatGPT. The packaged request tells ChatGPT what to do, so processing begins from the uploaded request.

        3

        ChatGPT should return one response ZIP. Unzip it and open CLICK_ME.html.

        The response requests

        Individual student reports, class-wide patterns, recommended groupings, common and individualized practice, plus a six-station review/extension set with answer key.

        Teacher review stays central. The package asks ChatGPT to show its evidence basis and flag uncertainty rather than silently guessing.

        Student data: this page processes selected files in your browser to make the ZIP; it does not upload them by itself. Upload/use student evidence only in ways allowed by your district's student-data and AI policies.
