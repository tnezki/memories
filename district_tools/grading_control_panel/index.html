Build a grading request

Only student evidence is required. The rubric and teacher notes are optional.

Best results: one file per student with the student's name in the filename. Combined class scans are also okay when student names are visible in the work.
    If a rubric is included, the response may score against it. Without a rubric, the request asks for evidence-based feedback and mastery indicators rather than an invented numeric grade.
      Useful hints you can add: click any idea to place it in your notes, then edit it as needed.
      Add the required fields and at least one evidence file.

      What happens next?

      1

      Complete this form and download the request ZIP.

      2

      Upload that ZIP to ChatGPT. The packaged request tells ChatGPT what to do, so processing begins from the uploaded request.

      3

      ChatGPT should return one response ZIP. Unzip it and open CLICK_ME.html.

      The response requests

      Individual student reports, class-wide patterns, recommended groupings, and print-ready follow-up materials: one common class packet plus individualized student practice.

      Teacher review stays central. The package asks ChatGPT to show its evidence basis and flag uncertainty rather than silently guessing.

      Student data: this page processes selected files in your browser to make the ZIP; it does not upload them by itself. Upload/use student evidence only in ways allowed by your district's student-data and AI policies.
