Build a Tiered Task request

Required fields stay intentionally small. The request ZIP carries the full DOK, reading-access, product-choice, layout, and QA contract to ChatGPT.

Reading/access level changes wording, chunking, and vocabulary support only. The generated task must keep the same academic target and DOK demand.

Enter 1-4 statements. The tool creates one integrated card, not one card per statement.

Attach a reading, assignment, dataset, image, rubric, existing handout, or other resource the generated card should use or respect.

    Leave many checked for student choice, or uncheck options to limit the choices. The response must not add products you did not allow.

    Add the required fields, at least one I Can statement, and at least one product type.

    What happens next?

    1

    Complete this form and download one request ZIP.

    2

    Upload the ZIP to ChatGPT. The packaged contract is the complete build request, so no separate PM prompt is needed.

    3

    ChatGPT returns one response ZIP. Unzip it and open CLICK_ME.html.

    The response should contain

    • One student Tiered Task Card.
    • DOK 1, 2, 3, and 4 tasks on that same card.
    • A Teacher Guide / Evidence Guide.
    • HTML + PDF versions linked from CLICK_ME.html.
    • A QA record checking DOK, reading access, product choices, layout, links, math/visuals, and PDFs.
    DOK is not “easy to hard.”
    The response contract requires a real change in cognitive complexity. DOK 4 must involve genuine extended thinking rather than simply more questions.

    Selected files: this page reads them locally in your browser only to create the request ZIP. It does not upload them by itself. Follow district policy for any protected information you later upload to an AI service.
