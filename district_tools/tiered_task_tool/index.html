Build a Tiered Task request

Keep the normal path simple. The request ZIP carries the DOK rules, locked styling, district grapher, repeatable build utilities, and QA.

Enter 1-4 statements. Grade level and these targets set the rigor. The tool creates one integrated card, not one card per statement.

You can add multiple files. Select several at once or add a group of readings, assignments, datasets, images, rubrics, examples, or existing handouts.
    Advanced options

    Optional refinements. Leave these alone when the grade level, learning targets, and broad student choice are enough.

    Reading/access level changes wording, chunking, and vocabulary support only. It must not lower the academic target or DOK demand.

    Allowed student product types

    Broad student choice is the default. Uncheck options only when you want to limit how students may demonstrate the same academic evidence.

    Add the required fields and at least one I Can statement.
