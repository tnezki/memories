# CPM Tools Source Mirror

This is a code-only reference mirror of the local `CPM_Tools/cc3_tools_v3` application.

Purpose:
- preserve the locked CPM teacher-tool UI/control patterns as a reusable reference;
- let ChatGPT inspect the current builder controls from GitHub without asking for another ZIP;
- keep runtime data and teacher-created library data local.

Included: app source, builder/assembler source, assessment/creation/visual/bank pages, and shared style/JS files.

Excluded on purpose: `.runtime`, imports, exports, textbook/library content, user assets, generated visuals, assessment requests/results, saved sets, caches, ZIPs, and the old delete-later app.

The local `CPM_Tools` folder remains the running source of truth. Refresh this mirror with `memories/Tools/tool_mirrors/Refresh CPM Tools Mirror.command`, then use GitHub Sync when ready.
