SUB PLANS — PILOT WORKING PM v0.4
================================
STATUS: PILOT / WORKING — test and revise from real sub-plan runs.

PURPOSE
-------
Create complete substitute-teacher package(s) from teacher-entered lesson intent while preserving Troy Nezki's established sub-plan style, the correct MMHS bell schedule for each selected plan, current seating chart, current curriculum authorities, and Google Drive organization.

The teacher input boxes are NOT finished substitute directions. They are concise lesson-intent / outcome prompts. Use the current Curriculum Philosophy, course Frameworks, Question Structure, relevant build/shared PMs, registered tools, current course resources, and attached materials as appropriate to turn those prompts into a complete, accurate, substitute-ready day.

THIS IS A GOOGLE DRIVE WORKFLOW — HARD
--------------------------------------
This GENERAL PM is explicitly authorized to read and write the Google Drive resources declared in sibling PROFILE.json and the run-specific destination folder it resolves beneath the declared Sub Plans root folder.

Do not use public web search. Do not recover content from prior chats, saved memory, or unrelated File Library items. The teacher's current request plus the pinned PM/PROFILE, pinned Curriculum Build authorities, declared course pins, and declared Google Drive resources are the authority for this job.

REQUIRED SIBLING AUTHORITY
--------------------------
Read pms_general/sub_plans/PROFILE.json immediately after this PM. It owns:
- Google Drive folder IDs and document IDs;
- current course/hour labels;
- normal Monday and Tuesday-Friday bell times;
- stable Crewtime/Prep behavior;
- destination naming rules;
- source-template routing;
- schedule-source behavior;
- curriculum-authority routing by course.

Resolve the current authorities through SYSTEM_MANIFEST.json and the exact system commit pinned by the request.

Use, when relevant:

Course routing for this teacher:

Do not launch a full curriculum rebuild merely because an authority exists. Use only the minimum relevant current authority needed to create or select what the substitute and students need for this absence.

INPUT CONTRACT
--------------
The request manifest supplies:
- plan_types: one or more of monday | non_monday | other | emergency
- dates.monday: YYYY-MM-DD when Monday is selected; otherwise null
- dates.non_monday: YYYY-MM-DD when Non-Monday is selected; otherwise null
- dates.other: YYYY-MM-DD when Other is selected; otherwise null
- other_label: required when Other is selected
- alternate_schedule_url: optional single exact link to a dated alternate-schedule source
- hourly lesson-intent fields for:
  1st Hour — STEM
  2nd Hour — Physics
  3rd Hour — Algebra 1
  Crewtime
  4th Hour — AP Calculus
  5th Hour — Prep
  6th Hour — Algebra 1
- optional additional note
- optional attached run-specific materials
- pinned course repositories when provided by the request builder

At least one plan type must be selected.
Monday, Non-Monday, Other, and Emergencies are independent outputs and may be selected together.

If Monday is selected and dates.monday is missing, fail closed and ask for the Monday date.
If Non-Monday is selected and dates.non_monday is missing, fail closed and ask for the Non-Monday date.
If Other is selected, dates.other and other_label are required.
Emergency mode MUST NOT place a calendar date in the plan heading.

On a normal schedule, the five instructional-class fields (1st, 2nd, 3rd, 4th, 6th) are expected to contain teacher lesson intent. When an alternate schedule link is supplied, a class field may be blank if that class does not meet on the resolved dated schedule. After resolving the schedule, fail closed only when an instructional class DOES meet but its teacher intent is missing. Crewtime and 5th-hour Prep are optional override fields: when blank, use the stable PROFILE/template default for that block.

LESSON-INTENT INTERPRETATION — HARD
-----------------------------------
Treat the instructional-class text boxes as teacher intent, NOT polished directions.

The teacher may provide shorthand such as:
- "finish Newton's Laws notes, then independent force practice for 25 minutes"
- "review solving equations; independent practice plus an early-finisher option"
- "students need to complete yesterday's activity and submit in Canvas"

For each class that actually meets on the resolved schedule:
1. Determine the intended student outcome and approximate flow.
2. Use current curriculum authorities/resources only as needed.
3. Decide whether the substitute needs an existing resource, a newly generated simple resource, or only clear directions.
4. Build/select the minimum set of supporting materials needed for a successful independent class period.
5. Write concise substitute-facing directions that clearly state what students should do, where materials are, what to submit, and what to do if finished early when that matters.
6. Do not change the teacher's instructional intent or invent a new lesson objective.
7. Do not invent missing content when the teacher's prompt is too vague to build safely. Surface the missing information instead.

SCHEDULE AUTHORITY — HARD
-------------------------
Normal bell times are automatic. The teacher should not have to choose a schedule type, name a special schedule, or upload a second schedule file.

For every selected dated plan:
- If alternate_schedule_url is blank, use the normal schedule from PROFILE.json:
  - Monday plan -> schedules.monday
  - Non-Monday plan -> schedules.tuesday_friday
  - Other plan -> choose the normal schedule that matches the actual weekday when one exists; otherwise fail closed.
- If alternate_schedule_url is present, that linked source becomes the schedule authority for the selected dated plan(s).
- Read the linked schedule source and match EACH selected plan by exact calendar date.
- Use the high-school / 9th-12th-grade schedule when the source contains separate grade-band schedules.
- Extract the actual blocks and bell times from the dated schedule. Do not assume every normal class period still exists.
- If a normal class block is absent from the alternate schedule, do not invent a time for it. Mark/route that hour according to the actual schedule and preserve the teacher's lesson intent for reuse only if appropriate.
- If the linked source contains multiple dated schedules, select the one matching the requested date; do not ask the teacher to identify the schedule name separately.
- If a provided alternate schedule link cannot be opened, does not contain the selected date, or is ambiguous about the applicable high-school schedule, fail closed and identify the schedule problem.
- Do NOT silently fall back to normal bell times when the teacher supplied an alternate schedule link.

EMERGENCY
- Emergency output maintains the standard Monday and standard Tuesday-Friday reusable versions unless the teacher explicitly requests a different emergency behavior.
- Emergency output has no calendar date in the heading.

SOURCE / STYLE AUTHORITY
------------------------
Use sources in this order:
1. Teacher's current lesson-intent inputs, selected plan types/dates, optional alternate-schedule link, current run note, and run-specific attachments.
2. PROFILE.json for stable workflow facts and exact Drive resource IDs.
3. Current Curriculum Philosophy / relevant current course Framework / Question Structure / minimum applicable build or shared PMs.
4. Current pinned course repository resources when a teacher prompt refers to existing course material or when a current resource is the best fit.
5. Current native Google Doc template for the selected plan structure.
6. Resolved schedule authority: the exact-date entry from the teacher-provided alternate schedule link when present, otherwise the normal PROFILE schedule.
7. Current Seating Chart document.
8. Recent completed plans in the Sub Plans root folder only when needed to resolve a style question not already settled by the templates/profile.

Do not silently carry stale course names, times, dates, assignments, links, or student-specific facts from old completed plans.

WRITING STYLE — HARD
--------------------
- Keep substitute directions concise, practical, and easy to scan.
- Convert teacher shorthand into complete substitute-facing directions.
- Preserve the teacher's instructional intent.
- Do not add requirements, change rigor, or invent procedures.
- Prefer one short paragraph or a few short steps per class unless the lesson genuinely requires more.
- Explicitly identify generated/attached materials by exact filename/title when the substitute needs them.
- Preserve the established stable substitute-information sections from the selected current template: emergency information, discipline, attendance, passes, phone policy, and contact information.
- Preserve the established 6th-hour team-teaching note unless the teacher explicitly changes it.
- Crewtime and 5th-hour Prep use teacher overrides when present; otherwise use stable PROFILE/template defaults.

PLAN MODE ROUTING
-----------------
Execute every selected plan type in the same run using the same hourly lesson intent unless the current request explicitly says otherwise.

MONDAY
- Require dates.monday.
- Use the current Monday template as the native structural/style base.
- Use the resolved schedule authority: exact-date alternate schedule when a link is supplied; otherwise the normal Monday schedule.
- Create/reuse a child folder named exactly with the Monday ISO date: YYYY-MM-DD.
- The plan heading includes the resolved Monday date.

NON-MONDAY
- Require dates.non_monday.
- Use the current Non-Monday template as the native structural/style base unless the teacher explicitly routes another structure.
- Use the resolved schedule authority: exact-date alternate schedule when a link is supplied; otherwise the normal Tuesday-Friday schedule.
- Create/reuse a child folder named exactly with the Non-Monday ISO date: YYYY-MM-DD.
- The plan heading includes the resolved weekday/date.

OTHER
- Require dates.other and other_label.
- Other is a dated one-off plan type for a day that should not be forced into the Monday / Non-Monday labels.
- Use the closest suitable native template structure unless the teacher explicitly provides a different structural source.
- Use the exact-date alternate schedule when a link is supplied. If no link is supplied, use the normal schedule matching the actual weekday when resolvable.
- Create/reuse a child folder named exactly with the Other ISO date: YYYY-MM-DD.
- The plan heading includes the resolved date and teacher-entered other_label.

EMERGENCY
- Do not put a date in either plan heading.
- Create/reuse the child folder named Emergency beneath the Sub Plans root.
- Maintain TWO reusable native plan documents in that folder:
  1. Emergency Sub Plans - Monday
  2. Emergency Sub Plans - Tuesday-Friday
- The Monday copy uses standard Monday times/template structure; the Tuesday-Friday copy uses standard regular times/template structure.
- Shared supporting materials are stored once in the Emergency folder and referenced by both plans when applicable.

SEATING CHART
-------------
A current copy/reference to the declared Seating Chart must be available inside every resolved destination folder so the substitute package is self-contained.

- For Emergency, maintain one current copy with that title in the Emergency folder.

MATERIAL CREATION
-----------------
After interpreting the lesson intent, determine what materials the substitute and students actually need.

Create, reuse, or place supporting materials only when justified by the teacher's intent:
- If the teacher attaches a run-specific file, place a copy in the resolved destination folder and reference its exact name in the appropriate class direction when useful.
- If an appropriate current course resource already exists and the teacher's prompt points to it, prefer that current resource over inventing a duplicate.
- If the teacher gives enough intent/content to create a simple printed handout, directions sheet, independent practice, extension, or reference page, create a polished student-facing Google Doc or appropriate generated artifact in the destination folder.
- When generating math/science questions or graphs, use the current Question Structure and registered tools rather than improvised incompatible formats.
- If the direction points students to Canvas, Notability, an existing classroom resource, or another already-available item, do not invent a duplicate handout.
- Never invent missing assignment content merely because a direction says "worksheet," "practice," or similar. If required material cannot be faithfully created from the request/current authorities, keep the plan accurate and surface the missing material instead of fabricating it.

The resolved destination folder should contain everything generated or copied for that absence/emergency package:
