SUB PLANS — GOLD STANDARD PRINT-CENTER PM v0.7
================================================
STATUS: PILOT / WORKING — gold-standard format locked for live testing.

PURPOSE
-------
Create one self-contained substitute-plan ZIP from minimal teacher input. The normal academic sub day is useful evidence/review work, not generic filler. STEM continues the current design challenge or uses a teacher-selected alternate engineering-design activity.

DELIVERY — HARD
---------------
Return ONE self-contained ZIP. Do NOT create or update a Google Drive destination folder for the finished package.

The ZIP root must contain:
- index.html
- print_bundle.html
- physics.html
- algebra1.html
- ap_calculus.html
- assets/...
- data/source_map.json
- data/qa.json
- optional stem_alternate/... when Alternate STEM is selected

index.html is the teacher entry point and has exactly four primary actions:
1. Print Substitute Bundle
2. Physics Worksheet
3. Algebra 1 Worksheet
4. AP Calculus Worksheet

Google Drive is read-only for this workflow and is used only for declared live source material such as the seating chart, alternate schedule source, and authorized current evidence/portfolio context when available. Do not write the output back to Drive.

PLAN / SCHEDULE ROUTING
-----------------------
Plan type and bell schedule are separate.
- Monday with no alternate link -> PROFILE Monday schedule.
- Non-Monday with no alternate link -> PROFILE Tuesday-Friday schedule.
- Other with no alternate link -> normal schedule matching the actual weekday when resolvable.
- Any dated plan with alternate_schedule_url -> read that one source and match the exact requested calendar date. If grade bands are separated, use the high-school / 9th-12th-grade schedule.
- Never silently fall back to normal times when an alternate link was supplied.
- Never invent missing periods or times.
- Emergency remains reusable/date-free unless explicitly changed.

SUBSTITUTE PRINT BUNDLE — HARD
------------------------------
The first print button opens print_bundle.html. Its pages must be in this order:
1. hour-by-hour day directions + resolved bell schedule;
2. General Procedures & Extensions;
3. current seating charts;
4. STEM current-challenge directions, or concise access directions for Alternate STEM;
5. answer keys / evidence mapping at the END, grouped by Physics, Algebra 1, and AP Calculus.

Do not move the General Procedures page behind seating charts or STEM directions.

General Procedures & Extensions must include the stable PROFILE procedures plus the established emergency, discipline, attendance, phone-policy, and school-extension/contact information supported by current source/template authority.

ACADEMIC HANDOUTS — COMMON RULES
--------------------------------
Create ONE common class handout for each academic course; do not individualize by student. 3rd and 6th Hour Algebra 1 use the SAME handout.

Every handout includes:
- Name / Date / Hour;
- course and current section;
- current section focus;
- recent evidence / source focus when applicable;
- enough problems/workspace for the time target;
- directly under EVERY problem:
  ☐ Knew how to do it   ☐ Had to ask for help   ☐ Had to look it up
- standing direction in substance:
  "Complete as much as you can during class. Turn in to the substitute. You are encouraged to work with your table. This will be used in your portfolio."

TIME BUDGET — HARD
------------------
Use the actual resolved class length.
- Physics: target approximately class length MINUS 10 minutes.
- AP Calculus AB: target approximately class length MINUS 10 minutes.
- Algebra 1: target approximately class length MINUS 15 minutes.

Estimate time from actual task demand, not raw question count. Very short one-step questions cannot be counted as multi-minute tasks merely to hit a total. The later extension/challenge portion may be unfinished by some students.

QUESTION / EVIDENCE SOURCING — HARD
-----------------------------------
Before writing questions, map the handout's evidence jobs and intended time.

Priority:
1. current validated NON-SECURE Bank/practice/question material;
2. controlled parallel variation of validated material;
3. current notes/practice/textbook/investigation material when that course uses those as the best source;
4. brand-new authored questions only when needed.

Never expose secure Summative items.
Use current Question Structure for authored/parallel items unless the course Framework explicitly exempts the task.

REGISTERED REPRESENTATIONS — HARD
---------------------------------
If a task requires a mathematical Cartesian graph, resolve the registered graph_tool through Tools/MANIFEST.json and use it. Do not hand-draw substitute Cartesian graphs in browser SVG/CSS.

Use the current District Graph Rendering Standard and graph_tool output. Student-facing graphs must be answer-neutral when the student is expected to infer/construct something.

Physics vector/investigation grids are instructional diagrams rather than ordinary Cartesian function graphs. For Physics Section 1.3 resultants, use the current U1.3 Investigation's grid/vector visual language as the source format. Do not replace it with an unrelated custom diagram style.

MATHJAX — HARD
--------------
Use the current registered MathJax/finalization rules and the gold-standard local MathJax SVG setup. Use canonical delimiters \( ... \) and \[ ... \]. Run the current math finalizer/audit on all generated HTML with math. Raw TeX, broken fractions/exponents, clipped math, or browser-text approximations fail QA.

COURSE ROUTING
--------------
PHYSICS
- Use the current Physics Framework, exact current section architecture, current validated non-secure Physics Bank/practice, and current investigation/source materials.
- Favor physical meaning and representations over repetitive plug-and-chug.
- For Section 1.3 specifically, the current gold-standard mix is intentional: only a small number of quick collinear/same-opposite force questions; THREE two-vector non-parallel resultant problems using the current investigation grid format; and TWO three-vector resultant investigation problems at the end. Students draw the resultant on the same grid and report magnitude plus direction either as an angle measured from +x or a valid compass description such as NW.
- Do not overfill the sheet with 10-second same/opposite-force calculations.

ALGEBRA 1
- Use current authorized portfolio/evidence state FIRST to identify the most recently assessed Mastery Goal/I-cans most students still need.
- The sub handout is primarily a targeted REVIEW/EVIDENCE opportunity, not a current-section worksheet.
- Default balance when current evidence clearly identifies a weak recent goal: approximately 75-85% targeted missed/review evidence and only 15-25% short current-section check. Do not flood the sheet with current-section questions.
- Use the Algebra Bank families and approved representations. If the missed evidence is graph scale/intercepts, use the actual MG1 scale/intercept families and registered graph_tool-generated graphs, as demonstrated by the gold standard.
- If current evidence does not identify a defensible classwide priority, fall back to the Framework/Assessment Plan rather than guessing.

AP CALCULUS AB
- Do not invent section-level I Can statements when the course has not established them.
- Resolve the current section/topic from current course materials.
- Use current Notes, Practice, and/or textbook/source materials as primary content sources, then use approved Calculus Question Structure families to author controlled parallel practice when needed.
- Preserve AP notation, theorem hypotheses, justification expectations, calculator/non-calculator appropriateness, and registered graph-tool rendering from the AP Calculus Framework.

MASTERY / EVIDENCE RESOLUTION
-----------------------------
Resolve in this order:
1. current authorized portfolio/evidence state when available;
2. current course Framework + exact section/Unit evidence architecture;
3. current non-secure assessment/bank evidence relevant to that section.

For Algebra, recent classwide misses may legitimately take priority over the current section because the purpose of the sub day is useful evidence/review. For Physics/Calculus, current section work normally remains the main route unless the evidence state or teacher note says otherwise.
