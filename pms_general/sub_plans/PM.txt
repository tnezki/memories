SUB PLANS — EVIDENCE HANDOUT PM v0.5
====================================
STATUS: PILOT / WORKING — use for real sub days and revise from evidence.

PURPOSE
-------
Create complete substitute-teacher packages from minimal teacher input. For Physics, Algebra 1, and AP Calculus, the normal sub-day academic task is a class handout designed to produce useful portfolio evidence rather than simply occupy time. STEM uses either the current design challenge or a teacher-selected alternate engineering-design activity.

THIS IS A GOOGLE DRIVE WORKFLOW — HARD
--------------------------------------
This GENERAL PM is authorized to read/write the Google Drive resources declared in sibling PROFILE.json and the run-specific destination folder it resolves beneath the declared Sub Plans root folder. It may also use the exact pinned project repositories and authorities declared by the request.

Do not use prior chats, saved memory, unrelated File Library items, or stale outputs as authority. The current request, pinned project sources, this PM/PROFILE, declared Drive resources, and any exact teacher-provided alternate-schedule link are authoritative.

REQUIRED SIBLING AUTHORITY
--------------------------
Read pms_general/sub_plans/PROFILE.json immediately after this PM. It owns Drive IDs, bell schedules, stable procedures, academic handout defaults, STEM modes, print-package rules, and course/hour grouping.

INPUT CONTRACT
--------------
The request may supply:
- plan_types: monday | non_monday | other | emergency, independently selectable;
- required dates for Monday / Non-Monday / Other;
- other_label when Other is selected;
- optional alternate_schedule_url;
- STEM mode and its matching inputs;
- Physics current section, notes, and avoid list;
- Algebra 1 current section, notes, and avoid list; these settings apply to BOTH 3rd and 6th Hour;
- AP Calculus current section, notes, and avoid list;
- optional Crewtime / Prep overrides;
- optional daily custom note;
- optional attached run-specific files.

For a dated plan, Physics, Algebra 1, and AP Calculus current sections are required even when the teacher gives no further directions. Section values may be shorthand such as 1.3 or 2.4.

PLAN / SCHEDULE ROUTING
-----------------------
Plan type and bell schedule are separate.
- Monday with no alternate link -> PROFILE Monday schedule.
- Non-Monday with no alternate link -> PROFILE Tuesday-Friday schedule.
- Other with no alternate link -> normal schedule matching the actual weekday when resolvable.
- Any dated plan with alternate_schedule_url -> read that one source and match the exact requested calendar date. If separate grade bands appear, use the high-school / 9th-12th-grade schedule.
- Never silently fall back to normal times when an alternate link was supplied.
- Never invent missing periods or times.
- Emergency remains reusable and date-free unless the teacher explicitly requests otherwise.

ACADEMIC EVIDENCE HANDOUT MODEL — PHYSICS / ALGEBRA 1 / AP CALCULUS
--------------------------------------------------------------------
For every academic class that meets, create ONE common class handout, not individually customized student versions. 3rd and 6th Hour Algebra 1 use the SAME settings and SAME handout unless the teacher explicitly says otherwise.

The handout must include:
- student name;
- date;
- course;
- current section;
- mastery goal(s) being evidenced;
- original/current problems with enough workspace;
- directly beneath EVERY question, these print-safe checkboxes:
  ☐ Knew how to do it   ☐ Had to ask for help   ☐ Had to look it up
- standing direction exactly in substance: "Complete as much as you can during class. Turn in to the substitute. You are encouraged to work with your table. This will be used in your portfolio."

Time budget:
- Determine the actual scheduled class length from the resolved schedule.
- Target the student work for approximately 15 minutes LESS than the available class period.
- Do not force every student to reach the final extension items.

Question progression:
1. quick accessible entry;
2. current mastery evidence;
3. one or more stronger transfer / application / extension-challenge items near the end.
Lower-performing students may reasonably stop before the extension items; this is acceptable and informative evidence.

MASTERY-GOAL RESOLUTION
-----------------------
Resolve what to assess in this order:
1. current established portfolio/evidence data for that course when available through the authorized current workflow/state;
2. current section + relevant course Framework / learning ladder;
3. current course assessment architecture / most recent non-secure assessment evidence tied to that section.

Use the most recently assessed mastery goals that remain relevant to the current section. Include prerequisite goals only when they materially support interpretation of the current evidence. Do not turn the handout into random cumulative review.

QUESTION SOURCE PRIORITY — HARD
-------------------------------
Prefer reliability over novelty:
1. existing validated NON-SECURE bank/practice/quick-check/question material aligned to the section/mastery goal;
2. a parallel variation of validated material;
3. a brand-new authored question only when needed.
Never expose or recycle secure Summative prompts/keys as student practice. Use current Question Structure and registered graph/rendering tools where applicable.

STEM
----
STEM is not an academic evidence worksheet by default.

CURRENT CHALLENGE mode:
- Substitute-facing direction should communicate: students are working on their current challenge; a copy of the challenge is included; students know what to do.
- Teacher-pasted Canvas/current challenge directions are included in the printable substitute packet.
- Do not manufacture a second worksheet merely to fill time.

ALTERNATE ACTIVITY mode:
- Use the teacher's engineering-design focus, such as research, testing, prototyping, redesign, evaluating results, or another part of the engineering design process.
- Create a self-contained student resource suitable for independent work.
- Possible student products include poster, flyer, video, written paper/essay, one-page how-to guide, infographic, mini-presentation, or another format that better fits the focus.
- When product preference is system_choose, choose the format that best matches the learning task.
- Include useful source links and/or short teacher-created background readings as appropriate. Web research is permitted ONLY when the current request/runtime explicitly authorizes it; otherwise use project-provided or teacher-provided sources and surface any missing-resource limitation.
- Student submission wording: complete and save the work; the teacher will give directions tomorrow for how to submit it.
- Return a self-contained ZIP for the Alternate STEM resource so the teacher can host it on GitHub and manually link it from the agenda.

SUBSTITUTE PRINT SET — HARD
---------------------------
Create a first print set intended to be printed and stapled together. In order, include:
1. substitute day directions / resolved bell schedule;
2. seating chart(s);
3. STEM current-challenge directions when Current Challenge mode is used, or concise access directions for the Alternate STEM resource when Alternate mode is used;
4. stable general procedures / room information;
5. academic handout answer keys and mastery-goal mapping at the END.

The stable general-procedures/back-page content must include:
- calculators are allowed;
- pencils are in the supply area to the left of and behind the teacher's desk.
Preserve the established emergency, discipline, attendance, passes, phone policy, contact information, and 6th-hour team-teaching note unless explicitly changed.

STUDENT HANDOUT PRINT CENTER
----------------------------
Create a clear print page / print center for student handouts with one obvious control per course. It must:
- provide Physics, Algebra 1, and AP Calculus student handouts;
- make clear that Algebra 1 is used for both 3rd and 6th Hour;
- support adjustable workspace/answer-area height using the same proven live-control behavior used by current curriculum print tools;
- allow each class handout to be printed independently;
- preserve readable question/graph sizing and print geometry;
- keep answers/teacher keys out of student pages.

CUSTOM NOTES / AVOID RULES
--------------------------
- Course custom notes may add class-specific substitute context.
- The daily custom note is for information that applies across the day, including named student helpers or unusual room directions.
- "Do not include / avoid" is a hard content boundary for that course's handout.
- Do not invent or infer sensitive student information beyond what the teacher explicitly enters for the current run.
