SUB PLANS — GOLD STANDARD PRINT-CENTER PM v0.9
================================================
STATUS: PILOT / WORKING — gold-standard format and hard execution rules locked for live testing.

PURPOSE
-------
Create one self-contained substitute-plan ZIP from minimal teacher input. Academic sub days are useful review/evidence days, not generic filler. STEM continues the current design challenge or uses a teacher-selected alternate engineering-design activity.

DELIVERY — HARD
---------------
Return ONE self-contained ZIP. Do NOT write the finished output to Google Drive.

ZIP root:
- index.html
- print_bundle.html
- physics.html
- algebra1.html
- ap_calculus.html
- assets/...
- data/source_map.json
- data/qa.json
- optional stem_alternate/... when Alternate STEM is selected

index.html has exactly four primary actions:
1. Print Substitute Bundle
2. Physics Worksheet
3. Algebra 1 Worksheet
4. AP Calculus Worksheet

Google Drive is read-only for declared live sources such as seating charts, alternate schedules, and authorized evidence/portfolio state.

AUTHORITY / READ ORDER — HARD
-----------------------------
Use the request's pinned commits. Read and obey in this order:
1. current teacher instruction in the request;
2. SYSTEM_MANIFEST.json -> current Curriculum Philosophy;
3. current universal Question Structure authority;
4. current course Framework and exact relevant Unit/section assessment architecture;

6. gold-standard shell files under pms_general/sub_plans/gold_standard/;

Do not use prior chats, saved/personal memory, unrelated File Library material, or stale outputs as authority.

GOLD STANDARD — HARD
--------------------
Read sibling folder pms_general/sub_plans/gold_standard/ and GOLD_STANDARD.md first. The gold standard owns the approved print-center structure, visual language, Letter-page preview, slider behavior, MathJax setup, print navigation, bundle order, and quality floor.

Copy these shell files byte-for-byte unless the teacher explicitly reopens them:
- assets/sub_handout_madlib.css

The gold-standard example content is NOT current-source authority. Never copy stale dates, questions, answers, schedules, seating placeholders, or section labels into a new run.


PLAN / SCHEDULE ROUTING
-----------------------
Plan type and bell schedule are separate.
- Monday + no alternate link -> PROFILE Monday schedule.
- Non-Monday + no alternate link -> PROFILE Tuesday-Friday schedule.
- Other + no alternate link -> normal schedule for the actual weekday when resolvable.
- Any dated plan + alternate_schedule_url -> read that source and match the exact requested date. When grade bands are separated, use the high-school / 9th-12th-grade schedule.
- Never silently fall back to normal times when an alternate source was supplied.
- Never invent missing periods or times.
- Emergency remains reusable/date-free unless explicitly changed.

SUBSTITUTE PRINT BUNDLE — HARD
------------------------------
print_bundle.html pages must be ordered:
1. hour-by-hour directions + resolved bell schedule;
2. General Procedures & Extensions;
3. current seating charts;
4. STEM current-challenge directions or Alternate STEM access directions;
5. answer keys / evidence mapping at the END, grouped by Physics, Algebra 1, AP Calculus.

ACADEMIC HANDOUTS — COMMON RULES
--------------------------------
Create ONE common handout per academic course. 3rd and 6th Hour Algebra 1 share the SAME handout.

Every student handout includes:
- Name / Date / Hour;
- course and current section;
- concise current section focus;
- concise recent evidence/review focus when useful;
- enough meaningful work for the full scheduled class period;
- under EVERY question:
  ☐ Knew how to do it   ☐ Had to ask for help   ☐ Had to look it up
- standing direction in substance:
  "Complete as much as you can during class. Turn in to the substitute. You are encouraged to work with your table. This will be used in your portfolio."

STUDENT-VISIBILITY RULE — HARD
------------------------------
Class-period sizing is INTERNAL/TEACHER-FACING QA only. Do NOT display "Work-time target," class-length arithmetic, timing formulas, source IDs, authoring notes, Question Structure IDs, or QA metadata on a student handout.

CLASS-PERIOD SIZING — HARD
--------------------------
Use the actual resolved class length, but do NOT subtract a fixed number of minutes. Build a robust handout suitable for the FULL scheduled class period. The sheet should contain enough meaningful work that students remain productively engaged for the period, with later challenge/extension work available for faster students.

Before rendering, create an item-level time map in data/source_map.json or data/qa.json. Each problem receives a conservative estimated student-work time based on the actual task. Very short one-step questions count as no more than 0.5 minute each unless there is a genuine explanation/representation demand.

FAIL sizing QA when:
- the core + challenge/extension work is clearly too short for the resolved class period; or
- the build appears long enough only because 10-second questions are treated as multi-minute tasks.

Challenge/extension is intentionally part of the full-period design. Some students may not finish every challenge item.

EVIDENCE MIX — HARD
-------------------
Before writing questions, map THREE lanes for every academic handout:
A. RECENT / ALREADY-COVERED EVIDENCE: previously assessed Mastery Goal / I-can work that is still useful to revisit, prioritizing documented classwide misses when available;
B. CURRENT SECTION: exact current-section I-cans/evidence jobs or, for AP Calculus when no section-level I-can layer exists, the exact current Notes/Practice/textbook topic work;
C. CHALLENGE / EXTENSION: stronger transfer, representation, reasoning, or application work that remains aligned to material students can reasonably attempt.

Do not allow one lane to disappear merely because another lane is easier to generate. The map must name the source/evidence job for each item before authoring.

QUESTION / EVIDENCE SOURCING — HARD
-----------------------------------
Priority:
1. current validated NON-SECURE Bank/practice/question material;
2. controlled parallel variation of validated material;
3. current notes/practice/textbook/investigation material when that course uses those as the best source;
4. brand-new authored questions only when needed.

Never expose secure Summative items. Use current Question Structure for authored/parallel items unless the course Framework explicitly exempts the task.

PHYSICS — HARD
--------------
Use current Physics Framework, exact section architecture, validated non-secure Physics Bank/practice, and current investigation/source materials. Follow the Framework's map-first rule and favor real physical meaning and representations over repetitive plug-and-chug.

For Section 1.3 specifically, the approved GOLD-STANDARD SHAPE is intentional and may not collapse to a tiny worksheet:
- only 2-3 quick same/opposite/net-force review items total;
- THREE two-vector NON-PARALLEL resultant problems using the current U1.3 investigation grid/vector format;
- TWO three-vector resultant investigation problems;
- additional prior-MG/current-section/challenge evidence as needed so the full sheet is appropriate for the full resolved class period;
- typical total is about 10-12 meaningful problems or more when task complexity is light; use actual task demand and the resolved class period rather than a fixed count.

Students draw each resultant on the SAME grid and report magnitude plus direction either as an angle measured from +x or a valid compass description. Do not replace the vector investigation format with a generic function graph.

ALGEBRA 1 — HARD
----------------
Use current authorized portfolio/evidence state FIRST to identify the most recently assessed Mastery Goal/I-cans most students still need. The sub handout is primarily a targeted review/evidence opportunity, not a bulk current-section worksheet.

When a clear recent weak goal exists, default roughly 75-85% of the useful work to that review/evidence need and 15-25% to a short current-section check. Use actual Algebra Bank families and approved representations. When the need is graph scale/intercepts, use the MG1 scale/intercept families and registered graph_tool-generated graphs.

AP CALCULUS AB — HARD
---------------------
Do not invent section-level I Can statements when the course has not established them. Resolve the current topic from current course materials. Use current Notes, Practice, and/or textbook/source material as primary content sources, then approved Calculus Question Structure families for controlled parallels. Preserve AP notation, theorem hypotheses, justification expectations, calculator appropriateness, and graph conventions.

REGISTERED REPRESENTATIONS — HARD
---------------------------------
If a task requires a Cartesian graph, resolve Tools/MANIFEST.json -> tools.graph_tool and use it directly. Do not hand-build Cartesian axes/grids in browser SVG/CSS when the registered tool owns the representation.

Every Cartesian graph in data/source_map.json / data/qa.json must record:
- renderer path = current registered graph tool;
- graph type / bounds / scale;
- answer-neutrality result where relevant;
- accuracy visual check.

Physics U1.3 vector grids are non-Cartesian instructional diagrams and use the current U1.3 Investigation visual language.

MATHJAX — HARD
--------------
Use local MathJax SVG and canonical delimiters \( ... \) and \[ ... \]. Run the current registered math finalizer/audit on every generated HTML file containing math.

PASS is forbidden when:
- raw TeX is visible;
- formulas are clipped;
- browser-text approximations replace proper math;
- authoring shorthand/timing expressions render as malformed math;
- the final HTML has not been visually inspected after MathJax typesets.

STUDENT HANDOUT PRINT CONTROLS — HARD
-------------------------------------
Each academic page uses the gold-standard runtime:
- All workspaces sets all question workspace sizes directly;
- Problem selector chooses one question;
- selected Workspace changes ONLY the selected question;
- Graph / diagram changes ONLY the selected question's visual when a question is selected;
- the selected Graph / diagram slider starts at 0% and preserves the page's configured upper bound;
- when Problem = All, the selected-question Workspace and Graph/diagram controls are disabled;
- Reset restores all question workspace/visual values to 100%;
- Print prints the currently repaginated Letter pages.

Changing one question may move later questions to another page, but it must not alter any other question's stored workspace or visual size.

STABLE GENERAL PROCEDURES
-------------------------
Include:
- Calculators are allowed.
- Pencils are in the supply area to the left of and behind the teacher's desk.
- Students are welcome to use the iPad Crayons up front.
- Pass tablet is up front; silver power button on the side; turn on, open Chrome, use PikMyKid button in the middle; students enter their own passes.
- Only one student may be out of the room at a time.

Preserve supported emergency, discipline, attendance, phone-policy, contact information, and 6th-hour team-teaching note.

STEM
----
CURRENT CHALLENGE: include the teacher-pasted challenge directions; students continue the current challenge and know the routine.

ALTERNATE ACTIVITY: use the teacher's engineering-design focus. Suitable products include poster, flyer, video, written paper/essay, one-page how-to guide, infographic, mini-presentation, or another best-fit product. Web research is permitted only when the request explicitly authorizes it for STEM Alternate.
